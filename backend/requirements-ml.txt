# "To support decoding audio data, please install 'torchcodec'" 로 학습이 시작조차 안 된다.
# ⚠️ torchcodec은 torch와 버전이 묶여 있다(0.6.x ↔ torch 2.8). 최신판을 깔면 CUDA 13
#    런타임(libnvrtc.so.13)을 요구해 CUDA 12 환경에서 import부터 실패한다.
#
# 🔴 2026-09-15 실측 — **이 핀은 Pod 이미지 전용이다. 로컬(Python 3.14)에서는 설치되지 않는다.**
#    `pip install "torchcodec>=0.6.0,<0.7.0"` →
#      ERROR: Could not find a version ... (from versions: 0.0.0.dev0, 0.9.0, ... 0.16.0)
#    0.6.x에 cp314 휠이 없기 때문이다. 즉 이 파일 전체가 **로컬 Python 3.14에서는
#    설치 불가**다. 학습·평가는 어차피 Pod에서 도니 실무상 문제는 아니지만, 로컬에
#    깔리겠거니 생각하고 시도하면 여기서 막힌다.
#
#    로컬에서 굳이 맞추려면 (torch 2.14 ↔ torchcodec 0.12.x)가 짝이고 추가 설치만으로
#    끝나지만(torch는 안 건드린다), **torchcodec은 FFmpeg 공유 라이브러리를 요구한다** —
#    libavcodec/libavformat이 없으면 import 단계에서 OSError로 죽는다(WSL2 기본 상태가
#    그렇다). 시스템에 FFmpeg를 깔아야 하므로 로컬 검증 비용이 작지 않다.
#
#    ⇒ **데이터셋 오디오 디코딩이 필요한 스크립트(eval_dgop_discrimination,
#      fit_dgop_calibration의 비-smoke 경로)는 로컬에서 사전 검증할 수 없다.**
#      Pod 이미지(torch 2.8 / torchcodec 0.6.x)에서 돌린다 — 2026-09-09 A-3·A-4가
#      실제로 그 조합에서 성공했다.
