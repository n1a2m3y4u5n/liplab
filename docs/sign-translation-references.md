# 수어 학습 보조 모듈 — 수요 근거 인용문헌

> LIPLAB에 한국어→한국수어(KSL) 학습 보조 모듈을 넣는 근거. 대회 제출서에 인용.
> 분류: 근거는 **"농인에게 한국어는 제2언어이고, 한국어 문해가 취약하며, 수어 정보접근
> 수요가 실재한다"**는 need를 뒷받침한다. 모듈은 *통역*이 아니라 *학습·이해 보조*로 포지셔닝.

---

## 1. 전제 — 농인의 제1언어는 한국수어, 한국어는 제2언어

- **국립국어원, 「2023년 한국수어 활용 조사」** — 수어 사용 농인의 **90.8%가 "가장 적절한
  언어는 한국수어"**라고 응답(한글 3.5%, 음성 한국어 0.5%).
  - 보도: 뉴시스, https://www.newsis.com/view/NISX20240603_0002759140
- **이영재, 「농인의 언어 의식과 수화 사용」**, 국립국어원 『새국어생활』 특집 "농인의 제1 언어,
  수화" — https://www.korean.go.kr/nkview/nklife/2013_2/23_0203.pdf
- **민은주(2011), 「제2언어로서의 수화가 농청년의 정체성 형성에 미치는 영향 분석」**, 특수교육저널.

## 2. 왜 한국어 텍스트만으론 배제되나 — 농인의 문해·읽기 곤란

- **옥정달(2008), 「문장제시수단에 따른 청각장애대학생의 독해능력에 관한 연구」**, 특수교육저널:
  이론과 실천 9(4). — https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART001301833
- **윤석민(2015), 「성인 농인 문해교육 체계 설립을 위한 해석적 연구」**, 국어문학 60.
- **「수화 중심 독서지도가 농인의 어휘·문법·쓰기·읽기 능력에 미치는 효과」**, 특수교육저널. —
  https://journal.kci.go.kr/jsped/archive/articlePdf?artiId=ART001355015
- 요지: 청각장애 학생은 읽기이해 부족으로 화용·추론·고등사고의 언어 표현에 지연 → **한국어
  텍스트 단독 제공은 접근성 한계.** (수어·시각 보조가 이해를 돕는다는 근거)

## 3. 수어 정보접근·통역 수요 (규모·현황)

- **중증 청각장애인의 30.1%가 수어를 주 소통수단**으로 사용.
  - 에이블뉴스, https://www.ablenews.co.kr/news/articleView.html?idxno=213002
- **수어통역이 가장 필요한 영역: 의료기관 83.0%**, 정부 지원 요구 1위 = 공공·금융·의료기관
  **수어통역사 배치 확대 86.8%.** (뉴시스, 위 링크)
- 수어 사용 농인의 **41%가 만 7세 이후에 수어를 습득**(언어 습득 지연 → 문해 취약 배경).
  - 서울경제, https://www.sedaily.com/article/13899445

## 4. "한국어→한국수어 변환"은 학술·산업에서 활발히 다뤄지는 방향 (수요 인정)

- **「농인 중심의 기계번역을 위한 한국수어 스크립트 제작 및 텍스트 데이터 전처리 연구」**, KCI. —
  https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003132508
- **「아바타 수어 서비스를 위한 한국어–한국수어 변환 기술 연구」**, KISTI. —
  https://koreascience.kr/article/CFKO202023758834180.pdf
- **KoSign / NIASL2021** 한국어–KSL 병렬 말뭉치 (SLTAT 2022). — https://aclanthology.org/2022.sltat-1.9/
- 산업: 이큐포올(정부 브리핑·재난문자 '수어통'), 케이엘큐브(핸드사인톡톡 API), 국민연금공단
  웹 수어 번역 — 한국어→수어 아바타/영상이 **이미 공공영역에서 실서비스로 도입**됨.

## 5. 근거 → LIPLAB 설계로의 연결

| 근거 | LIPLAB 설계 반영 |
|---|---|
| 농인 제1언어 = 수어(90.8%) | 학습 문장을 **수어로도** 제시(제1언어 접근) |
| 한국어 문해 취약 | 한국어 텍스트에 **수어 + 입모양** 시각 보조 병기 |
| 정보접근 수요(의료 83%) | 일상·필수 어휘 중심 학습 콘텐츠 |
| 자동수어 품질 한계(농아인협회 비판) | **실제 국립국어원 영상** 사용 + "학습 보조(베타)" 정직 라벨, 통역 대체 주장 안 함 |

## 6. 데이터 출처·라이선스 (반드시 표기) — 실측 확인 반영

라이선스는 데이터셋/영상마다 다르므로 **개별 확인**이 필요하다(조사에서 정정된 사실):

- **텍스트 데이터** — 국립국어원 「한국수어사전 한국어대응표현정보」(공공데이터포털,
  데이터셋 15135637, 2024-09-09). **이용허락범위 "제한 없음"**(상업·변형 제약 명시 없음).
  본 모듈의 표제어·수형설명·분류 데이터 출처. → https://www.data.go.kr/data/15135637/fileData.do
  - 참고: 형제 데이터셋 「표제어 및 용례」(15122687)는 **공공누리 제4유형**(출처표시+상업금지+
    변경금지)로 라이선스가 다름. 데이터셋 ID별 표기를 반드시 개별 확인할 것.
- **수어 동영상** — 국립국어원 「한국수어사전」(sldict.korean.go.kr)은 기본
  **CC BY-NC-ND 2.0 KR**(저작자표시·**비영리**·**변경금지**). 게다가 일부 영상은 국립국어원
  비소유라 CC 미적용. → 저작권정책: https://sldict.korean.go.kr/front/main/copyRightPolicy.do
  - **결정: 영상은 임베드하지 않고 표제어 상세페이지로 "딥링크"만 한다.** 단순 링크는 복제·
    배포에 해당하지 않아 안전하고, ND(변경금지)·NC(비영리)·비소유 영상 리스크를 모두 회피한다.
  - **비영리 전제**: 본 도구는 학습 보조(비영리)로 NC 조건에 부합. 향후 **상업화 시** 영상
    이용은 국립국어원 별도 허락이 필요하다.
  - UI 출처표시 문구(수어 페이지 하단에 상시 노출):
    > 수어 영상 출처: 국립국어원 「한국수어사전」(sldict.korean.go.kr) — CC BY-NC-ND 2.0 KR.
    > 데이터 출처: 국립국어원 「한국수어사전 한국어대응표현정보」(공공데이터포털).
