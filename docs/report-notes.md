## 축 A. 농인 발화 합성과 음성구동 아바타(A4)

- **합성 교란의 검증(A, 그림7).** AI Hub 538 실발화 10화자 300문장에 경·중·심 교란을 적용했다.
  ASR CER 0.194, 0.503, 0.723, 0.922, D-GOP 원점수 16.4, 9.1, 5.3, 2.1. 클립의 82.3%에서 D-GOP가 강도 순서를
  지켰다. 첫 판(macOS TTS 7문장)은 결론에서 뺐다. 근거: `docs/deaf-synthesis.md`, `docs/dgop-remeasure-538.json`.
- **A4 제품 모델.** 동결 WavLM-large와 BiGRU 머리, 20화자 학습. 처음 듣는 화자의 jawOpen 상관 r 0.657
  (3개 홀드아웃). 평가 화자로 학습 시점을 고른 값이라 낙관적이다(화면 문구도 그렇게 적었다).
- **A1(농인 합성 증강의 견고성).** 10화자, 화자·문장이 겹치지 않는 5겹 교차검증, 4조건 × 3시드 = 60적합,
  사전등록 sha256 `f7db54f8…`. 합성 심 조건 jawOpen r이 0.202에서 0.308(augF, +0.106 [+0.040, +0.178])로 오르고,
  일반 잡음 증강보다도 +0.079 높다. 깨끗한 발화는 −0.022 [−0.046, +0.001]로 사전등록 비열등 기준(−0.02)을 조금 넘어
  판정은 '승자 없음'이다. 보고서에는 "증강은 합성 교란 견고성을 크게 높였으나 깨끗한 발화 비용이 기준을 넘어 제품에
  넣지 않았다"로 쓴다. 표는 `docs/deaf-synthesis.md` 3.1절.
- **예시 음성.** 앱의 A4 예시 5개는 합성 음성(TTS)이며 입모양은 현재 모델로 다시 계산했다(9/23).

## 축 B. 전사 비의존 발음채점(D-GOP)

- **보고서에 쓸 논지는 견고성이 아니라 전사 비의존성과 연속성이다(그림6).** 깨끗한 정상 발화도 문장 전체를
  정확히 옮긴 경우는 4.3%뿐이고(CER 0.194), D-GOP는 전사 없이 명료도에 비례한다(전사 정확도와 스피어만 0.86).
  합성 교란에서는 두 지표가 비슷한 폭으로 떨어지므로 "D-GOP가 ASR보다 견고하다"고 쓰지 않는다.
  근거: `docs/dgop-demo.md`.
- **A-7(D-GOP 표시점수 앵커).** 지금 앱에 든 앵커(9/9, 바뀌기 전 채점식으로 잰 값)로는 538 정상 발화 300문장의
  표시점수 중앙값이 59.7점이고 단어·문장 합격선(65점)을 넘는 문장이 15%다. 같은 자료의 naive 원점수 중앙값으로 다시 맞춘
  후보 앵커(정상 16.55→90점, 경 9.0→72, 중 4.8→58, 심 1.9→40)에서는 90점·97%다. 후보에서는 원점수 23.2 이상이 100점이라
  정상 발화의 7.3%가 만점을 받는다(지금 앵커는 만점이 나오지 않게 정했었다). 앱의 D-GOP 경로는 꺼져 있고, 후보 앵커는
  608 실제 청각장애 발화에서 몇 점으로 보이는지 확인한 뒤 적용 여부를 정한다. 근거: `liplab-lab/tools/a7_calibration.py`,
  `liplab-lab/data/a7_calibration_538.json`.
- **실제 청각장애 발화(그림8).** 정상(538, n=40) CER 0.219 대 608 언어청각장애 3화자(n=5) CER 0.401, 약 1.83배.
  표본이 작다. 608 감음신경성 화자 세션을 문장 단위로 잘라 CER과 D-GOP를 다시 재는 중이다
  (`liplab-lab/tools/b608_measure.py`).

## 축 C. 시각 지각공간

- 데이터(538 10화자 입모양)로 만든 공간에서 화자를 바꿔도 비심이 우연보다 잘 갈린다(균형 정확도 자음 0.345,
  모음 0.386, 우연 0.2). 손코딩 음운 공간과의 거리 상관은 0.30, 0.22로 약하다. 그래서 음운 유사도는 규칙,
  시각 혼동은 데이터로 따로 쓴다. 근거: `docs/perceptual-space-demo.md`.
- **6.1 채점 근거 문구.** 예전 소규모 대조 실험의 상관(−0.19)은 방향이 음수였다. 보고서의 "데이터 공간으로
  채점 근거를 대체한다"는 서술은 "규칙이 주, 데이터는 보조"로 고친다.
- **C-현황(입모양 지속시간 상수).** 538 실발화 280문장의 강제정렬 음절 간격과 비교하면 엔진은 실제 말(초당 6.0음절)보다
  1.9배 느리고(초당 3.2음절), 받침 음절을 실제(1.2배)보다 길게(1.6배) 만든다. 음절 단위 순위상관 0.30. 학습용 느린 속도로는
  받아들일 수 있어 앱은 바꾸지 않았다. 근거: `docs/engine-duration-check.md`.
- **표6-C1(데이터 유래 자모 유사도).** 공개 자원 1.2.0에서 첫 판(4화자, 거의 모든 쌍 0.99, 손코딩과 −0.19)을
  10화자 LDA 판(자음 120쌍·모음 153쌍, 손코딩과 0.30·0.22)으로 바꿨다. 세션 2에서 30화자로 다시 만든다.
  채점과 문항 선정에는 쓰지 않는다. 근거: `docs/korean-speechreading-resources.md`, `backend/data/c_jamo_similarity.json`.

## 축 E. 조음 교정

- **E-1(혀 역추정).** USC-TIMIT 영어 EMA 4화자로 음성→조음 역추정을 학습했다. 처음 듣는 화자 상관 r 0.448
  (혀 약 0.41). 언어가 달라(영어 조음) 제품에는 넣지 않았다. 제품은 웹캠으로 보이는 3차원(개구·원순·폐쇄) 교정,
  모음 포먼트 교정(E-2, LPC로 F1·F2 추정 후 목표 모음과 비교), 교정 세션 처음·끝 오차 기록(E-9)으로 대체했다.
  근거: `liplab-lab/notes/09-gpu-results.md`, `backend/formants.py`, `backend/articulation.py`.
- **E-8(재현성).** 사라진 AAI 학습 스크립트를 `liplab-lab/tools/train_aai.py`로 복원했다. 모델 구조는 체크포인트
  (`models/kr_e_aai_usctimit.pt`)를 strict로 읽어 확인했고(A4 헤드와 같은 구조, 출력 18채널), USC-TIMIT mview 형식 로더는
  합성 파일로 시험했다. 음성 백본·주기·하이퍼파라미터는 원본 값이 남아 있지 않아 복원 기준값이다. 다시 학습하려면
  파드에서 USC-TIMIT(8.5GB)를 받아야 한다.
- **표7-③ 정정.** "립리딩은 클라이언트 ONNX(영상이 기기 밖으로 나가지 않음), 조음 진단은 규칙 교정,
  AAI는 랩 실증"으로 고친다.

## 축 J. 시각 증강 기호

- **J-2(유성 대신 긴장).** 한국어 장애음은 평음·경음·격음의 3항 대립이고, 유성성은 평음이 유성음 사이에서
  울리는 변이음이라 뜻을 가르지 않는다. 그래서 기호는 기식(격음), 긴장(경음), 울림(비음)에 대응시키고 유성은
  따로 표시하지 않는다.
- **발음 모드.** 기호는 표준발음법을 거친 실제 발음에 붙는다(국물의 비음화, 먹고의 경음화). 186문장 중 63문장(34%)의
  기호가 표기 기준과 달라졌다. 기호가 붙는 음절 55.8%, 문장당 기호 수 상한 2개로 평균 1.99개. 근거: `docs/cue-overlay.md`.
- **J-3.** 단어·문장 퀴즈에서 답을 확인한 뒤(틀렸을 때 무엇이 달랐는지 보는 순간) 학습자의 약한 표적 입모양 음절에만
  기호를 입꼬리 옆에 겹치고, 숙달되면 흐려진다. 문제를 푸는 동안에는 보이지 않는다. 보기가 최소대립 짝이라 기호만
  보고도 답이 드러나기 때문이다(예: 물·풀·불은 비음·기식·없음으로 갈림). 표준검사와 문맥 추론 문항에도 넣지 않는다.

## 축 K. 입술 너머 얼굴 신호

- 비음 AUC 약 0.60~0.64(우연보다 높음), 유성 AUC 약 0.55(우연 수준)라 유성은 화면에 표시하지 않는다.
  미세 움직임 확대(EVM) 전처리는 +0.01에 그쳐 채택하지 않았다(K-8). 근거: `docs/k-facecue.md`.
