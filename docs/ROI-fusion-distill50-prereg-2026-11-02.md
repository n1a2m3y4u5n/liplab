# 50% ROI+입술80 결합 증류 개발 선택 사전 등록

2026-11-02 `spec-gpu-fill3.md`의 D다. 큰 결합은 seed0·1 개발 관문을 넘었지만, 작은38% 결합을 CTC만으로 처음부터 학습한 A는 미달했다. 이번 질문은 **큰 결합 선생의 두 입력 지식을 50% 결합 학생으로 증류**하면 정확도 개선과 경량화를 함께 유지하는가다. A의 결과를 뒤집지 않고, 새 방법을 seed0 한 번만 확인한다. **학습33/검증12 개발 선택, 판정 없음, 깨끗한 평가 대기**다. 앱·플래그·배포·푸시는 바꾸지 않는다.

## 구조·참조·데이터 고정

선생은 full fusion seed0 `model.pt`, SHA256 **42b5fc382377c3a6db4567a989d372b741d8b34504323956bd92bb58ed084c35**,6,068,989파라미터다. 다른 선생·시드를 고르지 않는다. 학생 ROI 경로는 C의 공개 `nextreg_distill50.build_student()` 그대로다: 정규화80×80→평균풀링40×40, stem16, 잔차24·48·96·192 각1블록, 선형256, LayerNorm256→양방향GRU2층 hidden276 dropout0.2→53자모. ROI3,030,525파라미터에 기존 full fusion과 같은 lips80→LayerNorm80→Linear64→GELU→Linear256 잔차21,984개를 더해 **3,052,509파라미터**다. 태그는 `fusion_distill50_roi256_lips80_kd_v1`로 분리한다. 학생은 seed0 무작위 초기값이며 선행 A·C·선생의 가중치로 초기화하지 않는다.

## C와 같은 증류·훈련

선생 eval/no_grad로 **train 역할 클립만** 한 번 읽어 최대400프레임의 겹치지 않는 창으로 나눈다. 중앙80자르기·원래 ROI z정규화와 같은 전역 프레임의 정규화 lips80을 함께 넣고53로짓을 float16 캐시한다. 끝 창은 실제 길이만 쓴다. 검증 역할에는 로짓을 계산하지 않고 캐시 영역을0으로 둔다. 역할별 캐시 수·선생/좌표/prep SHA를 기록한다. 캐시 float16은 목표 저장이며 ONNX 가중치 형식은 FP32다.

학생과 목표는 동일한 전역 프레임 번호로 재색인한다. 원래 B33 속도0.8~1.25·같은 화자 idle75 연결, 무작위80자르기·좌우반전0.5·최대3프레임 시간마스크를 유지한다. 좌표 반전은 같은 동전값과 점 대응+x부호 반전을 쓰며 시간마스크·패딩의 좌표 임베딩도0이다. 선생 목표는 깨끗한 두 입력, 학생은 증강된 두 입력인 일관성 증류이며 증강마다 선생을 재실행했다고 부르지 않는다.

손실은 C와 같은 **0.5×CTC + 0.5×T²×유효 프레임 평균 KL(softmax(teacher/T)||softmax(student/T)), T=2**다. CTC는 배치 항목 평균이다.4000프레임 미니그룹 바깥의 항목수/배치수 가중치를 KL 안에서 상쇄해 전체 배치 유효 프레임 평균을 보존한다. 패딩은 KL에서 제외한다. 배치·목표 문맥이 교차하지 않도록 동기로 읽으며, tuple의 ROI 장치/시간 차원을 사용한다. 합성 점검에서 전체 배치와 미니그룹 합의 KL 일치, train-only 캐시와 speed/idle 재색인·좌표 대응을 확인한다.

seed0 한 번, AdamW lr3e-4 wd1e-4, 배치32,4000유효 프레임 그룹, 최대40에폭,2에폭마다 검증, patience6회 미개선, 기울기5, idle0.5, **AMP0·CPU4스레드·black GPU cap0.92**를 고정한다. 체크포인트는 기존4지 hard ctc_ll α1·idle75·dup1/2 화자평균 평균의 최고값으로 선택한다. CER는 같은 체크포인트의 검증 문장 자모CER다. resume·추가 시드·구조/배치/상한 조정 재시도는 하지 않는다. OOM·기술 실패는 그대로 보고한다.

## FP32 두 입력과 동일 WASM
