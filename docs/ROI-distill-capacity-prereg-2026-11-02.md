## 같은 증류와 학습 규칙

앞선 작은 후보와 같은 증류 방법을 고정한다. 선생 eval/no_grad로 학습33명 clip만 한 번 순회하고, 각 clip을 최대400프레임의 겹치지 않는 창으로 나눠 중앙80자르기·원래 정규화의53로짓을 float16 캐시한다. 마지막 창은 실제 길이만 쓴다. 검증 clip에는 캐시를 만들지 않는다. 학생의 B33 프레임 번호·속도 변환·동일 화자 idle 연결로 목표도 재색인한다. 선생은 깨끗한 입력, 학생은 무작위 자르기·거울상·시간마스크 입력인 증강 일관성 증류다. 매 증강 입력에 선생을 재실행한 결과로 부르지 않는다. 캐시의 float16은 고정 교사 목표 저장이며 학생/선생 ONNX 가중치 저장은 FP32다.

손실은 `0.5×CTC + 0.5×T²×유효 프레임 평균 KL(softmax(teacher/T)||softmax(student/T))`, T=2다. CTC는 배치 항목 평균, KL은 배치 전체 유효 프레임 평균이다. 원래4000프레임 미니그룹의 외부 가중치를 상쇄해 KL의 배치 전체 평균을 보존한다. 패딩은 KL에서 제외한다. 목표와 입력 대응을 위해 동기 배치로 읽는다.

각 학생 seed0 한 번, AdamW lr3e-4 wd1e-4, 배치32, 그룹 상한4000프레임, 최대40에폭,2에폭마다 검증, patience6회 검증 미개선, 기울기5, idle0.5, 속도0.8~1.25·무작위80자르기·거울상0.5·시간마스크≤3, AMP0, CPU4스레드를 고정한다. 체크포인트는 원래 검증4지 dup1·2 화자평균의 평균 최고값(엄격한 개선)으로 고른다. 두 장치에서 구조와 cap 외 같은 규칙을 쓴다. 출력이 비어 있을 때만 시작하며 resume·추가 시드·배치/구조/상한 변경 재시도는 없다. OOM 또는 기술 실패면 그대로 보고한다.

## 한 번의 개발 선택과 최소 용량 규칙

각 학생 학습 종료 뒤 고정 선생과 선택 학생을 동일 B33 검증12명에서 한 번씩 비교한다. hard CTC likelihood α1, idle75, dup1·2 각각의 화자평균을 낸 뒤 두 평균의 평균을 쓴다. 미분할 문항을 버리지 않는다. CER는 같은 문장 전체의 보조 보고이고 별도 관문을 추가하지 않는다.

각 학생이 다음을 **모두** 만족해야 통과한다.

1. 검증4지 학생−고정 선생 ≥−0.02.
2. 같은 FP32/opset17 학생 ONNX 바이트 ≤선생 ONNX의40%.
3. 같은PC·같은입력 CPU WASM 학생 중앙시간 ≤선생의50%.

## 동일 ONNX와 WASM 측정

각 선생/학생을 FP32·opset17로 내보낸다. 입력 원화소 범위 float32 `[B,T,80,80]`, 출력 `[B,T,53]`, 내부 정규화는 학습과 같다.75프레임 합성 입력에서 PyTorch 원경로↔wrapper와 wrapper↔ONNX CPU 로짓 최대차이<1e-3를 기술 유효성 조건으로 확인한다. 통과하지 못하면 정확도만으로 배포 가능한 후보라 하지 않는다. 이 확인은 검증 화자 재판정이 아니다.

WASM은 lab-sub CNSAI2025의 설치된 onnxruntime-web1.19.2, Node24, WASM CPU EP1스레드에서 선생/학생 두 세션을 미리 만들고 측정한다. 입력은 PRNG xorshift seed20261102의 동일 `[1,75,80,80]` 정수0~255 float32로 실제 평가 클립을 쓰지 않는다. 모델당5회 예열, 선생→학생/학생→선생 순서를 번갈아20쌍의 `session.run` walltime만 잰다. 로딩·입력 생성·출력 유효성 검사는 타이머 밖이다. 각20회 중앙값 비율로 판단하며 원시 시간·PC/CPU·ORT/Node버전·입력/모델 SHA를 보존한다. **25% 비교 다음38% 비교의 고정 순서**로 각각 한 번 측정한다. KMSAV CPU 작업을 중단하지 않는다. 타 PC·native ORT 시간·더 유리한 재측정으로 대체하지 않는다. Android 실측 주장을 하지 않는다.
