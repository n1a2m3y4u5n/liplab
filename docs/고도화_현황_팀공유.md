계획서 「멀티모달 발음·독화 평가를 중심으로 한 LIPLAB 고도화」의 축 A~K 중,

## 📋 지금 팀이 준비할 것 (코드 아님, 사람 몫)

1. **염우진** — AI Hub 가입 + 휴대폰 인증 → OLKAVS 신청 (승인 즉시, 다운로드 TB 주의).
   샘플은 이미 받아 전처리 검증 완료 ([데이터 조사](lipreading-data-research.md))
2. **GPU** — 무료 **Kaggle**(주 30h) / **Colab**로 시작, 무거운 학습만 **RunPod RTX4090**(~$200, 보호자 카드).
   **H100 불필요** — 전체 실험 실지출 $150~350 예상
3. **최윤건** — 아바타용 3D 자산(Character Creator) 제작
4. 농인 파일럿 · 언어재활 자문 섭외 (검증 필수, 리드타임 김)
5. **배포** — 결정 시 새 fly 앱(새 링크)으로. 기존 전시용 `liplab.fly.dev`는 유지
