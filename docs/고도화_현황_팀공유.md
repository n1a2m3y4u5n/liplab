## 1. 이번 통합과 9/24·9/25 추가

- **9/25 오후: 발음 채점 모델을 int8로 줄여 개발 서버를 다시 4GB 기계로.** 가중치만 int8로 두고 계산은 그대로 해서, 학습 전에
  적은 다섯 조건(재검 관문 재현, 538·608 점수 일치, CPU 경로, 호스팅 메모리)을 모두 통과했다. 점수 차는 평균 0.2~0.4점,
  메모리는 최대 3.15GB(fp32 4.3GB). 배포는 아직 하지 않았다.
- **9/25 오후: 제품 립리딩 모델 교체는 새 화자로도 관문 미달.** P2 모델과 후보 로그우도 채점을 함께 쓰는 조합을 처음 보는
  12명으로 쟀더니 23.9% → 28.3%(+4.4점, 관문 +5점). 제품은 그대로 두었다. 채점 방식만 바꾸는 더 작은 변경을 새로 등록해
  다른 화자로 확인하는 중이다.
- **9/25 오후: 음소 점수는 한두 음절 자음 바꿈을 잡는다.** 문장 점수로는 못 거르던 ㅁ↔ㅂ·ㄴ↔ㄷ 바꿈을 자체 모델의 초성
  점수는 깨끗한 발화에서 AUC 0.99로 가른다(가장 낮은 초성이 바꾼 자리인 비율 93%). 저하가 크면 약해지므로 상대 순위로만 보이자.

- **9/25: 발음 채점 모델을 직접 학습했다.** 팀원 체크포인트는 옛 채점식 기준이라 쓰지 않고, 같은 레시피로 채점기·정렬기를
  공개 자료(Zeroth)로 다시 학습했다(RunPod A100 약 3시간). 학습 전에 적은 관문에서 1차(538 10화자)는 강도 순서 +2.7%p
  [0.0, 5.7]로 경계에서 떨어졌고, 1차 뒤 등록한 독립 재검(새 20화자)은 +3.8%p [2.3, 5.5]로 통과했다. 실제 청각장애 발화의
  정상 대비 분리도는 0.892에서 0.933으로 올랐다. 그래서 개발 서버 채점 모델을 자체 모델로 바꿨다(배포 전, `docs/scorer-selftrain.md`).
- **9/25: 608 실제 청각장애 발화를 확보했다.** 감음신경성 27명 669문장. 전사 오류 0.66(정상 0.19), D-GOP 38(정상 80)로
  합성 경과 중 사이에 놓인다(그림 7). 자기지도 음성변환(kNN-VC)으로 만든 발화는 실제 발화를 규칙 합성보다 덜 닮아 부정 결과로 남긴다.
- **9/25: 배포 전 점검에서 결함 하나를 고쳤다.** 새로 빌드하면 SQLAlchemy 2.1이 들어와 greenlet이 빠지고 서버가 뜨지 않았다
  (`sqlalchemy[asyncio]`로 수정, 지금 떠 있는 전시앱은 옛 이미지라 영향 없음).

- 두 브랜치(`feat/content-scale`, `feat/sublexical-feedback`)를 새 통합 브랜치로 합쳤다. 원래 브랜치는 그대로 두었다.
  발음 채점식은 팀 표준(naive D-GOP), 화면은 Figma 디자인, 촉각 기능은 뺐다.
- 9/24 추가: 공용 음성 백본 서비스(A-9), 음소별 소리·입모양 융합(B-5·B-6)과 비음 보조(K-5), VocalTractLab 성도 단면(E-6),
  교사용 인쇄 결과지(I-9), 화자별 얼굴 목록(H-6), 공개 자원 1.3.0과 배포 묶음(C-8), 파일럿 준비(결함 수정과 문서 7종),
  실제 영상 위 기호 연구용 페이지 `/lab/cue-video`(J-9), GPU 사용 원장(4.2-6), 1구간 점검점 초안(`docs/checkpoint-2026-09.md`),
  콘텐츠 월간 루틴 초안(`docs/content-routine.md`).
- **D-GOP 정렬 결함을 찾아 고치고 다시 쟀다.** kresnik 모델의 CTC blank는 `[PAD]`인데 정렬이 id 0 음절 '볍'을 blank로 썼다.
  고친 뒤 538 원점수는 원본 80.2·경 49.6·중 26.7·심 5.8(예전 16.4·9.1·5.3·2.1), 강도 순서 95.7%, 전사 정확도와 0.986이다.
- 개발 서버(liplab-dev) 서버 추론 설정을 배포 전에 파드에서 점검했다. 9/25 자체 모델 설정은 fp32로 최대 메모리 5.0GB였고,
  오후에 int8로 3.15GB가 되어 4GB 기계로 되돌렸다. 맞는 문장 88~93점·다른 문장 45~48점(합격선 65 미만). 배포는 아직 하지
  않았다(`DEPLOY.md` 9항).
- 테스트: 백엔드 249개, 프론트 72개 통과, 프로덕션 빌드 통과.
