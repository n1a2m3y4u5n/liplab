## 1. 이번 통합과 9/24 추가

- 두 브랜치(`feat/content-scale`, `feat/sublexical-feedback`)를 새 통합 브랜치로 합쳤다. 원래 브랜치는 그대로 두었다.
  발음 채점식은 팀 표준(naive D-GOP), 화면은 Figma 디자인, 촉각 기능은 뺐다.
- 9/24 추가: 공용 음성 백본 서비스(A-9), 음소별 소리·입모양 융합(B-5·B-6)과 비음 보조(K-5), VocalTractLab 성도 단면(E-6),
  교사용 인쇄 결과지(I-9), 화자별 얼굴 목록(H-6), 공개 자원 1.3.0과 배포 묶음(C-8), 파일럿 준비(결함 수정과 문서 7종).
- **D-GOP 정렬 결함을 찾아 고치고 다시 쟀다.** kresnik 모델의 CTC blank는 `[PAD]`인데 정렬이 id 0 음절 '볍'을 blank로 썼다.
  고친 뒤 538 원점수는 원본 80.2·경 49.6·중 26.7·심 5.8(예전 16.4·9.1·5.3·2.1), 강도 순서 95.7%, 전사 정확도와 0.986이다.
- 테스트: 백엔드 241개, 프론트 64개 통과, 프로덕션 빌드 통과.

## 3. 데이터와 GPU

- 538: 30화자 900클립 확보. 608: TS02를 끝까지 받았으나 라벨로 고른 세션이 TS02에 없어 0개, 범주 28만 골라 다시 받는 중
  (TS02의 범주 28 wav는 deflate 압축이라 풀기를 더했다. 직후 재시작은 서버가 끊어 한 시간 쉬고 다시 받는다).
- RunPod: 세션 2(A2·D v2·C30)·세션 3(D-GOP 재측정, 융합 검증, D-7) 끝나 파드 종료. 세션 4(조음 역추정 mm 오차) 진행 중,
  608이 오면 세션 5(608 측정·kNN-VC). 잔액 약 $19.8.

## 4. 공개 전에 정해야 할 것

- 개인정보 보호책임자 이름·연락처(처리방침에 비어 있음)
- 파일럿: 참여 코드·집단·기호 없는 집단, 연구 윤리 절차, 보관 기간, 가명 비밀키(`LIPLAB_PILOT_SECRET`). 순서는 `docs/pilot/checklist.md`
- 공개 빌드에서 전 단계 열기(`LIPLAB_UNLOCK_ALL`)를 끌지
- 공개 자원 게시 채널(저장소·Zenodo)과 저자 정보, AI Hub 유래 자모 유사도 재배포 가능 여부
- AI Hub 데이터는 재배포할 수 없어 앱 데모에는 쓰지 않는다(예시 음성은 합성 음성)
