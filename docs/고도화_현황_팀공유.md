## 🔬 데이터로 검증 중 (지금 백그라운드 실행)

노트북 로컬 compute로 진행(mediapipe=conda `liplab`, torch=임시 venv). **RunPod 불필요, 크레딧 $25 보존.**

- **B 실증** — 정상(538) vs 비정형/농인(608) ASR CER 비교로 "전사 종속 채점이 비정형 발화서 붕괴" 실증.
- **D 화자확대** — 신규 30화자(OLKAVS) 재다운·컷·추출→ 교차화자 단어 top-1이 기존 7% 넘는지.
- **A4 백본 스왑** — 같은 데이터로 동결 백본 kresnik→WavLM-large 교체 시 jawOpen r 상승 여부(오디오 표현이 천장인가).

## 🧱 데이터로 안 뚫리는 축 — 실제 벽과 방향 (실험으로 확인)

| 축 | 벽 | 방향 |
|---|---|---|
| **A** | 동결 백본이 천장(화자 8→23 r 0.675→0.588). 진짜 농인 데이터 부재 | 데이터 아닌 **백본 교체**가 유일 레버(실험 중). r=0.675면 출시 가능 |
| **E** | 한국어 조음(EMA/rtMRI) 공개셋 부재, 영어 AAI는 언어 불일치(r≈0.41) | **규칙 조음교정+성도 시뮬로 이미 해결.** ML은 접는 게 정답 |
| **C** | 데이터 시각유사도 ≠ 손코딩 음운유사도(비교 잣대가 다름) | **음운=규칙, 시각혼동=데이터** 각자 사용(구현됨). 대체 시도가 실수였음 |
| **K** | 유성성은 후두에서 나 얼굴에 신호 없음(AUC 0.55=찍기) | **비음만 실사용 + 정직 표기.** 유성은 접거나 EVM(고비용·저수익) |

정직한 천장 명시가 리포트 신뢰도를 높인다(negative result는 연구의 강점).
