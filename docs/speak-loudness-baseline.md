# 말하기 0·1단계 크기·발성 판정: 기기 기준선과 음높이 발성(2026-09-29, 측정 전 사전 등록)

## 문제

- 크기: 0단계(발성)와 1단계 '크게'·'작게'는 자동 음량 조절(AGC)을 끈 채 유성 프레임 평균 RMS로 크기 = (평균 RMS − 0.01) / 0.13 × 100을
  내고 절대 문턱(발성 22, 크게 60, 작게 12~45)으로 판정한다. 같은 목소리도 마이크 감도와 입과의 거리에 따라 몇 dB씩 달라지므로
  판정이 기기에 달려 있다(예: 크기 40 목소리가 −6dB 기기에서는 약 18로 발성 불합격).
- 발성: 발성 구간은 RMS > 0.01인 표본이라 속삭임·숨소리도 '소리를 이어 냈다'로 센다.

## 설계(R)

녹음 루프 표본(약 67ms마다 42.7ms 버퍼의 RMS와 음높이)으로 판정한다.

- 잡음 바닥 F: 처음 0.3초 표본 RMS 중앙값과 전체 표본 RMS 10백분위 가운데 작은 값(말을 바로 시작해도 바닥이 말소리가 되지 않게),
  하한 0.0005.
- 유성 표본: RMS ≥ 2F(바닥 +6dB)이고, 버퍼를 최댓값 0.5로 맞춘 뒤 `lib/pitch.js`와 같은 자기상관으로 70~500Hz 주기를 찾았고,
  그 주기에서 정규화 상호상관(선명도)이 θ 이상. 속삭임·숨소리는 주기가 없어 선명도가 낮다.
- 이어 낸 발성 길이 Dv: 유성 표본이 끊김 0.15초 이내로 이어진 가장 긴 구간(`lib/voicing.longestVoicedRun`과 같은 규칙).
- 크기 L: 유성 표본 RMS 중앙값(dBFS). 신호 대 잡음 SNR = L − 20·log10(F).
- 0단계 합격: Dv ≥ 1.2초이고 SNR ≥ 12dB. 합격한 0단계 시도의 L을 기기별(마이크 deviceId)로 브라우저 저장소에 최근 5개까지 두고,
  2개 이상이면 그 중앙값이 기준선 B다(저장소를 못 쓰면 기준선 없음).
- 1단계(기준선이 있을 때): '크게'는 L ≥ B + 6dB, '작게'는 B − 18dB ≤ L ≤ B − 6dB이고 둘 다 Dv ≥ 0.3초(속삭임은 '작게'가 아니다).
  기준선이 없으면 지금 절대 규칙 그대로. 넣게 되면 '작게' 문항 안내의 '속삭이듯'은 '목소리는 내면서'로 바꾼다.
- '길게'는 Dv ≥ 2초.

## 측정(파드, 앱 루프를 파이썬으로 옮김)

- 자료: 538 문장 클립 1,740개(화자 해시 절반 0은 θ 탐색, 절반 1은 확인), 608 평서·의문 대본 문장 자르기(`docs/sentence-intonation.md`
  608 절과 같은 자르기, 범주 27·28·32). 합성 신호: 속삭임 '아'(백색 잡음 → 포먼트 750·1200·2600Hz 공명기), 숨소리(200~2000Hz 대역
  잡음, 느린 들숨·날숨 포락선), 비교용 유성 '아'(성문 펄스열 90~260Hz, 흔들림 1%, 기식 잡음 섞음). 각 200개, 길이 1.5~3초, 크기
  −45~−12dBFS, 앞 0.4초 잡음만(−65dBFS). 시드 0은 탐색, 시드 1은 확인.
- 크기 변화: 파일 그대로(0dB)와 −12·−6·+6dB(+6은 ±1에서 잘림).
- 모음 구간: 표본 가운데 ±2표본(±133ms) 안 최댓값의 −6dB 이내이면서 클립 최댓값의 −20dB 이상인 표본(음절 핵, 대개 모음).
- 기준선 흉내: 같은 화자·같은 크기 변화에서 Dv ≥ 0.3초인 클립들의 L 중앙값.
- θ 정하기(탐색): {0.3, 0.4, 0.5, 0.6, 0.7, 0.8} 가운데 538 절반 0 모음 구간 유성 비율이 0.90 이상인 가장 큰 값(없으면 0.3).
  합성 시드 0의 속삭임·숨소리 통과율은 함께 적기만 한다.

## 확인 기준(θ를 고정한 뒤)

- C1 크기 불변: 538 절반 1과 608 각각에서, (클립 × 크기 변화 3개 × 판정 3개[0단계 합격, '크게' 합격, '작게' 합격])가 0dB 판정과 같은
  비율 ≥ 0.95. 지금 규칙의 같은 비율도 함께 적는다.
- C2 속삭임·숨소리: 합성 시드 1의 속삭임·숨소리 400개 가운데 0단계 합격 비율 ≤ 0.05(지금 규칙도 함께 적는다).
- C3 청각장애 발성의 음높이 검출: 608 모음 구간 표본 가운데 유성으로 잡힌 비율 ≥ 0.80(표본 전체, 화자별 분포도 적는다).
