# BS27+lips80 작은 CTC 개발 후보 (2026-11-02, 실행 전)

목적은 브라우저에서 이미 얻을 수 있는 정규화 입술 좌표를 추가하는 개발 경로를 계속할지 정하는 것이다. 코디네이터 승인에 따라 BS27 기준선과 BS27+lips80 후보를 같은 분할로 새로 학습한다. 결과는 **검증 12명 선택, 판정 없음, 깨끗한 평가 대기**다. 앱은 바꾸지 않는다.

자료: train538의 기존 split 학습33·검증12만. 평가19·clean_eval·E2·KMSAV·OLKAVS 사전학습은 사용하지 않는다. 기존 ROI run_base prep에 허용된 학습·검증 클립 이름 목록으로 입력을 먼저 제한해 같은 문장 제외 규칙을 유지한다. 기존 spans.jsonl은 화자/클립 메타로 먼저 거르고 해당 BS JSON만 연다. 평가 화자의 프레임·음성·점수는 읽지 않는다. subset bench는 기존 d_bench build rule3,3으로 새로 만들며 두 조건이 같은 어휘·문항·구간·분할을 공유한다. 검증 화자가 이미 여러 선택에 쓰였음을 명시한다.

BS27은 기존 MOUTH_KEYS, 좌표80은 JSON lips(40점 xy, 눈꼬리 거리 정규화·회전 보정)다. d_bench의 기존 재색인·결측 보간을 사용한다. 좌표 유효 프레임이 전체의80% 미만인 클립은 두 조건 모두 제외한다. 클립의 앞뒤 큰 결손은 기존 bench 규칙대로 처리한다. 결측률·클립 수·화자 수·어휘 수·input sha를 보고한다. 후보만 유리한 문항을 남기지 않는다.

두 모델 모두 train_lipread.build(n_in,53)의 LayerNorm→BiGRU3층256 CTC, seed0, AdamW lr3e-4 wd1e-4, 배치64, 최대40에폭, 2에폭마다 검증, patience6, 기울기5, idle0.5. 기존 B 후보의 문장+어절 학습, 75프레임 idle 창, 속도0.8~1.25·거울상·최대3프레임 마스크를 공유한다. BS채널은 기존 이득0.9~1.1·잡음σ0.01, 좌표는 기하를 보존하기 위해 이득·독립 잡음을 추가하지 않고 속도·거울상(점 대응+x부호 반전)·시간마스크만 공유한다. 입력 차원 외 모델·학습 설정은 같다. 초기화 RNG는 각 실행 seed0으로 재설정한다.

주 개발 지표는 검증 4지 hard ctc_ll α1, idle75, dup1·2 화자평균의 평균이며 체크포인트도 그 값으로 고른다. 후보−기준 ≥+0.03이고 검증 문장 자모CER 후보−기준 ≤+0.02일 때만 좌표 경로를 후속 깨끗한 평가 후보로 남긴다. 그렇지 않으면 이 입력·모델의 경로를 포기한다. 두 모델 한 시드씩만이며 추가 시드·목표/문턱 변경은 하지 않는다. V-verify의 목표 검증 AUC나 새 평가 성능을 이4지 지표로 대체했다고 주장하지 않는다. 10/17 V-verify AUC0.712 미달은 그대로다. 통과해도 별도 목표검증 등록과 독립 확인이 필요하다.

CPU 준비는 lab-black, 학습은 B33s0 종료를 확인한 lab-black GTX1080에서 한 모델씩. CPU4스레드, 1080은 AMP를 쓰지 않으며 배치가 메모리를 넘으면 같은64배치의 기울기를 누적해 평균을 보존한다. GPU가 다른 학습에 쓰이면 대기하며 다른 프로세스를 중단하지 않는다. 예약 작업S4U로 연결 독립 실행, GPU 시작 시각과 PID를 보고한다.
