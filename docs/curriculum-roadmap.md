# 커리큘럼 개선 계획 (2026-09-28)

9/28 커리큘럼 평가에서 나온 문제를 고치는 순서와 방법이다. 각 항목에는 해소하는 문제, 설계, 검증 기준, 선행 조건을 적는다.
검증 기준은 결과를 보기 전에 여기 적고, 탐색은 시드 0 또는 화자 절반 0, 확인은 시드 1 또는 절반 1로 한다(지금까지와 같은 사전 등록 방식).

## 0. 평가에서 나온 문제 (요약)

| 번호 | 문제 | 근거 |
|---|---|---|
| P1 | 한 개의 규칙 기반 합성 얼굴로만 훈련하고 평가해 실제 화자로의 전이가 불확실하다 | 고변이 훈련(Logan, Lively & Pisoni 1991), 독화 훈련 전이 검토(Bernstein 외 2022) |
| P2 | 분석 훈련(입모양·단어)을 끝내야 종합 과제(문맥·문장)가 열린다 | Walden 외(1977), Rönnberg ELU 모형 |
| P3 | 1·2단계가 모두 선다형(폐쇄형)이다 | 폐쇄형 훈련의 개방형 전이 제한 |
| P4 | 감속 재생에서 얻은 정답도 숙달에 그대로 들어가 자연 속도 숙달을 확인하지 않는다 | |
| P5 | 되묻기·환경 조정 같은 의사소통 전략 훈련이 없다 | 성인 청각 재활 프로그램(Hickson 외 2007) |
| P6 | 말하기 채점이 청각장애 화자에게 불리하다(전사 경로 맞게 말함 불합격 18~20%, 정상 0.4%) | `docs/speak-transcript-scoring.md` |
| P7 | 말하기 3단계 자음에 마찰음·파찰음·성문음(ㅅ ㅆ ㅈ ㅊ ㅉ ㅎ)이 없다. 청력 손실 발화에서 가장 흔히 무너지는 고주파 소리다 | `speak_curriculum.py` 3단계 9문항 |
| P8 | 말하기 피드백이 매 시도 즉시이고 적은 항목을 차례로 반복한다(습득에는 유리, 유지·전이에는 불리) | 운동학습 원리(Maas 외 2008) |
| P9 | 말하기 숙달이 단일 항목 점수라 의미 있는 말 속에서 쓰는지(음운 수준) 확인하지 않는다 | Ling(1976) |
| P10 | 학습자의 청력 손실 시기·보조기기·수어 사용을 고려하지 않고 모두 같은 경로를 밟는다 | 집단 이질성 |
| P11 | 독화가 소리 없이 시각으로만 제시된다(보청기·인공와우 사용자의 실제 조건과 다름) | Summerfield(1992) |
| P12 | 사전·사후 검사가 훈련과 같은 얼굴·같은 형식이라 전이를 재지 못한다 | 구성적 정렬(Biggs) |

## 1단계: 코드만으로 바로 (진행 중인 작업 포함)

### 1-0 진행 중
- 혼동 짝 출제(2단계): 사전 기준 미달로 구현하지 않음(9/28, 5a48d41). 오답 기록으로 짝을 찾는 재현율이 5~8%라 병목이다. 짝을 안다면
  57~62% 단축. 다음은 시행마다 보인 보기를 기록하고 짝 확인 문항을 섞는 것(`docs/confusion-pair-serving.md` 5.4절).
- D-GOP 청각장애 발화 측정: 끝남(9/28). 2-1 판정은 아래. 포먼트 혀 교정 검증은 파드에서 진행 중.

### 1-1 속도 조건을 숙달에 반영 (P4)
- 설계:
  - 답마다 재생 속도(학습자 선택 × 적응 감속)를 기록한다.
  - 1.0배 미만에서 얻은 정답은 숙달 추정에 성공 0.5로 넣는다. 편향 보정 이동 평균이 0~1 값을 받도록 넓힌다.
  - 숙달한 단계에는 1.25배 '빠른 말' 레벨을 연다(엔드리스·복습).
- 검증(가상 학습자 시뮬레이션, `scripts/mastery_sim.py` 모형 확장):
  - 모형: 감속 시 정답 확률이 자연 속도보다 높다.
  - 거짓 숙달은 자연 속도 정답 확률이 0.65 미만인 시점의 숙달 판정으로 본다. 이 비율이 지금 규칙보다 낮아야 한다.
  - 감속을 쓰지 않는 학습자의 숙달 지연 중앙값은 지금보다 3번 넘게 늘면 안 된다.
  - 두 조건을 모두 만족할 때만 채택한다.
- **결과(9/28, e1d145a): 채택.** 감속 정답 0.5만 쓰면(C1) 감속이 줄지 않는 학습자의 43%가 200번 안에 숙달하지 못해, 보호 지표
  (감속 학습자 숙달 비율 5%p 넘게 하락 금지)를 더해 '숙달 추정 70 이상이면 적응 감속을 끄는' C2(70)을 골랐다. 시드 1 확인에서
  거짓 숙달 10.6 → 4.9%(최소 8번, 감속 방식 A), 감속 안 하는 학습자 지연 27 → 27번, 보호 지표 96.6%로 네 경우 모두 통과.
  2단계에 `speed` 기록·0.5 반영, 엔드리스 단어·오늘의 복습에 1.25배 '빠른 말'. 1단계는 속도 조절이 없어 1.0배, 3단계는 모형이 달라
  넣지 않았다(`docs/mastery-ewma.md` 7절).

### 1-2 개방형 문항 도입 (P3)
- 설계:
  - 2단계 숙달 뒤 레슨의 30%를 주관식(단어 입력)으로 낸다.
  - 3단계는 숙달 추정 50 이상이면 선다형과 주관식을 반씩, 70 이상이면 주관식만 낸다.
  - 입모양이 똑같은 다른 말을 쓰면 '입모양은 맞음'으로 부분 점수와 안내를 준다. 오답으로 보지 않는다.
- 검증:
  - 채점 규칙 단위 테스트(정답, 같은 입모양 다른 말, 다른 입모양, 빈 답, 띄어쓰기·받침 오타).
  - 숙달 판정은 주관식 정답을 선다형 정답과 같게 센다(우연 수준이 더 낮아 거짓 숙달이 늘지 않는다).
- **결과(9/28, a43c983): 구현.** 2단계 숙달 뒤 12문항 중 4문항 주관식. 채점(`visual_difficulty.typed_word_verdict`)은 한글 음절만
  남겨 비교(띄어쓰기·문장부호 무시), 정답 1, 입모양이 똑같은 다른 말 0.5와 안내, 그 밖 0. 받침 오타는 따로 봐주지 않고 입모양
  규칙을 따른다(값/갑 0.5, 밥/반 0). 시행 기록은 `word_typed`. 3단계는 지금 이미 주관식·서술형이 2/3라 '반반'을 글자대로 하면
  선다형이 늘어서, 50 미만 지금 그대로(선다형 약 1/3), 50~70 선다형 문장 6개마다 1개, 70 이상 주관식·서술형만으로 옮겼다(`lib/openSet`).

### 1-3 분석·종합 섞기 (P2)
- 설계: 2단계 레슨 12문항 중 2문항을 문맥 문항으로 바꾼다. 목표 단어가 짧은 문장 안에 있고, 보기는 같은 입모양 무리 단어다.
- 문맥 문항의 답은 2단계 숙달에 넣지 않고 학습 기록과 지식추적에만 넣는다. 잠긴 단계의 답은 숙달에 넣지 않는다는 원칙을 따른다.
- 선행: 혼동 짝 작업과 같은 파일(`visual_difficulty.stage2_plan`, `WordStage.jsx`)을 고치므로 에이전트 병합 뒤에 한다.
- **결과(9/28, b0f0b3c): 구현.** 기존 문맥 추론 문항 풀(`_training_closures`, check_closure 통과·사람 감수 제외·보기 3개 이상)이
  맞아 새로 만들지 않았다. 12문항 중 2문항(첫 문항 제외), 최근 14일 안에 푼 적 없는 문항 먼저. 답은 `/api/curriculum/context-answer`로
  시행 기록(stage 2, `context`)과 취약 입모양에만 남고 2·3단계 숙달에는 들어가지 않는다. 3단계 문맥 추론도 여기서 푼 문항을 뒤로 보낸다.
  `stage2_plan`은 바꾸지 않았다.

### 1-4 대화 되묻기 (P5)
- 설계: 4단계 대화의 AI 턴에 버튼 세 개를 둔다.
  - '다시': 같은 속도로 한 번 더
  - '천천히': 0.7배
  - '다른 말로': 같은 뜻을 다른 문장으로 바꿔 줌. LLM 한도(`llm_budget`) 안에서 쓰고, 한도를 넘거나 실패하면 '천천히'로 대신한다.
- 한 턴에 두 번까지는 이해도 점수에서 빼지 않는다. 되묻기 횟수는 학습 기록에 남긴다.
- 말하기 5단계의 '천천히 말해 주세요.', '다시 한 번요?'와 문구를 맞춘다.
- 대화 시작 전에 전략 카드 한 장을 보여 준다(되묻기, 자리·조명 조정, 상대에게 입을 보여 달라고 부탁하기).
- 검증: 기능 테스트, LLM 한도 소진 시 대체 동작 테스트.

### 1-5 말하기 자음 확장 (P7)
- 설계: 3단계에 사·싸·자·차·짜·하를 추가하고, 대립 짝(사/다, 자/차)을 둔다.
- 선행 검증(파드, 538 정상 화자):
  - 해당 자음이 든 맞게 말한 클립을 목표 자음만 바꾼 문장(ㅅ→ㄷ, ㅈ→ㅊ 등)에 대고 채점한다.
  - D-GOP가 그 음소에서 대치를 가려내는지 음소 단위 AUC로 잰다.
  - AUC 0.80 이상인 자음만 넣는다. 못 가리는 자음을 넣으면 틀린 피드백을 주게 된다.

## 2단계: 파드 측정 결과를 받아서

### 2-1 말하기 합격선·숙달 문턱 재설정 (P6)
- 입력: D-GOP의 538(정상)·608(청각장애) 점수.
- 합격선: 538에서 다른 문장을 말했는데 합격하는 비율(잘못 합격)을 5% 이하로 지키는 범위 안에서, 608에서 맞게 말했는데 불합격하는 비율(잘못 불합격)이 가장 낮은 값으로 정한다.
- 숙달 문턱: 608에서 맞게 말한 발화의 기대 합격률에서 5점을 뺀 값을 넘지 않게 한다. 기준을 잘 지킨 학습자도 닿지 못하는 문턱을 없애기 위해서다.
- 대체 규칙: 가능한 합격선에서도 잘못 불합격이 10%를 넘으면 4·5단계 숙달을 개인 기준선 방식으로 바꾼다.
  - 첫 10번의 중앙값 대비 15점 향상 또는 절대 기준 가운데 먼저 닿는 쪽을 쓴다.
- 탐색은 화자 절반 0, 확인은 절반 1로 한다.
- **결과(9/28): 합격선 65 유지(56은 확인 절반에서 538 오합격 10%로 실패), 4·5단계 숙달 90·85 → 77, 개인 향상 경로 추가.**
  근거와 수치는 `docs/speak-transcript-scoring.md` 'D-GOP 결과' 절.

### 2-2 조음 변이와 가상 화자 (P1)
- 설계:
  - 아바타 한 얼굴 안에서 레슨마다 다음을 바꾼다.
    - 말 속도(0.85~1.25배)
    - 입 벌림 폭(0.8~1.2배)
    - 입술 폭·돌출 배율
    - 동시조음 강도
    - 프레임 타이밍 흔들림
  - 이 값의 묶음을 가상 화자 6명으로 만든다. 4명은 훈련용이고 2명은 검사 전용으로 남긴다(2-3).
- 변이 폭 보정:
  - 파드에서 538 영상의 입 랜드마크(MediaPipe)로 입모양 무리별 화자 간 입 벌림·폭의 변동계수와 음절 속도 분포를 잰다.
  - 저장소에는 요약 통계(수십 개 숫자)만 넣는다. 원자료는 넣지 않는다.
  - AI Hub 유래 파생값이라, 공개 저장소의 AI Hub 유래 파일 건과 함께 사용자 확인을 받는다. 확인 전에는 문헌값으로 폭을 정한다.
- 검증:
  - 변이된 입모양이 다른 무리 중심보다 자기 무리 중심에 가까워야 한다(10무리 모두, `perceptual_space`).
  - 변이 폭이 538 화자 간 분포의 10~90 백분위 안에 들어야 한다.

### 2-3 전이 조건 사후 검사 (P12)
- 사후 검사(B형)를 두 조건으로 본다.
  - 기본 얼굴 1.0배
  - 검사 전용 가상 화자 1.0배
- 학습 효과 리포트에 '새 화자 조건 향상도'를 따로 보인다. 실제 사람 전이(3-3)가 생기기 전까지 쓰는 근거리 전이 지표다.

### 2-4 말하기 피드백 줄이기와 섞기 (P8)
- 설계:
  - 한 항목을 두 번 연속 합격하면 그 항목은 세 번마다 요약 피드백으로 바꾼다.
  - 0~3단계는 첫 합격 뒤 항목 순서를 무작위로 한다.
- 검증: 사용자 없이 효과를 잴 수는 없다. 지표로 복습(6일 뒤) 말하기 합격률을 기록해 두고 도입 전후를 비교한다.
- **결과(9/28): 섞기만 구현, 피드백 줄이기는 하지 않음.**
  - 섞기(8798f61): 2·3단계는 항목 수만큼 연습한 뒤로 (사용자, 날짜) seed로 순서를 섞는다(`speak_curriculum.interleaved_order`).
  - 피드백 줄이기는 구현하지 않았다. 청각장애 학습자는 자기 말소리를 귀로 확인하기 어려워 외부 피드백이 주된 피드백 원천이다.
    피드백 빈도를 줄이면 유지가 낫다는 운동학습 결과는 주로 청력이 정상인 화자에서 나와 그대로 옮겨진다고 보기 어렵다.
    매 시도 점수를 그대로 두고, 사용 기록(복습 합격률)이 쌓이면 다시 본다.

### 2-5 음운 수준 확인 (P9)
- 설계:
  - 3단계 자음 숙달에 조건을 더한다. 그 자음이 든 4단계 단어 3개 중 2개 이상을 합격해야 한다.
  - 2단계 모음도 같은 방식으로 확인한다.
- 검증: 숙달 시뮬레이션에서 숙달 지연 증가를 재고, 추가 확인 문항이 레슨 수를 20% 넘게 늘리지 않게 한다.
- **결과(9/28, 0c0f4b0): 구현, 규칙은 확인 4개 중 3개.** 이동 평균이 문턱에 닿으면 4단계 단어 풀에서 목표 소리가 첫 음절에 든
  낱말 4개(서로 다른 소리, 약한 소리 먼저)를 단어 규칙(합격 65)으로 확인하고, 최근 4번 중 3번 합격해야 숙달한다. 설계안 5개 중 4개는
  숙달까지 시도가 27~28% 늘어 기준을 넘었고, 4개 중 3개는 18%(시드 0)·20%(시드 1)였다. 거짓 숙달은 1.7 → 0.7%로 줄었다
  (`docs/mastery-ewma.md` 8절). 채점기가 낮게 보는 화자는 넘기 어려워, 건너뛰기로 다음 단계를 열 수 있게 두고 사용 기록으로 다시 본다.

### 2-6 학습자 정보 기반 기본값 (P10)
