# 주장 원장 초안(O8)과 분석 계획 사전 등록 초안(O1)

> **초안이다. 아직 등록하지 않았다.** 사용자가 7절의 결정을 내린 뒤 이 문서를 고쳐 OSF에 등록한다(idea-sweep 가2의 등록 기한
> 10월 15일). 등록 전에는 이 문서의 문장을 보고서·발표에 쓰지 않는다. 등록한 뒤 바꾸면 바꾼 날, 이유, 결과를 보기 전인지를 적는다.
> 작성 2026-10-06. 근거: master-plan 2판 0·1·5절, idea-sweep 가2·나2·나8·나15, `docs/pilot/design-simulation.md`, 9월 중간보고서.

## 1. 공통 규칙

1. **3갈래 판정.** 주지표의 95% 구간(동등성 검정은 90% 구간)으로 정한다.
   - 지지: 구간 하한이 0(또는 비교 기준)보다 크다.
   - 반증: 구간 하한이 0 이하이고 상한이 최소 의미 효과(MME)보다 작다. 의미 있는 크기의 효과가 없다는 뜻이며, '효과가 0이다'라는 뜻은 아니다.
   - 판정 불가: 구간이 0과 MME를 함께 포함한다. '효과 없음'으로 쓰지 않는다.
2. **문장 고정.** 최종 보고서의 핵심 주장 문장은 아래 칸의 문장 가운데 하나를 그대로 쓰고 중괄호 칸만 채운다. 팀원 1명이 대조해
   불일치 0건이면 통과다(가2 판정 기준).
3. **쓰지 않는 표현.** '유의하다', '입증되었다', '효과가 없다', '같다'(동등성 검정 없이), '최초', 청인 결과를 '청각장애 학습자에게
   효과'로 옮기는 표현, 앱 안 점수 향상을 전이 근거로 쓰는 표현(master-plan 9절).
4. **보호 지표.** 주지표가 지지여도 보호 지표가 기준에 못 미치면 지지 문장을 쓰지 않고 '보호 지표 미달' 문장을 쓴다.
5. **멈춤과 판정의 관계.** 순차 멈춤(베이즈 인자)은 언제 모집을 끝낼지만 정한다. 판정 문장은 멈춘 시점의 구간 판정으로 고르고,
   멈춤 근거(BF와 인원)를 같은 문단에 적는다. 이 방식에서 효과 0일 때 '지지'가 나올 확률은 모의실험에서 4.3%였다(설계 문서 3.4).

### 3.3 전이(P3 주가설)

| 칸 | 내용 |
|---|---|
| 주지표 | 실제 얼굴 개방형 문장 음소 정답률의 사람별 D = (B − A2) − (A2 − A1). 회차마다 다른 폼(A·B·C), 순환 라틴 방진. 순서를 고정효과로 둔 평균과 95% 구간(설계 문서 2.1). 자동 채점이 P20 기준(ICC ≥ 0.9)에 못 미치면 주결과를 낱말 정답률로 바꾸고 그 사실을 먼저 적는다 |
| 판정선 | 지지: 하한 > 0. 반증: 하한 ≤ 0이고 상한 < 5%p. 판정 불가: 하한 ≤ 0이고 상한 ≥ 5%p |
| 멈춤 | 한쪽 JZS BF+0(반코시 r = 0.707), 5명마다, 10명 전에는 멈추지 않음, BF ≥ 6 또는 ≤ 1/6, 최대 완료자 40명(설계 문서 5절) |
| 함께 보고 | B − A2(재검사 효과가 A2 뒤에 멈춘다고 보면 편향 없는 값, 전이의 관대한 상한), 4지선다 실제 얼굴 층, 무의미 낱말 층, ITT와 프로토콜 준수(용량 기준을 채운 사람) 결과, RCI ≥ 1.96 비율, 준수율 |
| 지지 문장 | "청인 또래 {n}명이 소리 없이 2주 학습한 뒤, 실제 화자 문장 영상의 음소 정답률은 학습 없는 기간의 변화보다 {d}%p 더 올랐다(95% 구간 {lo}~{hi}, 모집은 BF {bf}에서 {n}명으로 끝남). 이 결과는 청인 예비 파일럿에 한하며, 청각장애 학습자에게 같은 효과가 있다는 뜻은 아니다." |
| 판정 불가 문장 | "청인 또래 {n}명에서 학습 뒤 실제 화자 문장 음소 정답률의 추가 변화는 {d}%p(95% 구간 {lo}~{hi})였다. 구간이 0과 최소 의미 효과 5%p를 함께 포함해 실제 얼굴로의 전이가 있는지 판정할 수 없다. 이 결과는 전이가 없다는 근거가 아니다." |
| 반증 문장 | "청인 또래 {n}명에서 학습 뒤 실제 화자 문장 음소 정답률의 추가 변화는 {d}%p(95% 구간 {lo}~{hi})로, 미리 정한 최소 의미 효과 5%p보다 작았다. 이 학습 방식과 기간에서는 의미 있는 크기의 실제 얼굴 전이가 관찰되지 않았다." |
| 주장 상한 | 청인 또래, 소리 없이 2주, 실제 화자 2명의 문장 영상. 청각장애 학습자, 실제 대화, 촬영하지 않은 화자, 소리가 있는 조건으로 일반화하지 않는다. 앱 안 점수 향상은 이 주장의 근거로 쓰지 않는다 |

### 3.4 학습 효과(P3, C16)

| 칸 | 내용 |
|---|---|
| 주지표 | 아바타 검사(기본 얼굴, 훈련에서 뺀 검사 낱말) 정답률의 사람별 D = (B − A2) − (A2 − A1), 순서 고정효과 평균과 95% 구간 |
| 판정선 | 지지: 하한 > 0. 반증: 하한 ≤ 0이고 상한 < 5%p. 판정 불가: 나머지 |
| 보조 | 4주 유지 검사(R4 − A2)의 평균과 구간, 숙달 7일 뒤 지연 탐침 실패 비율이 모의실험 예측 +10%p 이내인지(C16), 새 가상 화자 조건 점수 |
| 검출력 주의 | 4지선다 24문항은 30명에서 효과 10%p일 때도 검출력 0.51이다(설계 문서 3.2). 효과가 작으면 판정 불가가 나올 가능성이 크다 |
