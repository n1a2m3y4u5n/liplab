## 2. 모형과 가정

### 2.1 설계와 주지표

- 회차: 학습 없이 A1, 며칠 뒤 A2, 2주 학습 뒤 B. 회차마다 서로 다른 동형 폼(A·B·C)을 본다. 폼 배정은 순환 라틴 방진 세 순서
  (ABC, BCA, CAB)를 모집 순서대로 돌려 준다. 세 순서를 같은 수로 채우면 폼 난이도 차이가 주지표 평균에서 상쇄된다.
- 주지표: 사람별 D = (B − A2) − (A2 − A1) = B − 2·A2 + A1(%p)의 평균.
- 주분석: **순서를 고정효과로 둔 D 평균**(세 순서 평균의 평균, 오차는 순서 안 잔차, 자유도 n − 3). 단순 평균의 t 구간도 함께
  계산했다(3.3).
- 3갈래 판정(최소 의미 효과 MME = 5%p, master-plan 0절 원칙 3): 지지 = 95% 구간 하한 > 0. 반증 = 하한 ≤ 0이고 상한 < 5.
  판정 불가 = 하한 ≤ 0이고 상한 ≥ 5. 세 범주는 겹치지 않는다. 하한 > 0이면서 상한 < 5인 경우(효과는 있으나 작음)는 '지지'에 넣고
  JSON의 `support_but_below_mme`에 따로 셌다.
- 검출력은 '지지' 확률이다(한쪽 2.5% 수준과 같다).

### 2.2 측정 모형

| 구성 | 개방형 문장(주결과) | 폐쇄형 4지선다(보조) |
|---|---|---|
| 사람 능력 | 로짓 θ ~ N(logit 0.30, 0.6²) | 로짓 θ ~ N(μ, 1²), μ는 사전 평균 정답률 50%가 되게 수치로 정함(−0.84) |
| 문항 | 문장 난이도 b ~ N(0, 0.8²), 문장당 채점 음소 14~26개(균등) | 난이도 d ~ N(0, 1²), 변별 1.2, 추측 0.25 |
| 응답 | 문장 안 음소 정오는 베타이항: p ~ Beta(πk, (1−π)k), k = 1/0.25 − 1, 정답 음소 수 ~ Binomial(m, p) | 문항마다 베르누이 |
| 회차 점수 | 정답 음소 수 합 / 채점 음소 수 합 | 정답 비율 |

효과는 확률 척도에 %p로 더한다. 사람 i의 회차별 가산값은 다음과 같다(ρ: 재검사 효과, τ: 전이 효과, ε: 회차 상태 잡음).

- A1: ε₁
- A2: ρᵢ + ε₂
- B: (1 + λ)ρᵢ + τᵢ + ε₃

따라서 D의 기댓값은 τ + (λ − 1)ρ다. λ = 1이면 주지표에 편향이 없고, λ < 1이면 전이를 (1 − λ)ρ만큼 낮게 추정한다.

### 2.4 베이즈 인자

- JZS 베이즈 인자(Rouder 외 2009)를 순서 고정효과 t 통계량(자유도 n − 3, 유효 인원 9/Σ(1/n_o))에 적용했다. δ는 순서 안 SD 단위의
  표준화 효과다.
- 주 설정은 한쪽 BF+0(δ > 0, 반코시 척도 r = 0.707)이다. 비교로 양쪽 BF10과 r = 0.5·0.35를 계산했다.
- 수치 적분은 비중심 t의 혼합 표현을 반코시 분위수 격자로 적분했다. 같은 코드의 양쪽 BF는 Rouder 식(g에 대한 1차원 적분)과
  다섯째 자리까지 일치했다(예: n = 20, t = 3에서 6.6188 대 6.6187, JSON `bf_selfcheck`). 등록 전에는 JASP나 R BayesFactor로
  같은 값을 한 번 더 확인한다.
- 멈춤 판정 시점: 5, 10, …, 40명. 최소 인원 n_min(이보다 적으면 멈추지 않음)을 5·10·20으로 비교했다.

영향이 작다(폼 효과는 순서 보정으로 빠진다).

### 3.6 예전 대략치와의 관계

idea-sweep 가1의 "30명 기준 12문항 5%p 검출력 0.24, 48문항 0.51"은 근거·보급 관점의 대략치였고 설계가 달랐다(사전·사후 두 번 비교로
보임). A-A-B 주지표는 측정오차가 6배로 들어가므로 같은 문항 수에서 검출력이 낮다. 이 모형에서는 30명·τ = 5에서 12문항 0.11,
48문항 0.29다. 가1·나8의 대략치는 이 표로 바꾼다.

## 4. 해석

1. **폐쇄형 4지선다는 주결과가 될 수 없다.** 48문항·40명에서도 τ = 5 검출력이 0.37이고, τ = 0일 때 판정 불가가 56%다. 가1과
   master-plan 5절이 주결과를 개방형 음소 정답률로 둔 판단과 맞다.
2. **개방형 40문장이 20문장보다 확실히 낫다.** 같은 30명에서 τ = 5 검출력 0.40 → 0.59, 반폭 5.7 → 4.5%p, 순차 설계의 τ = 5 오도
   7.8% → 3.0%. 가1의 문항 수 조건(계획 인원에서 5%p 검출력 ≥ 0.5 또는 반폭 ≤ 6%p)은 40문장이면 30명에서 둘 다 만족한다.
3. **효과가 MME(5%p) 근처면 40명으로도 판정 불가가 4분의 1 남는다.** τ = 5, 40명에서 지지 0.71, 판정 불가 0.26. 순차 설계에서는
   지지 쪽 멈춤 0.62, 40명 미결 0.36이다. 결과가 판정 불가로 나올 가능성이 작지 않으므로 그때 쓸 문장을 주장 원장에 미리 둔다
   (`claim-ledger.md`).
4. **효과가 10%p면 20~30명으로 충분하다.** 순차 설계 기대 n 16명, 지지 쪽 멈춤 0.99.
5. **재검사 효과가 A2 뒤에 줄어들면(λ < 1) 주지표는 전이를 낮게 추정한다.** λ = 0이면 −3%p, τ = 5 검출력 0.13. 반대로 B − A2만 보면
   λ = 0에서 편향이 없고 λ = 1에서 ρ만큼 높게 추정한다. λ가 0과 1 사이면 D ≤ τ ≤ (B − A2)이므로, 주지표 D는 보수적 하한이고 B − A2는
   관대한 상한이다. 두 값을 함께 보고하고, 판정은 D로 한다. A1 앞에 문항이 겹치지 않는 연습 블록을 두어 처음의 가파른 익숙함을 미리
   흡수하면 ρ 자체가 줄어 이 편향의 크기도 준다.

## 7. 한계

- 모형은 확률 척도 가산 효과, 정규 개인차, 독립 상태 잡음을 가정한다. 실제 학습 효과는 사전 능력에 따라 다를 수 있다(천장·바닥).
- 재검사 효과의 모양(λ)은 A-A-B 자료만으로 추정할 수 없다. 기저선을 셋 이상 두지 않는 한 4절 5의 상한·하한 보고가 최선이다.
- 개방형 점수는 자동 채점이 사람 채점과 같다는 전제다. P20(`typed-scoring-check.md`)에서 ICC가 0.9에 못 미치면 주결과를 낱말
  정답률로 낮춘다(master-plan 8절). 낱말 정답률은 이 모의실험에 넣지 않았다.
- 4지선다의 문항 반응 모형과 개방형의 베타이항 모형은 서로 다른 단순화이며, 두 층의 상관(같은 사람의 능력)은 모형에 넣지 않았다.
  두 층을 결합한 지표는 계산하지 않았다.
- 순차 설계의 결과는 5명 단위 확인과 모집 순 순서 배정을 전제로 한다. 같은 날 여러 명이 끝나면 B 완료 순번(`b_completed_seq`,
  `log-spec-audit.md`)으로 묶는다.
