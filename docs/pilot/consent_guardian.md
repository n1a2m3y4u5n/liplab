# 연구 참여 설명문과 법정대리인 동의서

> **먼저 읽을 것(연구진용, 나눠 주기 전에 이 상자를 지운다)**
>
> 1. **앱에는 법정대리인 동의 절차가 없다.** 가입 화면은 "만 14세 이상이거나 보호자 동의를 받았어요" 확인란 하나만 받고,
>    서버(`POST /api/auth/register`)는 이 확인 여부만 검사한다. 나이를 묻지 않고, 보호자가 실제로 동의했는지 확인하거나 기록하지 않는다.
>    `docs/pilot-data-spec.md` 2절도 연령 확인은 본인 확인란뿐이라고 적고, "만 14세 미만 참여자가 필요하면 법정대리인 동의 절차를
>    먼저 만들어야 한다"고 정했다.
> 2. **만 14세 미만을 포함하려면 아래를 먼저 마친다.** 그 전에는 이 동의서를 만 14세 미만 참여에 쓰지 않는다.
>    1. 앱에 법정대리인 동의 절차를 만든다. 보호자를 확인하는 방법, 동의 기록 저장, 보호자의 열람·정정·삭제 요청 처리를 포함한다.
>    2. `pilot-data-spec.md`와 처리방침(`frontend/src/pages/Legal.jsx`)을 그 절차에 맞게 고친다.
>    3. 윤리 심의에서 만 14세 미만 참여를 승인받는다.
>    4. 만 14세 미만 본인에게 줄 더 쉬운 설명문을 따로 만든다.
> 3. **만 14세 이상 만 19세 미만.** 계획서 §4.7은 "본인과 법정대리인의 사전 동의"를 약속했다. 윤리 심의 기관이 법정대리인 동의를 요구하면
>    `consent_participant.md`와 함께 이 동의서를 받는다. 이 경우 앱 가입은 참여자 본인이 한다.
> 4. 모으고 넘기고 지우는 내용은 `consent_participant.md`와 같게 유지한다. 한쪽을 고치면 다른 쪽도 고친다.

- 연구 제목: [연구 제목]
- 연구 책임자: [연구 책임자 이름·소속]
- 윤리 심의: [심의 기관], [승인 번호]

이 글에서 "참여자"는 보호자께서 법정대리인인 아동·청소년을 말합니다.
천천히 읽어 주시고, 모르는 부분은 언제든 물어보세요. 수어 통역으로 설명을 듣고 싶으면 알려 주세요.

## 1. 어떤 연구인가요

- LIPLAB은 입모양을 보고 말을 알아듣는 연습(독화)을 하는 웹앱입니다. [팀 이름]이 만든 연구용 시제품입니다.
- 이 연구는 LIPLAB을 [학습 기간]주 동안 쓴 뒤에 입모양 읽기 점수가 어떻게 달라지는지 알아봅니다.
- 앱이 쓰기 편한지, 앱에 나오는 작은 기호가 도움이 되는지도 알아봅니다.
- 앱의 효과는 아직 밝혀지지 않았습니다. 그것을 알아보려는 작은 연구입니다.

## 2. 누가 참여하나요

- 청각장애(농·난청)가 있는 사람 [당사자 인원]명, 청각장애가 없는 사람 [비당사자 인원]명이 참여합니다.
- 참여자 본인도 따로 설명을 듣고 스스로 참여 여부를 정합니다.
  참여자가 원하지 않으면 보호자께서 동의하셔도 참여하지 않습니다.

## 4. 좋은 점과 불편한 점

- 좋은 점: 독화를 연습할 수 있습니다. 다만 실력이 좋아진다는 보장은 없습니다.
- 불편한 점: 시간이 듭니다. 화면을 오래 보면 눈이 피곤할 수 있습니다. 참여자는 언제든 쉴 수 있습니다.
- 이 검사는 앱을 알아보려는 것이고, 참여자를 평가하려는 것이 아닙니다. 개인 점수를 학교나 기관에 알리지 않습니다.
- 앱은 시제품이라 오류가 있을 수 있습니다.

## 5. 어떤 정보를 모으나요

### 5-1. 앱에 저장되는 기록

앱을 쓰면 누구에게나 저장되는 기록입니다. 연구에 참여해도 앱이 더 모으는 기록은 없습니다.
학습 설정에 참여 코드, 집단, 참여 코드를 넣은 시각이 더해질 뿐입니다.

| 종류 | 내용 |
|---|---|
| 계정 | 이메일, 사용자 이름, 비밀번호(원래 글자로 되돌릴 수 없게 바꿔 저장), 가입 시각, 레벨, 경험치, 연속 학습 일수, 마지막 학습일 |
| 가입 동의 기록 | 동의한 이용약관·처리방침의 판본, 연령 확인 여부("만 14세 이상이거나 보호자 동의를 받았어요"), 동의 시각 |
| 학습 설정 | 학습 트랙, 현재 단계, 참여 코드, 집단, 참여 코드를 넣은 시각 |
| 문제 풀이 | 단계, 문제 종류, 문제, 고른 답, 맞았는지, 헷갈린 입모양 |
| 문장 연습 | 상황, 문장, 입력한 답, 점수, 걸린 시간, 난이도, 틀린 입모양과 소리 |
| 말하기 연습 | 목표 문장, 음성 인식 결과(말한 것을 글로 바꾼 것), 점수, 통과 여부, 소리 크기·높낮이·길이, 헷갈린 소리, 소리·입모양·종합 점수, 채점의 불확실성, 소리별 점수, 코칭 문구 |
| 검사 | 사전·사후 검사와 자가진단의 종류·판본, 정답 수, 정답 비율, 능력 추정치, 수준, 자주 틀린 입모양과 소리, 문항마다 고른 답 |
| 입모양 연습(웹캠) | 입모양 종류, 점수, 연습 처음과 끝의 오차, 측정 횟수 |
| 복습 | 약한 입모양, 복습 일정, 단계별 숙달, 저장한 문장 |

### 5-2. 저장하지 않는 것

- **목소리 녹음.** 말하기 연습을 하면 녹음이 서버로 갑니다. 채점하는 동안 서버 메모리에서만 쓰고 파일로 남기지 않습니다.
  음성 인식 결과(글)와 수치는 위 표처럼 남습니다.
- **웹캠 영상.** 기기 안에서만 처리하고 서버로 보내지 않습니다.
  입모양 연습 중에는 기기에서 계산한 입모양 수치(턱 벌림, 입술 둥글림, 입술 다물기)와 점수가 서버로 갑니다.
  순간마다의 수치는 저장하지 않고, 연습별 점수, 교정 처음·끝의 오차, 점수에서 나온 약점 정보만 남습니다.
- 말하기 연습과 웹캠 입모양 연습: [말하기·웹캠 연습 권장 여부].

### 5-3. 연구진이 받는 것(가명 자료)

연구진은 이름과 이메일을 뺀 자료만 받습니다. 이름 대신 가명을 붙입니다.

| 항목 | 설명 |
|---|---|
| 가명 | 서버 비밀키로 만든 12자리 기호 |
| 집단 | 어느 집단인지 |
| 학습 트랙 | 앱의 학습 경로 설정 |
| 참여한 날 | 참여 코드를 넣은 날 |
| 검사 결과 | 검사 종류(자가진단 포함), 판본, 정답 비율, 수준, 날짜, 참여 코드를 넣은 뒤의 검사인지 |
| 검사 문항별 응답 | 사전·사후 검사의 문항별 정오답과 고른 보기(문항 번호, 맞았는지, 고른 단어) |
| 단계별 연습 | 단계마다 푼 문제 수와 맞힌 수 |
| 말하기 연습 | 횟수와 평균 점수 |
| 학습한 날 | 앱으로 학습한 날이 며칠인지 |

- 단계별 연습, 말하기 연습, 학습한 날은 계정 전체의 기록과 참여 코드를 넣은 뒤의 기록으로 나눠 셉니다.
- 연구진이 받지 않는 것: 이메일, 사용자 이름, 입력한 문장, 음성 인식 결과, 코칭 문구, 시각 단위 기록.
- 가명 자료만으로는 누구인지 알 수 없습니다. 다만 서버 관리자(운영자)는 서버 비밀키로 가명과 계정을 맞춰 볼 수 있습니다.
  이 일은 동의 철회를 처리할 때와, 설문 연결에 동의한 참여자의 설문지에 가명을 적을 때만 합니다.

## 8. 그만두기와 동의 철회

- 참여는 자유입니다. 참여하지 않아도, 중간에 그만두어도 불이익이 없습니다.
- 보호자와 참여자 누구든 그만두기나 철회를 요청할 수 있습니다. 참여자가 그만두고 싶어 하면 그만둡니다.
- **그만두기**는 더 참여하지 않는 것입니다. 그때까지의 자료는 7번의 기한까지 두었다가 지웁니다.
  자료도 지우길 원하면 동의 철회를 요청해 주세요.
- **동의 철회**는 [문의 연락처]로 문자나 이메일을 보내 주시면 됩니다. 이유를 말하지 않아도 됩니다.
- 철회하면 이렇게 합니다.
  1. 앱 계정과 학습 기록을 모두 지웁니다. 앱에서 계정을 삭제할 때와 같은 범위입니다.
  2. 연구진이 이미 받은 가명 자료에서도 지웁니다.
  3. 설문지와 진행 메모에서 해당 부분을 지웁니다.
  4. 지운 사실은 가명으로만 파기 대장에 남습니다.
- 요청을 받은 날부터 [처리 기한]일 안에 처리하고, 결과를 글로 알려 드립니다.
- 이미 발표한 집단 결과(평균 등)에서는 뺄 수 없습니다.
- 앱에서 직접 계정을 삭제하면 앱 기록은 지워지지만, 연구진은 이미 받은 가명 자료에서 누구의 것인지 찾을 수 없게 됩니다.
  연구 자료에서도 빼려면 계정을 지우기 전에 연구진에게 먼저 알려 주세요.

## 9. 보호자의 권리

- 보호자는 참여자의 정보를 열람하거나, 고치거나, 지우도록 요청할 수 있습니다. [문의 연락처]로 요청해 주세요.
- 앱 안에서는 참여자 계정의 접근성 설정 → 내 데이터 → "내 학습 데이터 내려받기"로 기록 전체를 파일로 받을 수 있습니다.
- 검사 결과는 검사가 끝나면 참여자의 화면에 바로 나옵니다.

## 10. 참여자에게 부탁드리는 것

- '둘러보기'가 아니라 가입한 계정으로 들어갑니다.
- '학습 초기화'를 누르지 않습니다. 사전·사후 검사 결과는 남지만, 그동안의 연습 기록, 단계 진도, 복습 목록, 경험치가 지워집니다.
  그만큼 연구진이 받는 연습량(푼 문제 수, 말하기 횟수, 학습한 날 수)도 줄어듭니다.
- 검사를 다시 풀지 않습니다(검사 결과 화면의 '다시 검사' 포함).
- 참여 코드를 다른 사람에게 알려 주지 않습니다.
