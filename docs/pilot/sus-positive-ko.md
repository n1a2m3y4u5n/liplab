# 긍정판 SUS 한국어판과 번역·인지 면접 절차(P15, 초안 2026-10-06)

> master-plan 2판 P15, idea-sweep 나20. `docs/pilot/survey.md`의 자체 사용성 10문항(A1~A10)은 기준값과 비교할 수 없어, 모든 문항을
> 긍정문으로 바꾼 SUS(Sauro & Lewis 2011)로 바꾼다. 이 문서는 **번역 초안**이며, 아래 3절의 번역·역번역과 4절의 인지 면접을 거치기
> 전에는 파일럿에 쓰지 않는다. **한국수어 영상판은 촬영이 필요하고 아직 없다**(5절).

## 1. 왜 긍정판인가

- 원판 SUS(Brooke 1996)는 긍정문(홀수)과 부정문(짝수)이 번갈아 나온다. 한국어가 수어 다음의 둘째 언어인 참여자에게는 부정문 문항에서
  답의 방향을 헷갈릴 위험이 크다(`survey.md` 메모).
- 원판의 부정문을 임의로 쉽게 고치면 척도가 바뀌어 기준값과 비교할 근거가 사라진다(idea-sweep 7절).
- Sauro & Lewis(2011)는 열 문항을 모두 긍정문으로 바꾼 판을 만들어 원판과 평균이 비슷하다고 보고했다. 다만 이 문서에서는
  **긍정판으로 얻은 기준값과만 비교한다**(6절).
- 문헌 확인 수준: Sauro & Lewis 2011은 idea-sweep 8.2에서 '검색 결과 요약만' 확인한 상태다. 번역에 들어가기 전에 원문(CHI 2011
  논문)을 구해 아래 영어 문구를 글자 단위로 대조한다.

## 2. 문항 초안

응답: 1 전혀 그렇지 않다 / 2 그렇지 않다 / 3 보통이다 / 4 그렇다 / 5 매우 그렇다. 열 문항 모두 답한다. 판단하기 어려우면 3에 표시한다는
원판 안내를 따른다(SUS 문항에는 '모름' 칸을 두지 않는다).

| 번호 | 영어 원문(긍정판, 원문 대조 전 기억에 기댄 문구) | 한국어 1차안 | 쉬운 말 대안(인지 면접에서 비교) |
|---|---|---|---|
| S1 | I think that I would like to use this website frequently. | 나는 이 앱을 자주 쓰고 싶다. | |
| S2 | I found the website to be simple. | 이 앱은 단순했다. | 이 앱은 복잡하지 않았다. (부정 표현이 들어가므로 1차안을 우선) |
| S3 | I thought the website was easy to use. | 이 앱은 쓰기 쉬웠다. | |
| S4 | I think that I could use the website without the support of a technical person. | 나는 기계를 잘 아는 사람의 도움 없이 이 앱을 쓸 수 있을 것 같다. | 나는 다른 사람의 도움 없이 이 앱을 쓸 수 있을 것 같다. |
| S5 | I found the various functions in the website were well integrated. | 이 앱의 여러 기능이 서로 잘 이어져 있었다. | 이 앱의 여러 기능이 한 앱 안에서 자연스럽게 연결되어 있었다. |
| S6 | I thought there was a lot of consistency in the website. | 이 앱은 화면마다 쓰는 방법이 한결같았다. | 이 앱은 처음부터 끝까지 같은 방식으로 쓸 수 있었다. |
| S7 | I would imagine that most people would learn to use the website very quickly. | 대부분의 사람은 이 앱 쓰는 법을 아주 빨리 익힐 것 같다. | |
| S8 | I found the website very intuitive. | 이 앱은 보자마자 어떻게 쓰는지 알 수 있었다. | 이 앱은 매우 직관적이었다. (한자어 '직관적'의 이해도를 비교) |
| S9 | I felt very confident using the website. | 나는 이 앱을 쓸 때 자신 있었다. | 나는 이 앱을 쓸 때 헤매지 않고 자신 있게 썼다. |
| S10 | I could use the website without having to learn anything new. | 나는 새로 배울 것 없이 이 앱을 쓸 수 있었다. | |

번역 원칙
- 'website'와 원판의 'system'은 모두 '이 앱'으로 옮긴다.
- 한 문항에 생각 하나만 담는다. 1차안은 한 문장 20자 안팎, 부정 표현 없음을 목표로 했다.
- '일관성', '직관적', '통합'처럼 뜻이 추상적인 한자어는 1차안에서 풀어 썼다. 풀어 쓰면 뜻이 조금 달라질 수 있으므로, 원래 낱말을
  쓴 대안과 함께 인지 면접에서 비교한다(4절).
- S8과 S10은 1차안끼리 뜻이 가깝다(둘 다 '배우지 않고 쓸 수 있음'). 원문에서도 S8은 '보고 바로 앎', S10은 '새로 배울 것 없음'으로
  다르므로, 인지 면접에서 두 문항을 다르게 이해하는지 따로 확인한다.

## 3. 번역과 역번역 절차

| 단계 | 하는 사람 | 하는 일 | 남기는 기록 |
|---|---|---|---|
| 1. 원문 확정 | 연구진 1명 | 원 논문에서 긍정판 10문항과 응답 척도, 안내문을 옮겨 적고 출처 쪽수를 남긴다 | 원문 파일, 출처 |
| 2. 독립 정번역 | 번역자 2명(한국어 모국어, 영어 능통). 1명은 사용성 평가를 알고, 1명은 모른다 | 서로 보지 않고 각각 옮긴다(T1, T2). 이 문서의 1차안은 보지 않는다 | T1, T2 |
| 3. 조정 | 제3자 1명과 두 번역자 | T1·T2와 이 문서의 1차안을 비교해 한 판(T12)으로 합친다. 고른 이유를 문항마다 적는다 | 조정 기록표 |
| 4. 쉬운 말 점검 | 연구진 | C15 기준(문장 길이, 쉬운 낱말, 부정 표현 없음)으로 T12를 점검한다. 고친 곳은 3단계 사람들이 뜻이 같은지 확인한다 | 점검표 |
| 5. 역번역 | 원문을 보지 않은 번역자 2명(영어 모국어 또는 영어 능통) | T12를 영어로 각각 되옮긴다(BT1, BT2) | BT1, BT2 |
| 6. 대조 | 연구진과 1·3단계 사람 | 원문과 BT를 문항마다 '같음·조금 다름·다름'으로 표시한다. '다름'은 T12를 고치고 5단계를 그 문항만 다시 한다 | 대조표 |
| 7. 전문가 검토 | 특수교육·언어재활 자문(있으면), 청각장애 당사자 1명 이상 | 청각장애 학습자에게 어색하거나 오해할 표현을 찾는다 | 검토 의견 |
| 8. 인지 면접 | 4절 | | 4절 기록 |
| 9. 최종판 동결 | 연구진 | 판 번호와 날짜를 붙여 동결한다. 이후 바꾸면 새 판으로 다시 4절을 한다 | 최종판, 변경 이력 |

## 4. 인지 면접

- **대상:** 청인 3명 이상, 청각장애 당사자 3명 이상(나20 판정 기준). 당사자는 의사소통 방식(수어, 구어·보청기, 인공와우)이
  섞이게 고른다. 파일럿 본참여자는 면접 대상에서 뺀다.
- **진행:** LIPLAB을 10분 이상 써 본 뒤 한 문항씩 답하게 하고, 문항마다 다음을 묻는다. 당사자 면접은 참여자가 고른 방식(글,
  수어 통역, 필담)으로 한다.
  1. 바꿔 말하기: "이 문항이 무엇을 묻는지 자기 말로 말해 주세요."
  2. 답의 근거: "왜 그 번호를 골랐나요? 어떤 경험이 떠올랐나요?"
  3. 낱말 이해: 1차안과 대안 표현(2절 오른쪽 칸)을 보여 주고 어느 쪽이 더 이해하기 쉬운지 묻는다.
  4. 방향 확인: 5가 '그렇다' 쪽이라는 것을 헷갈리지 않았는지 확인한다.
- **판정:** 문항마다 바꿔 말하기가 원문 뜻과 맞으면 '이해'로 센다. 두 사람이 따로 판정하고 다른 경우는 협의한다. **이해율 ≥ 80%**인
  문항만 통과한다(청인과 당사자를 따로 계산해 둘 다 80% 이상). 미달 문항은 3절 3~6단계를 그 문항만 다시 하고 새 면접 대상 3명으로
  다시 확인한다.
- **기록:** 면접 기록에는 이름 대신 면접 번호와 집단만 적는다. 녹화하지 않는다(필요하면 동의서를 따로 받는다).

## 5. 한국수어 영상판(촬영 필요, 아직 없음)

- **필요한 이유:** 한국어 글이 둘째 언어인 수어 사용자에게 글판만 주면 사용성 점수에 읽기 능력이 섞인다(나20).
- **만드는 법:** 최종 한국어판(3절 9단계)을 농인 모국어 수어 사용자와 수어 통역사가 함께 수어로 옮겨 촬영한다. 다른 통역사가 영상만
  보고 한국어로 되옮겨 한국어판과 뜻을 대조한다(3절 5~6단계와 같은 방식). 당사자 인지 면접(4절)을 영상판으로도 한다.
- **촬영 사양(제안):** 문항마다 영상 하나, 정면, 상반신과 손이 모두 보이는 틀, 단색 배경, 1080p. 화면에는 영상과 한국어 문항을 나란히
  보여 주고 응답 칸은 같다. 영상 파일은 공개 저장소에 넣지 않는다.
- **선행 조건:** 수어 화자와 통역사 섭외, 출연 동의서(얼굴이 나오는 영상), 촬영 일정. master-plan 3절 촬영 목록과 같은 날에 찍을 수
  있다. 결정과 섭외 전까지 이 판은 비워 둔다.

## 6. 채점과 비교

- **문항 점수:** 긍정판은 뒤집을 문항이 없다. 문항마다 (응답 − 1)로 0~4점.
- **총점:** 열 문항 점수의 합 × 2.5 → 0~100점.
- **결측(미리 정한 규칙, 이 문서의 제안):** 한 문항이 비면 나머지 아홉 문항 평균으로 채워 총점을 낸다. 두 문항 이상 비면 그 사람의 SUS
  총점은 결측으로 두고 문항별 분포에만 넣는다. 채운 사람 수를 보고한다.
- **신뢰도:** 사용 뒤 Cronbach α를 보고하고 0.70 이상인지 적는다(나20). 표본이 작으면 α의 구간도 함께 적는다.
- **보고:** 집단별 평균, 표준편차, 중앙값, 범위와 평균의 95% 구간. 문항별 응답 분포를 함께 보인다.
- **기준값 비교는 긍정판 기준값과만 한다.** 원판 SUS의 평균 68이나 원판으로 만든 등급표(형용사 척도, 백분위 등급)에 긍정판 점수를
  대지 않는다. 긍정판으로 얻은 공개 기준값이 마땅치 않으면 기준값 비교를 하지 않고 기술 통계만 낸다. 한국어판과 수어 영상판 점수는
  서로 다른 판이므로 섞기 전에 판별 평균을 따로 보인다.
- **해석 주의:** 모든 문항이 긍정문이면 '그렇다' 쪽으로 기우는 응답 경향이 생길 수 있다(`survey.md` 메모와 같다). 결과에 이 한계를
  적는다. 청인 또래 파일럿(P3)의 SUS는 청인 사용성이며, 청각장애 학습자의 사용성으로 옮기지 않는다.

## 7. 다른 문서에서 고칠 것(이 작업에서는 고치지 않았다)

1. `docs/pilot/survey.md` A절: A1~A10을 이 문서의 최종판 S1~S10으로 바꾸고, 기존 A3(입모양이 잘 보였다), A4(속도가 알맞았다),
   A8(소리 없이도 어려움 없음)은 SUS와 별도 문항으로 남긴다(나20). SUS를 다른 문항보다 먼저 묻는다.
2. `docs/pilot/survey.md` 끝 메모: "SUS 대신 긍정문 자체 문항을 쓴다"를 "긍정판 SUS를 쓴다"로 고친다.
3. `docs/pilot/protocol.md` 6.3 사용성 분석: 합산 점수를 참고로만 쓰던 규칙을 6절 채점과 비교 규칙으로 바꾼다.
4. 동의서: 수어 영상판을 쓰면 설문 방식 칸에 영상판을 더한다.
