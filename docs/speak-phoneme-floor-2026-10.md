# 0점 음소가 있어도 합격하는 문장 점수: 최저 음소 규칙 확인 (2026-10-09, 사전 등록)

1~7절은 측정 전에 적고 따로 커밋한다. 결과는 8절에 붙인다. 측정 전에 바꾼 것이 있으면 7절에만 덧붙인다.

## 1. 문제

- 말하기 문장 점수는 D-GOP 음소 점수(0~1)의 평균을 배포 앵커(`backend/data/dgop_calibration_ours.json`)로 옮긴 값이고, 65점 이상이면 합격이다.
  `docs/scoring-regression-2026-10.md` 5절 기록대로 8음소 가운데 하나가 0이고 나머지가 0.9이면 원점수 78.8, 표시 86.5점으로 합격한다.
- 문장 하나에서 소리 하나만 틀리게 낸 경우(대치)를 문장 점수가 거의 가르지 못할 수 있다는 뜻이다. 반대로 음소 점수 하나는 믿기 어렵다.
  S2(`docs/phoneme-feedback-reliability-2026-10.md` 9.2절)에서 확인을 통과한 소리가 하나도 없었고, 538 정상 발화에서도 소리마다 거짓 빨강이
  8~10%였다. 그래서 '최저 음소가 낮으면 불합격'은 맞게 말한 문장을 많이 떨어뜨릴 수 있다.
- 이 등록은 최저 음소를 쓰는 규칙이 맞게 말한 문장의 비용보다 대치 문장을 더 많이 잡는지를 기존 점수 덤프만으로 확인한다. 새 추론은 하지 않는다.

## 2. 등록 전에 본 것

- 자료 형식을 확인하려고 덤프마다 첫 줄 몇 개를 열었다. 그중 608 자기 문장 하나(BJJ 세션 0번, 표시 80.4점)에 0.0과 0.0001인 음소가 있었고,
  538 교체 문장 하나(spk332, 원래 93.0점, 세 자리를 바꾼 목표 91.4점)를 보았다. 집계는 보지 않았다.
- 덤프의 음소 점수로 문장 원점수·표시 점수를 다시 계산하면 덤프의 값과 맞는지 점검했다(덤프마다 40줄, 교체 덤프 50레코드, 0.1점 넘게 다른 것은
  10/6 sc 덤프의 1줄). 이것은 재현 점검이고 결과 지표가 아니다.

## 4. 후보 규칙(문장 단계, 지금 판정이 합격인 시도에만 작용)

음소 목록은 앱과 같다: 정렬됐고 채점 대상이며 내지 않는 ㅎ이 아닌 음소. 문장 평균은 지금처럼 이 전체로 낸다. 최저 음소는 **문장 끝 음절을 뺀**
음소에서 고른다(`phone_reliability.final_syllable_start`, 끝 모음 정렬 결함 때문에 S2도 끝 음절을 판정하지 않았다).

- **F(t)** 최저 음소 보류: 표시 점수 ≥ 65이고 최저 음소 < t이면 '다시 말해 보기' 보류. 보류한 시도는 합격으로 세지 않는다. t ∈ {0.005, 0.01, 0.02, 0.05, 0.10}.
- **W(w)** 최저 음소 가중: 원점수를 (1 − w) × 평균 + w × 최저로 바꿔 같은 앵커로 옮기고 65점으로 다시 판정. w ∈ {0.1, 0.2, 0.3}.

두 갈래 모두 지금 합격인 시도를 합격 아님으로 바꿀 수만 있다(W는 최저가 평균보다 크지 않으므로). 그래서 아래 지표는 '합격에서 빠진 비율'로 잰다.

## 5. 지표와 판정 기준

지표(묶음마다, 지금 합격하는 시도 가운데 규칙이 합격에서 뺀 비율):
- 거짓 보류 `FH` = 자기 문장에서 빠진 비율. 538은 538-a + 538-b, 608은 608-own.
- 대치 잡기 `CS` = 교체·대치 목표에서 빠진 비율. 538은 538-a 조용, 608은 608-s18.
- 순이득 `NG` = CS − FH(같은 집단 안에서).
- 보고: 다른 문장·반례의 합격률 변화, 538 중 조건 교체의 CS, 자기 문장 전체 합격률 변화, 화자별 FH.

화자 절반: 608은 화자 이니셜 3글자의 crc32 % 2, 538은 화자 ID의 crc32 % 2(지금까지의 분석과 같다). 절반 0에서 탐색, 절반 1에서 한 번만 확인한다.
구간: 화자 단위 부트스트랩 2,000번(Random(20261009)), 95% 백분위 구간. NG는 같은 화자 재표집 안에서 두 비율의 차로 낸다.

판정 기준(확인 절반, 모두 넘어야 통과):

| | 기준 | 이유 |
|---|---|---|
| K1 | 538 FH ≤ 3%, 구간 상한 ≤ 5% | 정상 발화 문장을 거의 잡지 않아야 한다 |
| K2 | 608 FH ≤ 8%, 구간 상한 ≤ 12% | 음소 신뢰도가 낮다는 S2 결과로 608에서 거짓 보류가 많을 수 있어 상한을 따로 둔다 |
| K3 | 538 CS ≥ 30%, NG 구간 하한 > 0 | 소리 하나를 틀린 문장을 실제로 잡아야 한다 |
| K4 | 608 NG ≥ 0(점 추정) | 608에서 맞게 말한 문장을 대치 문장보다 더 많이 잡으면 안 된다 |

탐색 절차: 절반 0에서 후보 8개 가운데 K1~K4의 점 추정을 모두 넘는 것을 고르고, 그중 538 NG가 가장 큰 것 하나를 확인한다(같으면 FH가 작은 것).
넘는 후보가 없으면 판정은 **실패(탐색)**이고, 538 NG가 가장 큰 후보의 확인 절반 수치를 보고만 한다.
확인 절반에서 고르지 않은 후보의 수치도 함께 내지만 보고만 한다(판정에 쓰지 않는다).

절반별 시도 수(등록 전 불러오기 점검, 점수는 보지 않음): 538 자기 580/620, 교체 조용 299/316, 다른 1,159/1,239, 반례 2,358/2,424;
608 자기 455/226, 대치 534/174, 다른 855/360, 반례 1,504/1,167(탐색/확인). 화자는 538 79명, 608 34명. 최저 음소를 고를 음소가 없는 시도 5개는
규칙이 작용하지 않는다(지금 판정 그대로).

스크립트: `scripts/speak_phoneme_floor.py`(이 등록과 함께 커밋, 집계만 출력).

### 8.3 사후 관찰(등록 밖, 판정에 쓰지 않음)

- 538 교체 자리의 음소 점수는 1,317자리 가운데 96.1%가 0.05 미만이다(같은 자리의 원래 목표 점수는 87.2%가 0.5 이상). 음소 하나는 바꾼 자리를 잘 짚는다.
- 그러나 맞게 말한 538 자기 문장(538-a 600개)도 끝 음절을 뺀 음소의 8.9%가 0.05 미만이고, 문장 88.7%에 그런 음소가 하나 이상 있다(문장당 중앙 3개).
  608 자기 문장은 21.5%(문장당 중앙 4개, 음소 중앙 27개)다. 최저 음소는 거의 모든 문장에서 0 근처라 문장 사이를 가르지 못한다.

  새 등록과 새 화자 묶음이 필요하다. S2 결과(소리별 거짓 빨강 8~10%)와 같은 방향이다.
