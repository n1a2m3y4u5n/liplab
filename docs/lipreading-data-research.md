# 자체 립리딩 모델 — 데이터셋·사전학습 모델 조사

> 축 D의 '자체 립리딩 모델'(영상에서 입모양만 보고 단어 인식) 학습을 위한 사전 조사.
> 2026-09-03 기준. 각 항목의 접근 조건·라이선스는 착수 전 원문 재확인 필요.

## 핵심 요약
- **"AI Hub 립리딩 데이터"와 "OLKAVS"는 같은 데이터셋이다**(서강대 IIP 제작, AI Hub 배포판 = OLKAVS).
- 공개된 **단어 단위(word-level) 한국어 립리딩 코퍼스는 사실상 없다**. 대규모는 전부 문장 단위.
- 따라서 목표를 **"문장 open-set 인식"이 아니라 "수십 단어 closed-set 분류"로 축소**하는 것이
  고교생·제한 GPU 환경에 현실적이다.

## 1. 데이터셋

### OLKAVS = AI Hub 「립리딩(입모양) 음성인식 데이터」 (유일한 대규모 한국어 립리딩 코퍼스)
- 규모: 영상 5,750시간(9시점 멀티뷰), 음성 1,150시간, 화자 1,107명, 라벨 66,420건. **문장 단위**.
- 형식: mp4(영상) + wav + json(텍스트·바운딩박스). 공개 2022-07, v1.0.
- 접근: 무료. AI Hub 회원가입 + 휴대폰 본인인증 → 사용신청 후 자동승인(대개 즉시). 샘플(경량)은 로그인만으로 즉시.
- **실질 병목은 승인이 아니라 다운로드 용량(영상 수 TB급)과 스토리지**.
- 라이선스: AI Hub 이용정책(커스텀). 논문은 CC-BY-4.0이나 배포는 AI Hub 약관 우선. 상업 활용은 원문 확인.
- URL: https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=538 · https://github.com/IIP-Sogang/olkavs-avspeech · https://arxiv.org/abs/2301.06375

### KMSAV (ETRI) — 자발화 다화자 시청각
- 규모: 전사 약 150시간(GitHub엔 83시간 표기, **불일치 확인 필요**) + 미전사 유튜브 약 2,000시간. 문장/대화 단위.
- 접근: 오픈액세스, 회원가입 불필요, GitHub clone. 데이터 CC-BY-NC-SA 4.0(**비상업**), 코드 MIT.
- 논문에서 AV-HuBERT 한국어 파인튜닝 보고(체크포인트 공개 여부 **확인 필요**, 문의 pkyoung@etri.re.kr).
- URL: https://github.com/etri/kmsav

### 없는 것
- word-level 한국어 립리딩 벤치마크(영어 LRW·중국어 LRW-1000에 대응하는 한국어판)는 배포본 없음.
  문장 데이터를 **강제정렬(forced alignment)로 단어 구간 분할**하거나 **목표 단어를 자체 촬영**해야 함.

## 2. 사전학습 모델
| 모델 | 한국어 | 라이선스 | 비고 |
|---|---|---|---|
| **OLKAVS baseline V-model** | ✅ 한국어 학습(유일) | 코드 MIT / 가중치 AI Hub 약관 | 립리딩 34M, CER 26.6%/WER 47.9%. 초기가중치·특징추출기로 우선 검토 |
| AV-HuBERT (Meta) | ❌ 공식 없음 | 커스텀(비상업 통용) | fairseq·입술 ROI 정렬 진입장벽 높음. 후순위 |
| Auto-AVSR (mpc001) | ❌ | 코드 Apache-2.0 | 코드 최신·정돈. 중~높은 난이도 |

## 3. LIPLAB 팀 우선순위 (권고)
1. **AI Hub 립리딩 데이터 샘플(경량)부터 확보** — 가입+본인인증만으로 즉시·무료. 데이터 포맷·입술 크롭
   전처리 파이프라인을 먼저 검증. 전체 신청은 병행하되 스토리지(TB) 먼저 확인.
2. **목표를 closed-vocabulary(수십 단어) 분류로 확정** — 발음 교정 앱 성격상 정해진 단어/음절 인식이면 충분.
   LRW식 소형 모델(입술 ROI → 3D conv+ResNet → GRU/Transformer) 또는 MediaPipe 랜드마크 시퀀스 분류(초경량).
   필요하면 목표 단어를 자체 촬영해 소량 수집.
3. **OLKAVS V-model을 초기가중치로 우선**, AV-HuBERT는 라이선스(비상업)·진입장벽으로 후순위.
   공모전 이후 서비스화 계획이 있으면 각 라이선스·AI Hub 이용정책을 착수 전 확인.

## 착수 전 확인 필요
- KMSAV 전사 시간(150h vs 83h) · KMSAV 한국어 AV-HuBERT 체크포인트 공개 여부
- AV-HuBERT LICENSE의 상업적 사용 허용 여부 · AI Hub 립리딩 데이터의 상업 활용 가능 여부(이용정책 원문)
