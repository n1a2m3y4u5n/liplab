# 65% 결합 증류 seed1 추가 사전 등록

**사용자의 새 D65 seed1 즉시 실행 지시에 따른 시작 전 추가 등록**이다. 앞선 `87ea`의 “D65 seed0 네 관문 통과 뒤에만 seed1 별도 등록”이라는 대기 규칙은, D65 seed0 최종 네 관문이 아직 확정되지 않은 시점의 새 사용자 승인으로 **앞으로의 seed1 실행에 한해 대체**한다. 과거 seed0 문서/metadata의 `seed1_not_registered:true`는 당시 규칙의 이력이며 새 승인 뒤의 상태를 뜻하지 않는다. 부모 오케스트레이터는 상태 설명만 갱신하고 seed0 학습·평가 수식·결과는 바꾸지 않는다. 결과를 보고 유리한 시드를 사후 선택하는 것이 아니다.

**학습33/검증12 개발 선택, 판정 없음, 깨끗한 평가 대기**다. D65 seed0·D50·A·C의 파일과 미달 결과를 덮어쓰지 않고, 학생 seed1을 새 폴더에서 한 번만 실행한다. 앱·플래그·배포·푸시 변경은 없다.

## 고정 모델과 같은 seed 기준

선생은 큰 결합 **seed0** 그대로이며 SHA256 **42b5fc382377c3a6db4567a989d372b741d8b34504323956bd92bb58ed084c35**,6,068,989파라미터·teacher_seed=0이다. 학생은 `nextreg_distill65.build_student()` ROI3,940,973(전단741,920·후단3,199,053)에 같은 lips80 잔차21,984를 더한 **3,962,957파라미터**다. 내부40×40·stem16·잔차24/48/96/192 각1블록·선형256·LayerNorm256→BiGRU2층 hidden332 dropout0.2→53자모, 좌표 LayerNorm80→Linear64→GELU→Linear256 잔차 구조는 D65s0과 같다. 태그도 `fusion_distill65_roi256_lips80_kd_v1`로 호환되며 학생 seed·provenance·출력으로 분리한다.

학생의 **초기 R.setup과 실제 R.main을 모두 seed1**로 고정한다. 이전 학생이나 선생 가중치로 초기화하지 않는다. 정확도·CER 기준은 같은 seed **B33s1**의 완료된 선택 PT+요약이며 SHA256 **a0d2ff6c17799a0036f20dcf346594de0de794dfc358480d64c211928983c35f**다. B33s0이나 더 유리한 기준으로 바꾸지 않는다.

## 동일 자료·증류·훈련

기존 B33 prep 학습33명·검증12명, 같은 ROI/lips pack·문장 제외·어절·문항·idle·프레임 offset과 좌표 결측2프레임 보간·삭제0 계약을 그대로 쓴다. 평가19·clean_eval·E2·KMSAV·OLKAVS·새 자료는 사용하지 않는다.

고정 full fusion seed0을 eval/no_grad로 train 역할만 최대400프레임의 비중첩 창, 중앙80 ROI+같은 전역 프레임 lips80에 넣어53로짓 float16 캐시를 만든다. 검증 역할은 예측하지 않고 영역을0으로 둔다. 캐시 float16은 목표 저장이며 가중치/ONNX는 FP32다. 학생과 목표의 속도0.8~1.25·같은 화자 idle75 재색인, 무작위80자르기·좌우반전0.5·시간마스크≤3, 좌표 점 대응+x부호 반전·같은 마스크/패딩 임베딩0을 유지한다. 깨끗한 paired 선생과 증강된 paired 학생의 일관성 증류다.

손실은 **0.5×CTC + 0.5×T²×유효 프레임 평균 KL, T=2**다. CTC는 항목 평균, KL은 전체 배치 유효 프레임 평균이며 미니그룹 바깥 가중치를 안에서 상쇄한다. 배치/목표는 동기로 읽고 tuple의 ROI 시간·장치를 사용한다.

**학생 seed1 한 번**, AdamW lr3e-4 wd1e-4, 배치32,4000유효 프레임 그룹, 최대40에폭, 매2에폭 검증, patience6, 기울기5, idle0.5, **AMP0·CPU4**를 고정한다. main RTX3060 기술 메모리 상한 **0.45**(black seed0은0.92) 외 과학 설정은 같다. 체크포인트는 같은 hard ctc_ll α1·idle75·dup1/2 화자평균 평균의 엄격한 최고값이며 CER는 그 체크포인트의 검증 문장 자모CER다. resume·추가시드·배치/구조/손실 조정 재시도는 없다.

## 네 관문과 조건부 안정성

각 수치는 다음 네 기준을 그대로 적용한다.

1. 같은 seed B33s1 대비 검증4지 차이 ≥ **+0.02**.
2. 같은 seed B33s1 대비 검증 문장CER 차이 ≤ **+0.02**.
3. 학생 FP32 ONNX 크기 ≤ 고정 full fusion seed0의 **75%**.
4. 같은PC·같은입력 WASM 중앙시간 ≤ full fusion seed0의 **60%**.

**seed1은 D65 seed0이 네 관문을 모두 통과할 때에만 안정성 증거다.** seed0이 하나라도 미달이면 seed1이 통과해도 **기록 전용(RECORD_ONLY)**이며 D65 성공 시드로 고르지 않는다. 좋은 시드 선택·평균으로 실패를 덮기·관문 하향은 없다. 두 시드가 각각 네 관문을 모두 넘어야 두 시드 안정 통과다. 개별 seed1 수치와 상위 D65s0 조건부 결론을 분리하며 독립 판정·제품 성능·사람 독화 향상·Android 실측이라고 부르지 않는다.

## FP32·WASM과 고정 순서

D65s0과 같은 두 입력 FP32·opset17 wrapper를 쓴다. ROI 원화소0~255 `[B,T,80,80]`, 정규화 lips `[B,T,80]`, 출력 `[B,T,53]`이며75프레임 합성 원경로↔wrapper↔ONNX CPU 최대차이<1e-3를 확인한다. 다른 형식·유리한 재측정으로 바꾸지 않는다.
