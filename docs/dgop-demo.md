# B 실증 — 전사 비의존 발음채점(D-GOP)

고도화계획서 §3.2(B)의 논지는 "발음평가가 ASR 전사에 의존하면 대상(농인·난청)에게서 채점 근거가 무너지므로,
목표 음소열에 강제정렬해 직접 채점하는 D-GOP가 필요하다"이다. 이 문서는 그 논지를 실제 사람 발화로 잰 결과다.

> **판 이력.** 첫 판(2026-09-22)은 macOS TTS(`say -v Yuna`) 합성음 7문장으로 쟀고 "실제 음성"이라고 잘못 적었다.
> 병합 전 구현(`dgop_from_audio`, `naive × confidence`)을 쓴 값이기도 했다. 2026-09-23에 AI Hub 538 실발화
> 300문장과 팀 표준 채점식(naive)으로 다시 쟀고, 아래 1~4절이 그 결과다. 첫 판 결과는 5절에 참고로 남긴다.

## 1. 방법

- **데이터.** AI Hub 538(OLKAVS) 10화자 300문장(한 사람당 30문장, 16kHz), 문장 전사 보유.
  `liplab_gpu_snapshot/expand538`. RunPod RTX 3090에서 측정했다.
- **조건 5개.**
  - 깨끗한 원본
  - 농인 합성 경·중·심: `make_deaf_corpus.PRESETS`. 포먼트 0.95/0.90/0.84, 말속도 0.92/0.85/0.78,
    저역통과 3200/2500/1900Hz, 활성 발화 대비 SNR 25/15/8dB.
  - 뭉갬: 첫 판과 같은 신호 교란. 800Hz 저역통과, 말속도 1.3배.
- **ASR 전사.** `kresnik/wav2vec2-large-xlsr-korean` CTC 그리디 디코드. 음절 CER(공백·부호 제외).
- **D-GOP.** 통합 브랜치의 팀 표준 경로. `dgop_acoustic.phone_confidences`(강제정렬) +
  `dgop.sentence_dgop`(naive 채점, 원점수 ×100, 보정 전). 정렬기와 채점기 모두 공개 모델 kresnik이다.
  팀원의 A-2 정렬기(비공개 HF)를 쓴 판은 아니다.
- **재현.** `scripts/remeasure_b.py`. 요약 `docs/dgop-remeasure-538.json`, 클립별 원자료는
  `liplab-lab/data/pod_runs/session3_extra_20260924_0331/b_remeasure_fixed.json`.
- **판 이력(9/24).** 이 절의 D-GOP는 강제정렬 blank를 고친 판이다. 9/23 판은 kresnik의 CTC blank(`[PAD]`, id 1204)
  대신 id 0 음절 '볍'을 blank로 써서 구간이 퍼지고 목표 확률이 묽어졌다(원점수 16.4·9.1·5.3·2.1, 순서 82.3%, 상관 0.86).
  그 판은 `docs/dgop-remeasure-538-before-blank-fix.json`에 남겼다. ASR CER은 두 판이 같다.

## 2. 결과

| 조건 | ASR CER 평균(중앙) | 정확 전사 비율 | D-GOP 원점수 평균(중앙) |
|---|---|---|---|
| 깨끗한 원본 | 0.194 (0.178) | 4.3% | 80.2 (82.5) |
| 농인 합성 경 | 0.503 (0.479) | 0.3% | 49.6 (50.9) |
| 농인 합성 중 | 0.723 (0.736) | 0% | 26.7 (25.0) |
| 농인 합성 심 | 0.922 (0.941) | 0% | 5.8 (3.8) |
| 뭉갬 | 0.811 (0.826) | 0% | 17.8 (16.8) |

- 클립마다 D-GOP가 깨끗 ≥ 경 ≥ 중 ≥ 심 순서로 떨어진 비율: **95.7%**. 화자 10명 모두 평균이 크게 떨어졌다
  (깨끗 64.0~88.5 → 심 1.8~10.4).
- 모든 조건을 합쳤을 때 D-GOP와 전사 정확도(1 − CER)의 스피어만 상관: **0.986**. 깨끗한 발화만 봐도 0.956이다.
  다만 D-GOP와 ASR이 같은 kresnik 모델의 출력이라, 이 상관은 독립 검증이 아니라 한 모델의 두 읽기가 서로 맞는다는 뜻이다.
- 경 조건에서도 ASR은 다른 말로 옮긴다. 예: "최저임금이 … 아르바이트로" → "최여임금이 … 사르바이트노".

## 3. 해석

1. **정상 발화도 전사로는 거의 "정답"이 되지 않는다.** 깨끗한 정상 발화의 CER이 0.19이고, 문장 전체를 정확히
   옮긴 경우는 4.3%뿐이다. 전사가 목표 문장과 일치하는지로 채점하면, 제대로 말한 사람도 대부분 틀린 것으로
   처리된다. 채점 근거가 화자의 발음보다 ASR의 한계에 좌우된다는 뜻이다.
2. **D-GOP는 전사 없이 명료도를 연속으로 잰다.** 교란이 세질수록 D-GOP가 단조롭게 떨어지고(96%),
   전사 정확도와 0.986으로 같은 방향이다. 전사 문자열을 거치지 않고도 명료도에 비례하는 점수를 주고,
   음소 단위로 어디가 약한지도 짚는다. 깨끗한 정상 발화의 원점수가 중앙값 82점이라 표시 눈금도 자연스럽다.
3. **"D-GOP가 ASR보다 더 견고하다"는 이 실험으로는 말할 수 없다.** 합성 교란에 대해 두 지표는 함께, 같은
   폭으로 떨어진다(경 조건에서 전사 정확도 −38%, D-GOP −38%). 첫 판의 "ASR은 무너지고 D-GOP는 버틴다"는
   읽힘은 TTS 합성음 때문이었다. 이 판의 근거는 견고성이 아니라 **전사 비의존성과 연속성**이다.

## 4. 실제 청각장애 발화 근거와 한계

- 2026-09-18 로컬 측정: 정상(538, n=40) CER 0.219 대 608 언어청각장애 3화자(n=5) CER 0.401, 약 1.83배
  (재현 `liplab_gpu_snapshot/validate_b_local.py`). 실제 청각장애 발화에서 전사 오류가 커진다는 근거지만
  표본이 작다.
- 위 2절의 저하는 실제 청각장애 발화가 아니라 합성 교란이다. 같은 발화에서 D-GOP가 정상과 청각장애를 가르는지는
  608 음성을 받아(AI Hub, 2026-09-23 대기 중) 다시 잰다.
- D-GOP는 보정 전 원점수다. 앱 표시 점수의 보정 앵커는 채점식 교체 뒤 재적합이 필요하다(STATUS.md).

## 5. 참고: 첫 판(TTS 7문장, 구 채점식)

macOS TTS 7문장(`liplab-lab/data/ex_corpus`), 깨끗 대 뭉갬. ASR 정확 전사 0/14, D-GOP(구 채점식
`naive × confidence`) 2.87 → 0.49(−83%). 합성음은 ASR 학습 분포와 달라 깨끗한 조건의 전사 실패가 과장되었고,
구 채점식은 통합 브랜치에 없다. 결론에는 쓰지 않는다.
