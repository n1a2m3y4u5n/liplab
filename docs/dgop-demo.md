# B 실증 — 전사 비의존 발음채점(D-GOP)의 견고성

고도화계획서 §3.2(B)의 핵심 논지 — "발음평가가 ASR 전사에 의존하면 대상(농인·난청)에게서 붕괴하지만,
목표 음소열에 강제정렬해 직접 채점하는 D-GOP는 명료도에 반응해 견딘다" — 를 문장 클립 7개로 측정한 결과다.

> **정정(2026-09-23).** 이 문서의 첫 판은 7개 클립을 "실제 음성"이라고 적었으나, 클립은 사람 발화가 아니라
> macOS TTS(`say -v Yuna`)로 만든 합성음이다(`liplab-lab/tools/build_examples.sh`). 아래 결과는 합성음 기준이며,
> 실제 발화 근거는 마지막 절(538 정상 대 608 언어청각장애 CER)에 따로 적는다.

## 방법
- 데이터: macOS TTS(Yuna)로 합성한 한국어 문장 클립 7개(`liplab-lab/data/ex_corpus/ex1~7.wav`, 16kHz), 전사(`.lab`) 보유
  — 같이 밥 먹어요 / 굳이 그래야 해? / 좋다 / 국화가 폈어요 / 안녕하세요 / 물 주세요 / 반갑습니다.
- 조건: **깨끗**(원본) vs **뭉갬**(명료도 저하 프록시 = 저역통과 800Hz + 말속도 1.3배).
- ASR 전사: `kresnik/wav2vec2-large-xlsr-korean` CTC greedy 디코드.
- D-GOP: `backend/dgop_acoustic.py`(torchaudio forced-align + `dgop.py` 불확실성 보정).
- 재현: `liplab-lab/tools/dgop_demo.py`, 원자료 `liplab-lab/notes/dgop_demo_results.json`.

## 결과 (7클립 × 2조건 = 14)
| 지표 | 값 |
|---|---|
| ASR 정확 전사 | **0 / 14** (깨끗한 발화조차 정확히 못 옮김) |
| D-GOP 평균 (깨끗) | **2.871** |
| D-GOP 평균 (뭉갬) | **0.486** |
| 뭉갬 시 D-GOP 하락 | **−83.1%** |

클립별로도 명료도 저하 시 D-GOP가 일관되게 급락한다(예: 안녕하세요 4.30→0.40, 물 주세요 4.40→0.30,
반갑습니다 5.20→0.10). 반면 ASR은 두 조건 모두에서 다른 실단어로 확신 오전사한다
(안녕하세요→"안경하세", 뭉갬→"런변을 돼"; 반갑습니다→"값습니다", 뭉갬→"삼백 아라").

## 해석
1. **전사는 채점 근거로 불안정하다** — 명료도가 떨어지면 전사는 무음이 아니라 *다른 실단어*로 옮겨
   채점 근거가 무너진다. 다만 깨끗한 조건의 전사 실패(0/14)에는 TTS 합성음과 ASR 학습 분포의 차이가
   섞여 있으므로, 이 수치만으로 실제 발화의 전사 붕괴를 주장할 수는 없다(실제 발화 근거는 아래 절).
2. **D-GOP는 전사 없이 명료도에 반응한다** — 목표 음소열에 정렬해 프레임이 얼마나 목표대로 발음됐는지를
   직접 재므로, 명료도 저하에 비례해 점수가 떨어진다.

## 실제 발화 근거: 538 정상 화자 대 608 언어청각장애 화자 CER
- 2026-09-18 로컬 측정(연구 노트 기록, 재현 스크립트 `liplab_gpu_snapshot/validate_b_local.py`).
- ASR: 같은 `kresnik/wav2vec2-large-xlsr-korean` CTC 그리디 디코드. 608은 세션 단위 낭독 wav를 30초
  청크로 디코드해 이어붙인 뒤 전사와 비교했다.
- 결과: 정상(AI Hub 538, n=40) CER **0.219**(중앙 0.194) 대 608 언어청각장애 3화자(n=5) CER **0.401**
  (중앙 0.366), 약 **1.83배**.
- 한계: 608 표본이 5개·3화자로 작고, 이 비교는 전사 붕괴만 보인다. 같은 발화에서 D-GOP가 정상과
  청각장애를 구분하는지는 아직 측정하지 않았다.

## 한계 (정직)
- 7개 클립이 TTS 합성음이다. 538 실발화 클립(`liplab_gpu_snapshot/expand538`, 10화자 300개)으로
  같은 측정을 다시 해 이 표를 대체할 예정이다.
- D-GOP 점수는 원 GOP 스케일(0~수)로, 앱 표시용 `calibrate_score` 매핑과 별개다. 여기서 핵심은
  절대값이 아니라 조건 간 상대 하락폭이다.
- 명료도 저하는 실제 농인 발화가 아니라 신호 프록시(저역통과·속도)로 근사했다.
