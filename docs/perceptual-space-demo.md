# 데이터 기반 지각 공간(축 C) 소규모 실증

고도화계획서 §3.3(C)의 목표 수준은 "설계와 소규모 실증"이다. 앱의 채점과 난이도 지수는 손으로 코딩한
시각 자질(`backend/perceptual_space.py`: 조음 위치 = 입모양, 방식은 약한 보조)로 만든 지각 공간을 쓴다.
이 실증은 실제 사람의 입모양 데이터로 공간을 만들었을 때 손코딩 공간과 얼마나 맞는지, 입모양 그룹(비심)이
데이터에서 실제로 갈리는지를 본다. 스크립트 `scripts/c_perceptual_demo.py`, 결과 `docs/perceptual-space-demo.json`.

## 1. 데이터와 방법

- **데이터.** AI Hub 538(OLKAVS) 10화자 300문장. 입모양은 MediaPipe 블렌드셰이프(입 주변 27차원),
  음절 시각은 wav2vec2 강제정렬(`build_cd` v2, 298문장 중 281문장 정렬). RunPod GPU 세션(2026-09-23)에서 추출했다.
- **구간.** CTC 강제정렬 구간은 음절당 1~3프레임으로 짧아, 그대로 평균하면 모든 자모 쌍의 코사인 유사도가
  0.99 안팎으로 거의 갈리지 않았다. 그래서 음절 창을 이웃 음절과의 중간점까지 넓히고, 앞 35%를 초성,
  30~70%를 모음 구간으로 잘랐다. 초성 ㅇ(무음)은 뺐다.
- **정규화.** 화자마다 27차원을 z-정규화해 얼굴·녹화 차이를 줄였다.
- **평가.** 대본을 공유하는 화자를 같은 폴드에 묶은 5폴드(`folds.py`)로, 학습 화자의 비심 중심점에 가장 가까운
  비심으로 평가 화자의 구간을 분류했다. 데이터 공간은 LDA(선형 판별)로 만들고, 그 공간의 자모 중심점 거리와
  손코딩 공간의 거리(1 − 코사인 유사도)의 스피어만 상관을 계산했다.

## 2. 결과

구간 11,583개(자음 4,938, 모음 6,645).

| | 자음(비심 5종: 양순·치경·연구개·성문·경구개) | 모음(비심 5종: 개방·전설·원순·중설·이중) |
|---|---|---|
| 균형 정확도(클래스별 재현율 평균) | 0.345 | 0.386 |
| 우연 수준 | 0.200 | 0.200 |
| 전체 정확도 / 최빈 기준선 | 0.303 / 0.430 | 0.392 / 0.286 |
| 데이터 공간 대 손코딩 공간 거리 상관(스피어만) | 0.30 | 0.22 |

데이터 공간에서 가장 가까운 쌍:
- 모음: ㅐ-ㅔ, ㅓ-ㅕ, ㅙ-ㅚ, ㅙ-ㅝ, ㅛ-ㅝ, ㅔ-ㅖ. ㅐ/ㅔ와 ㅙ/ㅚ는 현대 한국어에서 소리가 합쳐진 쌍이라,
  데이터가 알려진 혼동을 스스로 드러냈다.
- 자음: ㄹ-ㄱ, ㄹ-ㄲ, ㅌ-ㅈ, ㄱ-ㄲ, ㅅ-ㅈ, ㄸ-ㄴ. 모두 손코딩 공간의 "입 안쪽 무리"(치경·연구개·경구개)
  안의 쌍으로, 입 안쪽 자음이 눈으로 잘 갈리지 않는다는 규칙과 맞는다.

## 3. 해석

- 화자를 바꿔도 비심 그룹은 우연보다 잘 갈린다(자음 0.345, 모음 0.386 대 0.2). 입모양 데이터에 비심 구조가
  실제로 들어 있다는 근거다. 다만 절대 수준은 낮아, 짧은 음절 구간의 평균 블렌드셰이프만으로는 개별 음절을
  읽기 어렵다(D 립리딩 정확도가 낮은 것과 같은 이유).
- 데이터 공간과 손코딩 공간은 약하게 같은 방향이다(0.22~0.30). 손코딩 공간은 조음 위치를 주 신호로 두는데,
  데이터는 모음 문맥(동시조음)과 구간 경계 오차의 영향을 함께 받는다. 채점 계수를 데이터 공간으로 바로
  대체할 근거로는 약하고, 손코딩 규칙을 유지하면서 데이터 공간은 혼동 쌍 발굴(예: ㅐ-ㅔ)에 보조로 쓰는 것이
  현재 증거에 맞는다(계획서의 "대체"와 다른 결정, 결과보고서에 편차로 적는다).
- LDA 공간은 전체 화자로 적합했으므로 거리 상관은 서술 통계다. 일반화 성능은 위 화자 분리 분류로 본다.

## 4. 한계와 다음 단계

- 10화자뿐이고, 파일명의 넷째 필드가 모두 F라 한쪽 성별일 가능성이 있다(필드 뜻은 추정). 세션 2에서
  20화자를 더해 다시 계산한다.
- 음절 창을 비율로 자른 근사다. 자모 단위 강제정렬(팀원 A-2 정렬기 또는 MFA)로 경계를 잡으면 나아질 수 있다.
- 대조학습(같은 비심은 가깝게, 다른 비심은 멀게) 임베딩은 이 데이터 규모에서 LDA와 차이가 작을 것으로 보여,
  화자를 늘린 뒤 시도한다.
