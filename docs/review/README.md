## 2. 가장 중요한 문제

1. **쉬운 한국어 E44(파일럿 참여 안내, `ProfilePage.jsx:241`).** '가명'을 '가짜 이름(가명)'으로 풀었다. 실제로는 이름이 아니라
   비밀키로 만든 번호(`pid`, `docs/pilot-data-spec.md` 3절)라 설명이 사실과 다르고, 연구 참여 화면에서 '가짜'라는 말은 신뢰를
   떨어뜨린다. 제안: "학습 기록은 이름과 이메일을 빼고, 이름 대신 붙인 번호(가명)로만 연구에 쓰여요." 연구윤리 담당 확인이 필요하다.
2. **파일럿 문장 16개가 훈련 문장과 겹친다.** 빌드 스크립트(`scripts/build_pilot_manifest.py`)는 띄어쓰기를 뺀 **완전 일치**만
   거르므로 한두 낱말만 다른 문장이 통과했다. 대화 대체 문장('맛있게 드세요.'·'잠시만 기다려 주세요.'·'조심히 가세요.'),
   상황 기본 문장('머리가 아파요.'), 말하기 문장('오늘 날씨가 좋아요.'), 9/29에 새로 서빙한 문맥 문항('창문 좀 열어 줄래?'·
   '손을 깨끗이 씻어.'·'엄마랑 시장에 가서')과 거의 같다. 훈련은 B 회차 전에만 하므로, 겹친 문장은 B 점수를 부풀려 학습 효과를
   크게 보이게 한다. 같은 폼 안의 SA01 '감기에 걸렸어요' ⊂ SA39 '동생이 감기에 걸렸어요'도 한 회차 안에서 뒤 문항을 쉽게 만든다.
3. **뜻 없는 말 4개가 소리 내면 실제 말이다.** 생성기는 글자 그대로만 사전과 대조해, 표준 발음과 ㅐ·ㅔ 합류를 보지 않는다.
   - 학습 `ns05` **게급**: '계급'은 표준 발음에서 [게급]도 허용된다.
   - 폼 B `NB03` **체림**: ㅐ·ㅔ가 같은 소리라 배우 이름 '채림'과 같다.
   - 폼 C **자겍**: '자객'과 같은 소리.
   - 폼 C **허참**: 감탄사 '허 참'이고 널리 알려진 방송인 이름. wordfreq 목록에 없어 걸러지지 않았다.
   - 권하는 고침(코드는 고치지 않음): 대조하기 전에 ㅔ→ㅐ, (ㅇ 밖의 첫소리 뒤) ㅖ→ㅔ로 바꾼 꼴도 함께 사전과 대조. 학습 목록(게급)을 바꾸면
     같은 시드의 뒤 목록이 바뀔 수 있으니, 폼 A·B를 지키려면 학습 목록은 손으로 한 낱말만 바꾸는 쪽이 안전하다.
4. **문맥 문항 140번(g3934e0dd) '카드에 작은 ___이 박혀 있어.'** 오답 '침'(벌침·바늘)을 넣어도 말이 되어 답이 둘로 읽힌다.
   고치지 않으면 **제외**를 권한다. 제안: "교통카드 안에 작은 ___이 들어 있어."(`check_closure` 통과).
5. **문맥 문항 오답 둘이 문법만으로 지워진다.** 78번 '여부가'(여부는 홀로 주어가 되지 않음), 103번 '푹이'(푹은 부사). 확장 문서 3절
   4항이 막으려던 경우다. 제안 오답 '거부', '몫'은 `_visually_confusable`과 `check_closure`를 통과한다.
