## 2. 확인했고 문제가 없던 것

- 음소거: 음소거면 마스터를 출력에 잇지 않는다. 보통·전화·방·보코더·소음·천천히(MediaElementSource) 모든 경로가 제한기를 거쳐 출력에 닿고, 음소거면 어느 경로도 출력에 닿지 않는다(그래프를 따라가 확인).
- MediaElementSource를 같은 `<audio>`에 두 번 붙이는 오류: 천천히 재생마다 새 `<audio>`를 만들어 생기지 않는다. 이번에 재생이 끝날 때 노드를 끊도록 했다.
- outputLatency: 정의되지 않았거나 0이면 null, 입모양 지연 0(덜 보정 쪽).
- 잡음 크기: 다섯 잡음 파일의 전체 RMS와 활성 레벨 차이 0.06 dB 이하(경쟁 화자 흐름의 쉼이 80 ms로 짧다). 전체 RMS를 그대로 써도 된다.
- 전화·방 판의 크기 재측정: 둘 다 만든 뒤 활성 레벨로 다시 잰다.
- 렌더 시간(이 맥, 1.36초 문장): 전화 11 ms, 방(0.8초) 24 ms, 보코더 44 ms, 소음 섞은 보코더 약 60 ms. 저사양 폰은 몇 배가 될 수 있으나 보코더·전화·방 판은 기억해 두 번째부터 0 ms다. 섞은 보코더는 SNR과 잡음 위치가 매번 달라 미리 만들지 않았다.
- 요약 성능: 시행 5천 건 83 ms, 3만 건 0.56초(ORM 전체 읽기가 대부분). 3만 건은 하루 100시행으로 약 10개월이라 지금은 두었다.
- KST 날짜: 시드·복습·요약 날짜 모두 created_at + 9시간, `_kst_today()`로 같다. due_reviews는 마지막 시도 다음 날(0시 KST)부터, 맞힌 뒤 사흘 뒤부터이고 두 번 맞히면 빠진다(경계 그대로).
- 다른 사용자의 회차 문자열 재사용: 회차 조회가 모두 user_id로 묶여 섞이지 않는다.
- 잠긴 단계·다시 쓴 답: session 'practice'로 남아 숙달·계단·내보내기에 들어가지 않는다.

## 3. 화면 담당에게 넘길 것

1. 소리+입모양 시행의 시작 맞추기(`SentenceTask` play): 지금은 누른 순간부터 `avOffsetMs()` 뒤에 입모양을 띄운다. 인공와우 모의에서는 보코더 렌더(이 맥 약 60 ms, 폰은 더 김)만큼 소리가 늦게 시작해 입모양이 앞선다.
   playClip에 `onStart(delayMs)`를 더했다(준비가 끝나 말소리가 delayMs 뒤 그래프에서 나온다는 알림). `opts.onStart = (d) => setTimeout(() => setPlayFrames(fresh), d - 300 + offset)`처럼
   알림을 받은 때부터 재면 렌더 시간과 상관없이 맞는다(MouthAvatar 앞 중립 300 ms를 뺀 값).
2. 검사·낱말 검사 답 실패 처리: 서버가 같은 답 재전송에 그때 결과를 돌려주므로(B4), 응답 없이 끊긴 경우(`!e.response`) 같은 본문으로 한 번 다시 보내면 검사를 이어 갈 수 있다. 지금은 연결 오류면 아무 표시 없이 멈춰 있다.
3. 결과 화면 7일 막대(`lib/listenReport.dayBars`)는 아직 시행 수(n)를 쓴다. days[i].minutes가 생겼으니 권장 15~20분과 비교하려면 이것을 쓰면 된다.
4. 검사를 중간에 그만두고 다시 시작하면 같은 폼이 다시 나온다(폼 순서는 마친 검사 수로 정함). 이미 들은 문장을 다시 듣는 연습 효과가 사전 검사에 섞일 수 있다. 폼 순서 규칙(test_form_for)은 콘텐츠·검사 담당과 정할 일이라 고치지 않았다.

## 4. 다른 담당 영역에서 본 것(고치지 않음)

- 내보내기 `listen_export`의 trials_by_stage는 계정 전체이고 참여 코드 뒤(since_join)로 나누지 않는다. 다른 집계는 둘 다 준다.
- 낱말 고르기는 item_key(`w:낱말`)에 정답이 드러나고 수준도 화면이 보낸다(±1만 받음). 학습자 자신의 기록이라 막지 않았다. 훈련 SNR도 화면이 보낸 값을 기록한다(실제로 들려준 값을 남기는 쪽이 맞아 그대로 둠).
- 검사 시작이 회차를 저장하지 않아 화면이 폼을 골라 보낼 수 있다(지금 화면은 서버 값을 그대로 쓴다).
- 잡음 버퍼는 62초 × 48 kHz라 하나에 약 12 MB, 5단계에서 네 종류를 돌리면 약 48 MB가 남는다. 종류 수가 정해져 있어 상한은 있다.
