# ROI + 입술 좌표 잔차 결합 개발 선택 사전 등록

2026-11-02 추가 지시(spec-nextreg-fill.md)에 따른 새 후보다. 질문은 BS27에 도움을 준 정규화 입술 좌표80이 B33 ROI 픽셀 모델에도 도움이 되는가다. **검증12명으로 고르는 개발 선택이며 판정·독립 평가가 아니다.** 앱·기본 플래그·배포는 바꾸지 않는다.

자료는 기존 B33 `run_base/prep.json`과 ROI pack의 학습33명·검증12명만 사용한다. 평가19명·clean_eval·E2·KMSAV·OLKAVS는 사용하지 않는다. 기존 prep의 학습 문장 제외, 문장/어절 목록, 쉬는 구간, 검증 문항과 문장 목록을 그대로 쓰며 좌표 결측을 이유로 클립·문항을 삭제하지 않는다. prep에 명시된 허용 클립의 `train538/rebuild/real_bs/<clip>.json`만 연다. ROI 전역 프레임 offset과 동일한 순서의 좌표 float32 pack을 만든다. JSON의 원 프레임 `t_ms`를30fps 프레임 번호로 반올림해 재색인하고 결측을 좌표별 선형 보간(양끝 최근값)한다. 전부 결측이면0으로 채우고 그 수를 보고한다. ROI와 원 JSON 길이 차이가2프레임을 넘거나30fps 계약이 아니면 실행 전 중단한다. 입력과 prep SHA256·결측 수를 저장한다.

B33 픽셀 전단(256출력)·LayerNorm→BiGRU3층256→53자모CTC 후단은 그대로다. 좌표80→LayerNorm80→Linear80×64→GELU→Linear64×256을 별도 경로로 추가하고 프레임마다 ROI256에 더한다. 추가 파라미터21,984개이며 연결 후 후단은 그대로256입력이다. 정규화 좌표는 눈꼬리 거리·회전·입술 중심 보정된 JSON lips80 그대로다. 기존 픽셀 전단과 후단을 먼저 초기화한 뒤 좌표 경로를 초기화해 같은 시드의 기존 가중치 초기값을 보존한다. 외부 모델/1080 열화 후보 가중치로 초기화하지 않는다.

시간 속도0.8~1.25·동일 화자 idle75 프레임은 기존 B33에서 뽑은 동일 전역 프레임 번호를 두 경로가 공유한다. ROI 무작위 crop은 기존대로이며 좌표는 이미 얼굴 기준 정규화돼 crop 이동을 적용하지 않는다. 좌우 반전은 같은 동전값을 쓰고 좌표 점 대응 `LIPS_MIRROR`와x부호 반전을 적용한다. 시간 마스크는 같은 프레임을 두 경로에서0으로 만들고 좌표 임베딩도 마스크해 bias가 남지 않게 한다. 패딩 좌표/임베딩은0이며 길이와 CTC 표적은 동일하다. 좌표 잡음·별도 시간 증강은 추가하지 않는다.

학습은 B33와 같은 seed0, AdamW lr3e-4·wd1e-4, 배치32, 유효 프레임4000 초과 시 같은 배치 평균의 기울기 누적, 최대40에폭, 매2에폭 검증, patience6, 기울기 상한5, idle확률0.5, AMP bf16=1이다. 검증은4지 hard ctc_ll α1·idle75·dup1/2 화자평균의 평균과 문장 자모CER이다. 같은4지 값으로 각 모델의 최고 체크포인트를 선택한다. 기준은 기존 완료된 같은 시드 B33의 최종 선택 모델·요약이며 새로 기준을 학습하거나 에폭을 다시 고르지 않는다.

**후보−같은 시드 B33의 검증4지 평균 ≥+0.02이고 선택 체크포인트의 검증 문장CER 차이 ≤+0.02일 때만 관문 통과다.** seed0을 한 번 실행하고 두 조건을 모두 넘을 때만 seed1을 한 번 실행한다. seed1도 같은 두 조건을 넘어야 개발 경로를 보존한다. 하나라도 미달하면 이 결합 경로를 보류하고 추가 시드·임계값·분할 변경을 하지 않는다. seed별 비교JSON은 덮어쓰지 않는다. 검증 화자는 이미 여러 개발 선택에 사용됐으므로 통과해도 새 평가 성능이나 사람 독화 향상이라고 주장하지 않는다. 깨끗한 평가는 나중의 별도 등록을 기다린다.

lab-sub RTX3060에서 GPU당 하나, S4U 예약 작업으로 연결 독립 실행한다. 시작 전 nvidia-smi로 다른 GPU 학습·DACON 없음과 시스템 여유16GB 이상을 확인한다. KMSAV CPU 판정에 양보하도록 OMP/MKL/OpenBLAS/Torch CPU스레드2, 디스크 미리읽기 작업자1개로 제한한다. 메모리 상한은 B33 원래3060 설정0.45다. GPU 시작 후 실제 프로세스·GPU 메모리 사용을 기록한다. OOM/입력 계약 오류이면 조용히 설정을 바꾸거나 시드를 반복하지 않고 오류와 미완료를 보고한다.
