# 말하기 전사 경로 채점과 D-GOP의 실제 청각장애 발화 검증(2026-09-28, 확인 전 기준)

## 목적

1. 전사 경로(D-GOP가 꺼졌거나 실패할 때 Whisper 전사 + 음운 유사도)는 맞힌 정도를 정답 길이로만 나눈다(재현율). 덧붙인 음절을
   감점하지 않아, 전사가 길게 나오면(환각·다른 말) 목표와 무관해도 통과할 수 있다(감사 S1 (b)). 정밀도를 넣은 F1로 바꿀지 정한다.
2. 무음·잡음 녹음에서 Whisper가 환각 전사를 내는지, vad_filter가 이를 막는지 잰다.
3. 계획서 2.5(당사자 발화 전이 가정)·2.6-①: 자체 D-GOP가 실제 청각장애 발화(AI Hub 608 감음신경성)에서 맞게 말한 문장과
   다른 문장을 얼마나 가르는지, 전사 경로와 나란히 잰다.

## 자료와 절차

- 538: 정상 화자 문장 클립 1,740개(`~/Downloads/liplab_gpu_snapshot/expand538_more`). 608: 감음신경성 청각장애 화자 27명의
  읽기 세션을 large-v3 단어 타임스탬프로 문장 단위로 자름(대본 문장과 SequenceMatcher 0.5 이상인 구간, 486문장 중 360문장, 24명).
  자료는 RunPod 파드에서만 처리하고 저장소에 넣지 않는다(국외 반출 확인 범위: RunPod 처리).
- 전사: 앱과 같은 설정(faster-whisper 1.x base, CPU int8, 빔 1, 온도 0, 한국어), vad_filter 없음(앱)·있음.
- D-GOP: 앱과 같은 자체 정렬기·채점기(int8, CPU), 보정 점수.
- 맞게 말함 = 클립 자기 문장을 목표로, 다르게 말함 = 음절 수 ±30%인 다른 문장을 목표로(클립마다 2~3개).
- 화자 해시 절반 0에서 탐색, 절반 1에서 확인(`scripts`의 analyze 스크립트, 결과 전에 이 기준을 적음).

## 확인 기준(전사 경로 채점을 R0 재현율 → R1 F1로 바꾸는 조건)

탐색 절반에서 R1의 합격선 t를 'R1의 맞게 말함 불합격률 ≤ R0(65점)의 불합격률 + 1%p'가 되는 가장 높은 값으로 정한 뒤, 확인 절반에서:
- C1 맞게 말함 불합격률(538·608 각각): R1(t) ≤ R0(65) + 2%p.
- C2 다르게 말함 합격률(538·608 합): R1(t) ≤ R0(65) × 0.8(20% 이상 감소).
- C3 잡음 전사가 5단계 문항에 합격하는 비율: R1(t) ≤ R0(65).
하나라도 실패하면 R0을 그대로 둔다. vad_filter는 잡음 환각 비율이 줄고 C1이 1%p 넘게 나빠지지 않을 때만 켠다.
D-GOP 대 전사 비교는 판정 없이 수치(AUC, 합격선에서의 불합격·오합격률)를 보고한다.

## 탐색 결과(화자 해시 절반 0, 538 30명 900클립, 608 13명 200문장, vad 없음)

- 합격선 65에서 R0 맞게 말함 불합격 538 1.0%·608 8.5%, 다르게 말함 합격 538 0.4%·608 9.4%. 잡음 전사가 5단계 문항에 합격하는 비율
  R0 28.1%(잡음 25개 중 4개가 '이 영상은 영상에서 …' 같은 환각 전사), R1 0%. vad_filter를 켜면 잡음 전사 0/25.
- R1 합격선 t: 기준(두 세트 모두 불합격률 ≤ R0(65) + 1%p)을 만족하는 최댓값 66.4를 내려 **t = 66**으로 확인한다.
