# 말하기 전사 경로 채점과 D-GOP의 실제 청각장애 발화 검증(2026-09-28, 확인 전 기준)

## 목적

1. 전사 경로(D-GOP가 꺼졌거나 실패할 때 Whisper 전사 + 음운 유사도)는 맞힌 정도를 정답 길이로만 나눈다(재현율). 덧붙인 음절을
   감점하지 않아, 전사가 길게 나오면(환각·다른 말) 목표와 무관해도 통과할 수 있다(감사 S1 (b)). 정밀도를 넣은 F1로 바꿀지 정한다.
2. 무음·잡음 녹음에서 Whisper가 환각 전사를 내는지, vad_filter가 이를 막는지 잰다.
3. 계획서 2.5(당사자 발화 전이 가정)·2.6-①: 자체 D-GOP가 실제 청각장애 발화(AI Hub 608 감음신경성)에서 맞게 말한 문장과
   다른 문장을 얼마나 가르는지, 전사 경로와 나란히 잰다.

## 자료와 절차

- 538: 정상 화자 문장 클립 1,740개(`~/Downloads/liplab_gpu_snapshot/expand538_more`). 608: 감음신경성 청각장애 화자 27명의
  읽기 세션을 large-v3 단어 타임스탬프로 문장 단위로 자름(대본 문장과 SequenceMatcher 0.5 이상인 구간, 486문장 중 360문장, 24명).
  자료는 RunPod 파드에서만 처리하고 저장소에 넣지 않는다(국외 반출 확인 범위: RunPod 처리).
- 전사: 앱과 같은 설정(faster-whisper 1.x base, CPU int8, 빔 1, 온도 0, 한국어), vad_filter 없음(앱)·있음.
- D-GOP: 앱과 같은 자체 정렬기·채점기(int8, CPU), 보정 점수.
- 맞게 말함 = 클립 자기 문장을 목표로, 다르게 말함 = 음절 수 ±30%인 다른 문장을 목표로(클립마다 2~3개).
- 화자 해시 절반 0에서 탐색, 절반 1에서 확인(`scripts`의 analyze 스크립트, 결과 전에 이 기준을 적음).

## 확인 기준(전사 경로 채점을 R0 재현율 → R1 F1로 바꾸는 조건)

탐색 절반에서 R1의 합격선 t를 'R1의 맞게 말함 불합격률 ≤ R0(65점)의 불합격률 + 1%p'가 되는 가장 높은 값으로 정한 뒤, 확인 절반에서:
- C1 맞게 말함 불합격률(538·608 각각): R1(t) ≤ R0(65) + 2%p.
- C2 다르게 말함 합격률(538·608 합): R1(t) ≤ R0(65) × 0.8(20% 이상 감소).
- C3 잡음 전사가 5단계 문항에 합격하는 비율: R1(t) ≤ R0(65).
하나라도 실패하면 R0을 그대로 둔다. vad_filter는 잡음 환각 비율이 줄고 C1이 1%p 넘게 나빠지지 않을 때만 켠다.
D-GOP 대 전사 비교는 판정 없이 수치(AUC, 합격선에서의 불합격·오합격률)를 보고한다.

## 탐색 결과(화자 해시 절반 0, 538 30명 900클립, 608 13명 200문장, vad 없음)

- 합격선 65에서 R0 맞게 말함 불합격 538 1.0%·608 8.5%, 다르게 말함 합격 538 0.4%·608 9.4%. 잡음 전사가 5단계 문항에 합격하는 비율
  R0 28.1%(잡음 25개 중 4개가 '이 영상은 영상에서 …' 같은 환각 전사), R1 0%. vad_filter를 켜면 잡음 전사 0/25.
- R1 합격선 t: 기준(두 세트 모두 불합격률 ≤ R0(65) + 1%p)을 만족하는 최댓값 66.4를 내려 **t = 66**으로 확인한다.

## 확인 결과(화자 해시 절반 1, 538 840클립, 608 11명 160문장, vad 없음 = 앱 설정)

| 기준 | R0(65) | R1(66) | 판정 |
|---|---|---|---|
| C1 맞게 말함 불합격 538 | 0.4% | 0.5% | 통과 |
| C1 맞게 말함 불합격 608 | 18.1% | 20.6% | **실패**(+2.5%p, 허용 +2%p, 160문장 중 4문장 차이) |
| C2 다르게 말함 합격(538+608) | 1.98% | 0.54% | 통과(608만 10.0% → 2.8%) |
| C3 잡음 전사 5단계 합격 | 28.1% | 0% | 통과(탐색 절반 값) |

C1이 실패해 **R0을 그대로 둔다**(사전 기준). vad_filter도 608 맞게 말함 불합격이 18.1% → 20.0%(+1.9%p, 탐색 절반도 +1.0%p)로
나빠져 켜지 않는다. 대신 확인된 사실: 전사 경로는 실제 청각장애 발화의 맞게 말한 문장을 18~20% 떨어뜨린다(정상 화자 0.4%).
환각 잡음이 합격하는 문제(28%)는 소리 없는 녹음을 막는 규칙(9/28, speak_curriculum.no_voice)이 무음은 막지만 잔잡음은 남는다.
스크립트: `scripts/speak_asr_pod_run.py`(파드 전사·문장 자르기), `scripts/speak_transcript_scoring_analyze.py`(채점 비교),
`scripts/speak_dgop_pod_eval.py`(D-GOP).

## 추가: Whisper 반복 루프 접기(9/28, 적용)

잡음 합격의 원인은 반복 루프였다(잡음 4개 모두 '이 영상은 영상에서 …', 실제 발화 전사 2,100개 중 16개도 끝에 '통화 통화 …' 같은
루프). 연속 3번 이상 반복된 어절 묶음(1~6어절)을 한 번으로 접으면(R0 그대로, 전체 자료로 잰 값): 잡음 전사의 5단계 합격 28.1% → 0%,
538 맞게 말함 불합격 0.7% 그대로, 608 12.8% → 13.3%(360문장 중 2개), 608 다르게 말함 합격 8.4% → 7.8%. 이득이 뚜렷하고 손해가 작아
전사 후처리로 넣었다(`speak_service.collapse_repeats`). 사전 기준을 따로 세우지 않고 전체 자료로 판단한 점은 한계로 남긴다.

## D-GOP 결과(9/28, 전체 2,876 채점, 오류 0)

맞게 말함 = 클립 자기 문장, 다르게 말함 = 음절 수가 비슷한 다른 문장 2개. 스크립트 `scripts/speak_dgop_pod_eval.py`, 분석은 같은 화자 해시 절반.

| | AUC | 65점 맞게 말함 불합격 | 65점 다르게 말함 합격 | 맞게 말함 중앙값 |
|---|--:|--:|--:|--:|
| 538 정상(58명, 600문장) | 0.998 | 1.7% | 0.0% | 87.9 |
| 608 청각장애(24명, 360문장) | 0.896 | 17.8% | 3.1% | 81.9 |
| 608 절반 0 / 절반 1 | 0.937 / 0.846 | 10.5% / 26.9% | 2.8% / 3.5% | 83.4 / 79.0 |
| 참고: 전사 경로 R0 608 | 0.926 | 12.8% | 8.4% | |

- D-GOP는 정상 화자에서 거의 완벽하게 가르지만 청각장애 화자에서 AUC가 0.90으로 내려간다. 전사 경로(0.93)보다 약간 낮고,
  65점에서 맞게 말한 문장을 더 많이 떨어뜨리는 대신 다른 문장을 덜 합격시킨다. 화자 절반 사이 차이가 커서(10.5% 대 26.9%) 화자 의존성이 크다.
- 해석 한계: 608의 '맞게 말함'은 대본을 읽은 발화라 실제 조음 오류가 섞여 있다. 불합격 17.8%는 채점기의 불공정 몫과 실제 오류 몫을
  합친 상한이다.
- 화자별(문장 13개 이상 15명) 65점 합격률: 0.00, 0.29, 0.69, 0.71, 0.75, 0.87, 0.88, 0.88, 0.88, 0.92, 0.94, 0.94, 0.94, 0.97, 1.00.
  숙달 문턱 90(4단계)에 닿을 수 있는 화자는 6명, 85(5단계)는 10명, 68은 13명이다. 문장이 1개뿐인 9명은 모두 불합격이라 문장 자르기 실패가
  섞였을 수 있어 화자별 표에서 뺐다.

### 커리큘럼 개선 계획 2-1 판정(`docs/curriculum-roadmap.md`, 기준은 결과 전에 적음)

- 합격선: 절반 0에서 '538 다르게 말함 합격 ≤ 5%' 안의 가장 낮은 값은 56(608 불합격 8.0%). 절반 1 확인에서 56은 538 다르게 말함
  합격 10.0%로 5%를 넘어 실패했다. 50점 부근에 다른 문장 점수가 몰려 있어(중앙값 49.9) 60 아래로 내리면 오합격이 급히 는다.
  **합격선 65 유지.**
- 숙달 문턱: 확인 절반 1의 기대 합격률 73.1%(65점) − 5 = **68**. 4단계 90 → 68, 5단계 85 → 68.
  - 리뷰 뒤 고침: 처음에는 608 전체 82.2% − 5 = 77로 정했다. 계획은 탐색 절반 0, 확인 절반 1이라 확인 절반 값으로 고쳤다.
  - 화자별 65점 합격률(위 15명)에서 68 아래는 2명(0.00, 0.29)이고, 0.69·0.71인 2명은 문턱 바로 위라 이동 평균이 흔들리며 닿는다.
    77이었으면 5명(0.00~0.75)이 아래였다. 문턱 아래 화자는 개인 향상 경로에 기댄다.
- 대체 규칙: 65점에서 608 불합격이 10%를 넘으므로(17.8%) 개인 향상 경로를 더했다. 이 단계 시도 20번 이상이고 최근 10번 점수
  중앙값이 처음 10번 중앙값보다 15점 이상 높으면 숙달(`speak_curriculum.gain_mastered`, `main._bump_speak_progress`).
  15점은 종단 자료 없이 정한 값이라 실제 사용 기록이 쌓이면 다시 본다.
- 리뷰 뒤 고침(9/28): 처음 구현은 이 단계의 SpeakAttempt 점수를 모두 읽어, 복습 세션 시도와 소리 없는 시도(점수 0)가 처음 10번에
  섞여 기준선이 내려갔다. 복습 무음 10번 뒤 늘 30점이면 숙달했다(이동 평균 0). 지금은 복습 시도(`speak_attempts.review`)와 소리 없는
  시도(크기 0, 또는 전사가 빈 문자열이고 점수 0, `speak_curriculum.voiced_attempt`)를 빼고, 소리 없는 이번 시도로는 판정하지 않으며,
  최근 10번 중앙값이 합격선 − 15(합격 65면 50) 이상이어야 한다는 절대 하한을 더했다. 조회도 처음 10번과 최근 9번만 읽는다.
  이 컬럼이 생기기 전의 복습 행은 가릴 수 없다(9/28 이후 배포 전이라 실제 기록에는 거의 없다).
