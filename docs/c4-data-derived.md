# 데이터 지각 공간에서 난이도와 최소대립쌍 도출(C-4)

계획서 §3.3 C-4는 지각 공간에서 채점 계수와 함께 문장 독화 난이도 지수와 최소대립쌍을 도출한다고 했다. 채점 계수(C-3)는
데이터 공간과 손으로 매긴 계수의 자모 쌍 상관이 자음 0.30, 모음 0.22로 약해 규칙을 유지했다(`korean-speechreading-resources.md`).
같은 데이터 공간으로 난이도와 최소대립쌍을 만들어 규칙판과 비교했다.

- 스크립트: `scripts/c4_data_derived.py`(표준 라이브러리만, 부트스트랩 seed 고정)
- 입력: `backend/data/c_jamo_similarity.json`(AI Hub 538, 10화자 300문장, 자음 16개·모음 18개)
- 출력: `backend/data/c4_data_derived.json`(내부용). AI Hub 데이터에서 계산한 값이라 재배포 허용을 확인하기 전까지 공개 자원과
  공개 API에 싣지 않는다.

## 1. 만드는 법

1. **자모 혼동도.** 같은 종류(자음·모음) 안에서 가장 닮은 두 자모와의 데이터 유사도 평균을 구하고, 종류 안에서 0~1로 편다.
2. **단어·문장 난이도(데이터판).** 단어는 초성(무음 ㅇ 제외)과 모음의 혼동도 평균이다. 종성은 데이터 공간에 없어 넣지 않았다
   (단어 528개의 초성·모음 중 99.6%가 데이터 공간에 있다). 문장은 어절 난이도의 평균이고, 문맥 추론 문항 186개의 빈칸을
   정답으로 채운 문장을 썼다.
3. **최소대립쌍(데이터판).** 단어 은행(528개)에서 초성이나 모음 한 자리만 다른 쌍 418개를 찾아, 달라진 두 자모의 데이터 유사도로
   줄 세운다.

## 2. 규칙판과의 비교(10화자판)

| 비교 | 값 | 해석 |
|---|---|---|
| 단어 난이도: 데이터판 대 규칙판 | ρ 0.25 (95% 구간 0.17~0.33, 528개) | 약한 양의 일치 |
| 단어 난이도: 데이터판 대 비가시성 | ρ 0.45 (0.38~0.52) | 안 보이는 음소가 많은 단어를 데이터도 헷갈린다고 본다 |
| 단어 난이도: 데이터판 대 동구형이음 비율 | ρ −0.03 (−0.12~0.06) | 일치하지 않음 |
| 문장 난이도: 데이터판 대 규칙판 | ρ 0.07 (−0.07~0.22, 186개) | 일치하지 않음. 어절 평균이라 문장 사이 차이가 작다 |
| 최소대립쌍: 규칙상 같은 입모양 짝을 데이터 유사도가 가르는 정도 | AUC 0.98 (418쌍) | 자음은 사실상 '입술 닫힘 대 나머지' 구분이다(아래) |
| 　같은 기준, 초성 쌍만 | AUC 0.99 (350쌍) | |
| 　같은 기준, 모음 쌍만 | AUC 0.91 (68쌍) | |
| 　입 안쪽 자음 무리 안에서 같은 입모양 번호끼리 | AUC 0.79 (177쌍) | 거친 구분보다 약하지만 우연(0.5)보다 높다 |
| 자모 쌍 수준(단어 빈도 가중 없이): 자음 입모양 번호 엄격 기준 | AUC 0.76 | |
| 　입 안쪽 자음 무리 안에서만 | AUC 0.68 (66쌍) | |
| 　모음 | AUC 0.78 | |

규칙의 `same_viseme_group`은 입 안쪽 자음(입모양 6·7·8·10)을 한 혼동 무리로 본다. 그래서 자음에서 AUC 0.98~0.99는
입술이 닫히는 자음(ㅂ·ㅃ·ㅍ·ㅁ)과 나머지를 가르는 거친 구분에 대한 값이다. 입술 닫힘은 눈에 가장 잘 띄는 조음이라
이 일치는 예상대로다. 무리 안쪽의 세부 구분(같은 입모양 번호끼리 더 닮았는가)에서는 AUC가 0.68~0.79로 내려간다.

## 3. 규칙과 다르게 나온 쌍

- **데이터만 닮았다고 본 쌍.** 배/비, 패/피(ㅐ·ㅣ, 유사도 0.83), 반/빈, 비/바(ㅏ·ㅣ, 0.70), 신발/선발(ㅣ·ㅓ, 0.71).
  규칙은 ㅐ를 벌린 입(2번), ㅣ를 옆으로 당긴 입(3번)으로 나누지만, 실화자 10명의 입 주변 계수로는 둘이 가깝다.
- **규칙은 같은 입모양인데 데이터는 떨어뜨린 쌍.** 빵/망, 물/뿔(ㅃ·ㅁ, 0.47), 빵/방, 불/뿔(ㅃ·ㅂ, 0.53).
  된소리 ㅃ은 입술을 더 세게 오래 다물어서 평음·비음과 다르게 보일 수 있다. 다만 ㅃ은 데이터에서 드문 자모라 값이 불안정하다
  (자원 문서의 '정직한 한계' 참고).

## 4. 결정

- 채점과 문항 선정은 규칙판을 유지한다. 데이터판은 거친 구조(입술 닫힘 대 나머지, 모음 무리)는 규칙과 맞지만, 난이도 순위는
  단어에서 약하게만 맞고(ρ 0.25) 문장에서는 맞지 않는다. 10화자판으로 문항 난이도를 바꿀 근거는 부족하다.
- 3절의 차이(ㅐ·ㅣ, ㅃ)는 콘텐츠 검수 때 확인할 후보로 남긴다. 규칙 표기를 바꾸려면 화자를 늘린 판에서 같은 방향이 유지돼야 한다.
- 세션 2의 30화자판(C30)이 나오면 `--sim`으로 같은 비교를 다시 돌려 이 표를 갱신한다.

```bash
python3 scripts/c4_data_derived.py                                  # 10화자판(기본)
python3 scripts/c4_data_derived.py --sim <30화자판 c_jamo_similarity 형식 JSON> --out backend/data/c4_data_derived_30spk.json
```
