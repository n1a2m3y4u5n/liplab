# 65% 결합 증류 seed0 개발 선택 사전 등록

사용자의 D65 즉시 실행 지시에 따른 새 용량 후보다. D50·D50 seed1·A의 파일·결과를 바꾸거나 좋은 시드를 다시 고르지 않는다. **D50과 같은 paired 증류에서 학생 ROI 계수만 C65 구조로 늘린다.** 학습33명·검증12명 개발 선택이며 **판정 없음, 깨끗한 평가 대기**다. 앱·플래그·배포·푸시는 바꾸지 않는다.

## 고정 모델·자료

선생은 큰 결합 **seed0 한 파일** 그대로다. SHA256 **42b5fc382377c3a6db4567a989d372b741d8b34504323956bd92bb58ed084c35**,6,068,989파라미터이며 teacher_seed=0이다. 학생은 `nextreg_distill65.build_student()`의 ROI256·후단을 그대로 쓰고 기존 lips80 잔차21,984개를 더한다. ROI3,940,973개(전단741,920·후단3,199,053), 합계 **3,962,957파라미터**다. 내부40×40, stem16, 잔차24·48·96·192 각1블록, 선형256, LayerNorm256→양방향GRU2층 hidden332 dropout0.2→자모53이며 좌표는 LayerNorm80→Linear64→GELU→Linear256을 ROI256에 더한다. 태그는 `fusion_distill65_roi256_lips80_kd_v1`로 분리한다. 이전 학생/선생 가중치로 초기화하지 않는다.

정확도·CER 기준은 같은 seed B33s0의 완료된 선택 PT+요약이며 SHA256 **d499c9f26affd57ef9cc4014c48337669ecfed7466a1ef8ac81c68742007ca1a**다. 기존 B33 prep의 학습33명·검증12명, 문장 제외·어절·idle·검증 문항·프레임 offset과 같은 lips pack(결측2프레임 보간·삭제0)을 유지한다. 평가19·clean_eval·E2·KMSAV·OLKAVS·새 자료는 쓰지 않는다. 캐시·훈련·비교를 위해 자기 사본을 다시 준비하되 공유 원본과 D50 결과를 수정하지 않는다.

## 같은 증류와 단 한 번의 학생 seed0

고정 full fusion seed0을 eval/no_grad로 **train 역할만** 최대400프레임 비중첩 창의 중앙80 ROI+같은 전역 프레임의 lips80에 넣어53로짓 float16 캐시를 만든다. 마지막 창은 실제 길이만 쓰고 검증 영역은 예측하지 않고0으로 둔다. 캐시의 float16은 목표 저장이며 모델/ONNX 가중치는 FP32다. 캐시·선생·좌표·prep SHA와 역할별 수를 남긴다.

학생과 목표는 같은 전역 프레임으로 재색인한다. 속도0.8~1.25·같은 화자 idle75·무작위80자르기·좌우반전0.5·시간마스크≤3과 좌표 점 대응+x부호 반전·동일 시간마스크·패딩 임베딩0을 유지한다. 깨끗한 paired 선생 목표와 증강된 paired 학생의 일관성 증류다. 증강마다 선생을 재실행했다고 부르지 않는다.

손실은 **0.5×CTC + 0.5×T²×유효 프레임 평균 KL, T=2**다. CTC 항목 평균과 KL 전체 배치 유효 프레임 평균을 사용하며 미니그룹 바깥 항목 비율을 KL 안에서 상쇄한다. tuple의 ROI 시간/장치 차원을 사용하고 배치/목표는 동기로 읽는다.

**student seed0 한 번**, AdamW lr3e-4 wd1e-4, 배치32,4000유효 프레임 그룹(같은 배치 평균), 최대40에폭, 매2에폭 검증, patience6회 미개선, 기울기5, idle0.5, **AMP0·CPU4·black cap0.92**를 고정한다. 체크포인트는 기존4지 hard ctc_ll α1·idle75·dup1/2 각각 화자평균 평균의 엄격한 최고값으로 선택하며 CER는 그 체크포인트의 검증 문장 자모CER다. resume·추가 시드·배치/구조/손실/상한 변경 재시도는 없다.

## 네 관문과 다음 시드 제한

다음 네 조건을 모두 만족해야 D65 seed0 관문 통과다.

1. 같은 seed B33s0 대비 검증4지 차이 ≥ **+0.02**.
2. 같은 seed B33s0 대비 검증 문장CER 차이 ≤ **+0.02**.
3. 학생 FP32 ONNX 바이트 ≤ 고정 full fusion seed0 FP32 ONNX의 **75%**.
4. 같은PC·같은입력 WASM CPU 중앙시간 ≤ full fusion seed0의 **60%**.

**seed1은 이번에 등록하거나 실행하지 않는다.** seed0이 네 관문을 모두 통과한 뒤에만 별도 시작 전 등록으로 고려한다. 정확도만 먼저 통과했다고 seed1을 시작하지 않으며, 미달을 다른 시드로 대체하지 않는다. 통과해도 검증12명 개발 선택이고 독립 판정·사람 독화 향상·Android 실측이 아니다. B33/큰 결합의 검증을 다시 계산하지 않고 완료된 요약과 후보의 동일 정의를 비교한다.

## FP32 두 입력과 마지막 WASM 순서

기존 paired wrapper로 두 모델을 FP32·opset17에 내보낸다. 입력은 원화소0~255 `roi[B,T,80,80]`와 정규화 `lips[B,T,80]`, 출력 `[B,T,53]`다. 합성 B1T75 원 PyTorch↔wrapper 및 wrapper↔ONNX CPU 차이<1e-3를 기술 조건으로 확인하며 다른 형식이나 유리한 재측정으로 바꾸지 않는다.

WASM은 lab-sub CNSAi2025·Node24·ORTWeb1.19.2·CPU EP1스레드다. 기존 paired xorshift seed20261102 입력을 쓴다. ROI/lips/합친 SHA256은 각각 **3b2b48ccab377f037ed82015d9cbc84f811392a4c3fa7fa7539a744534c8ccc7**, **7c8383e4a505b00880d73e2079d59cb4167efba8aa112109c8affb14b8ce9ad3**, **0fe46e1232254fb6193d2fd25d295893394894f2058337f67d018fe771b6c2a8**로 고정한다. 모델당5회 예열·20쌍 교대순서, `session.run`만의 각 중앙값 비율을 쓰고 로딩/입력 생성/검사는 타이머 밖이다. 원시20개씩과 PC/CPU/버전·모델·입력 SHA를 보존한다.

**전역 측정 순서는 C0→C1→D0→D1→C65s0→C65s1→D65s0다.** 학습이 먼저 끝나도 C65s1 측정 전에는 D65를 측정하지 않는다. 기존 측정을 반복하지 않는다. 공용 harness의 옛50% 시간 boolean은 쓰지 않고 D65 집계가 원시 중앙값의60% 관문을 계산한다. 파일 관문은 이 등록의75%이며 D50의60%로 혼동하지 않는다.
