# 입모양 목표 검증(V-verify) 사전등록: 기계 확인을 '4지 맞히기'에서 '목표와 맞는가'로(2026-10-17, 측정 전)

이 문서는 측정을 시작하기 전에 질문, 자료 분할, 후보, 선택 규칙, 판정 기준을 고정하고 커밋한다. 실행 뒤에는 9절 이후에
결과만 덧붙인다. 결과를 보고 후보·지표·기준을 바꾸어 다시 판정하지 않는다.

## 1. 질문과 제품 결정

웹캠 기계 확인(`LipReadCheck`)은 지금 4개 보기 중 하나를 맞히는 열린 인식이고, 처음 보는 화자에서 우연 수준이다
(제품 21.2%, V1 재학습 모델 30.1% [27.9, 32.4], `lipread-v1-prereg-2026-10.md` 부록과 V1 판정 FAIL). 그러나 단어 레슨의 학습자는
목표 단어를 이미 안다. 그래서 기계가 할 일을 "무슨 단어인가"에서 "목표 단어를 말한 입모양과 맞는가"로 바꾼다. 말하기 채점기 D-GOP의
시각판이다.

- 제품 결정: 시도 한 번(2.5초 녹화)과 목표 단어 t를 받아 점수 s(x, t)를 내고, s ≥ θ이면 **통과**, 아니면 **"목표와 달라 보여요"로
  표시**한다. 틀린 단어를 말한 시도를 잡아내고, 목표를 바르게 말한 시도는 되도록 통과시켜야 한다.
- 질문: 제품에 그대로 넣을 수 있는 입력(브라우저 MediaPipe 입 블렌드셰이프 27채널)과 모델(이미 학습된 V1 선택 모델, 또는 규칙·작은
  선형 모델)로, 처음 보는 화자 40명에서 바른 시도와 틀린 단어 시도를 이 결정에 쓸 만큼 가를 수 있는가.

## 3. 시도 만들기(합성)

어절 인스턴스(클립 x, 실제 단어 w)마다 아래 짝을 만든다. '입모양 열'은 자모를 7부류(양순 B: ㅁㅂㅃㅍ, 개방 A: ㅏㅐㅑㅒ, 평순 I:
ㅣㅔㅖ, 원순 U: ㅗㅛㅜㅠ, 중설 E: ㅓㅕㅡ, 이중 W: ㅘㅙㅚㅝㅞㅟㅢ, 그 밖 자음 C, ㅇ과 공백은 뺌)로 바꾼 표기상 열이다
(`engine.VISEME_MAP`와 `d_distractor_eval.VIS_CLASS`를 표기 자모에 적용, 발음 규칙은 적용하지 않음).

- 바른 시도(양성): (x, w).
- 다른 단어 시도(음성 N_other): 단어 풀에서 w와 음절수가 같고 입모양 열이 다른 단어 3개, `crc("vverify|other|" + iid + "|" + t)`
  오름차순. 학습자가 목표 t를 받고 다른 단어를 말한 경우의 모사다.
- 입모양 이웃 시도(음성 N_near): V1의 4지 hard 오답(자모 편집거리 최근접 3개, 같은 음절수 우선, seed 777) 중 입모양 열이 w와
  다른 것. 한두 자모만 다른 단어를 말한 경우다.
- 동구형이음(입모양 열이 w와 같은 hard 오답)은 눈으로 구별할 수 없으므로 음성에서 빼고, 표시되는 비율만 보고한다.

## 4. 후보 점수

모두 브라우저에서 돌릴 수 있다(A는 지금 ONNX 계약의 로짓과 `ctcScore.js`의 CTC 전방, B는 27채널 요약 통계와 선형 가중치 수백 개).
LL(t)는 목표 자모열의 CTC 로그우도(blank=0), |t|는 자모 수.

| 후보 | 정의 | 고른 까닭 |
|---|---|---|
| A1 원점수 | LL(t) / \|t\| | 4지 채점(ctc_ll α=1)을 그대로 문턱에 건 기준 |
| A2 GOP | (LL(t) − Σ_τ max_k log p_τ(k)) / \|t\| | 말하기 D-GOP와 같은 꼴, 자유 해독 최선 경로로 클립마다의 우도 크기를 지움 |
| A3 코호트 비 | LL(t) − log mean exp LL(c), c ∈ C(t) | 화자 검증의 코호트 정규화. C(t) = t와 음절수가 같은 풀 단어 30개(음절수마다 `crc("vverify|cohort|" + n + "|" + v)` 앞 30개 고정, t 자신은 뺌). 앱에서는 레슨 단어 은행으로 같은 일을 한다 |
| A4 입모양 코호트 비 | A3을 7부류 공간에서: 자모 사후확률을 부류별로 더하고(ㅇ·공백은 blank에 더함) 목표·코호트의 입모양 열로 CTC 전방 | 눈으로 구별할 수 없는 자모 차이를 점수에서 지워, 입모양이 다른 오답에만 반응하게 함 |
| B1 입모양 윤곽 | 창(75×27)의 채널별 최댓값·평균·표준편차(창 중앙값 기준)와 mouthClose+mouthPress 봉우리 수에서 단어의 부류별 개수(B, A, I, U, E, W)를 릿지(α=10, 표준화 특징)로 예측, s = −Σ_c (예측_c − 개수_c(t))² / σ_c² | 계획의 (b) 입모양 부류 검증. 닫힘·원순·벌림·평순을 블렌드셰이프로 직접 보며, 적합은 학습 화자로만 하므로 CTC 학습 편향이 없다 |
| F 결합 | z(A\*) + λ·z(B1), A\* = A1~A4 중 탐색 1위, λ ∈ {0.25, 0.5, 1, 2} 중 탐색 1위 | 두 정보원이 겹치지 않으면 더해 얻는 몫 |

- (c) 대조 학습 '맞음/안 맞음' 판별기는 이번 후보에서 뺀다. 같은 139명·같은 입력으로 새 모델을 학습해야 하는데 오늘 GPU는 다른 판정이
  쓰고 있고(데스크탑 GPU 프로세스는 한 개만), V1 CTC가 이미 목표 조건부 우도 P(t | x)를 주므로 판별 학습이 더할 몫은 주로 보정이며
  그 몫은 A3·A4의 코호트 정규화가 먼저 잰다. A·B가 기준에 가까우면 새 사전등록으로 시험한다.

## 6. 판정 기준(확인, 한 번)

- 주 지표: 평가 화자 40명의 합동 AUC(양성 대 N_other), 화자 군집 부트스트랩(10,000회, seed 0, 백분위) 95% CI.
- **PASS: AUC ≥ 0.75 그리고 CI 하한 > 0.70 그리고 동결한 θ에서 바른 시도 거부율 ≤ 30%와 N_other 표시율 ≥ 50%. 아니면 FAIL.**
- 기준의 근거: 등분산 이정규 모형에서 AUC 0.75(d′ ≈ 0.95)는 바른 시도를 20% 거부하는 문턱에서 틀린 시도를 약 54% 잡는다. 이보다 낮으면
  학습자는 바르게 말해도 다섯 번에 한 번 '달라 보여요'를 듣고, 틀린 단어의 절반 넘게가 통과한다. 피드백이 맞을 때보다 헷갈리게 할 때가 많은
  선이라 이것을 최소 쓸모로 잡았다. 거부율 30%·표시율 50%는 θ가 새 화자에서 크게 밀리지 않는지 보는 조건이다.
- 보고만(판정에 쓰지 않음): N_near AUC, 부류별 신뢰도(N_near 짝 중 목표와 실제 단어의 B·U+W·A·I 개수가 다른 짝만 모은 AUC),
  동구형이음 표시율, 화자별 AUC 분포, 음절수별 AUC, 후보 전부의 확인 수치, 모델 크기.

### 6.1 기대 효과(측정 전, 있는 근거로 계산)

- 등분산 이정규 모형에서 4지 정확도 a와 짝 비교 AUC는 a 0.30 → 0.55, 0.324 → 0.58, 0.40 → 0.64, 0.50 → 0.72, 0.615 → 0.80으로 대응한다.

  AUC는 약 0.55~0.58로 본다.
- 다른 단어 오답: 9/27 보기 실험에서 입모양이 뚜렷이 다른 보기(C1)가 hard보다 +8.5점이었다(예전 모델, `d-bench-v2.md` 9절). 같은 폭을 V1에
  더하면 4지 약 38~41%, AUC 약 0.63~0.65다. 합동 AUC는 클립 사이의 점수 크기 차이까지 견뎌야 하므로 이보다 낮거나 같다고 본다.
- **기대: N_other 합동 AUC 0.60~0.66, 기준 0.75에 못 미쳐 FAIL이 가장 그럴듯하다.** B1은 블렌드셰이프의 크기 통계만 보므로 단어 길이와
  원순·닫힘 개수 정도만 갈라 AUC 0.55~0.62로 본다. 기준을 기대에 맞춰 낮추지 않는 것은 1절의 제품 결정에 쓸 수 있는지가 질문이기 때문이다.
