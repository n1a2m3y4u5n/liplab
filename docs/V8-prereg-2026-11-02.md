# V8 얼굴 운율 채널 사전 등록 (2026-11-02)

## 질문과 범위

train538의 문장 끝 눈썹 변화가 의문문에서 더 크며, 문장 끝 고개 움직임이 문장 중간보다 큰가. 차이가 없으면 V8 아바타 채널 구현을 진행하지 않는다. 차이가 있으면 기본 끔 플래그 뒤 별도 사람 검증 실험만 제안한다. 이것은 학습 효과나 사람 독화 향상 판정이 아니다.

## 자료·분할·격리

lab-sub `liplab-lab/data/train538/manifest.tsv`의 1,920클립 64명과 `rebuild/real_bs/*.json`만 사용한다. manifest의 물음표(? 또는 ？) 포함 180클립을 의문문으로 정하고 나머지를 평서문으로 정한다. 이 표지는 문장 억양의 실제 주석이 아닌 텍스트 대리다. 내용과 채널 가용성만 확인했고 아직 아래 지표를 계산하지 않았다.

64명은 V1·V3에서 이미 사용됐다. 이 등록은 이전 연구와 독립된 새 화자 확인이 아니며, 사용 이력을 명시한 새로운 채널의 제한된 조건부 분석이다. 탐색으로 값을 고르지 않고 전 화자로 한 번만 계산한다. train538 밖의 영상·모델·봉인 `clean_eval_2026-11`·E2 클립은 읽지 않는다. 집단을 사후 재분할해 통과를 찾지 않는다.

## 고정 측정과 품질

프레임 시각 최솟값~최댓값을 0~1로 정규화한다. 유효 프레임 30개 미만, 전체 구간 1초 미만은 제외한다. 문장 시작·끝 음성 정렬은 쓰지 않으므로 영상 여백의 영향이 남는다. 이 한계 때문에 통과해도 구현 근거는 예비 수준이다.

눈썹 값은 browInnerUp, browOuterUpLeft, browOuterUpRight의 평균이다. 클립 효과는 마지막 20%(t≥0.8) 평균−중간 20%(0.4≤t<0.6) 평균. 화자마다 의문문과 평서문 각각 유효 2개 이상일 때 두 조건 클립 평균 차를 구한다. 적격 화자 20명 미만이면 판정 보류다.

고개 pitch는 fx 4×4 상단 회전행렬의 `atan2(R[2,1],sqrt(R[2,0]^2+R[2,2]^2))`를 도로 환산한다. 절대 pitch의 크기 대신 각 구간 안 연속 프레임 pitch 차 절댓값 합을 실제 시간으로 나눈 deg/s를 쓴다. 구간은 끝 20%와 중간 20%이며 각각 5프레임 이상, 시간 간격 100ms 이하인 쌍만 포함한다. 화자 효과는 모든 적격 클립의 끝−중간 평균. 적격 화자 20명 미만이면 보류다. fx가 없거나 유한하지 않으면 해당 클립 고개만 제외한다.

## 지표·통과·횟수

각 지표는 화자를 같은 가중치로 평균한다. 화자 bootstrap 10,000회, numpy default_rng(20261102), 양측 97.5% 백분위 구간(두 지표 Bonferroni)을 사용한다. 눈썹은 평균 차≥0.02(0~1 계수)이고 구간 하한>0, 고개는 평균 차≥1 deg/s이고 구간 하한>0이면 각각 통과다. V8 전체 통과는 둘 다 통과일 때만이다. 서로 다른 단위를 합치지 않는다.

계산·판정은 등록 커밋 후 한 번이다. 시드·문장군·지표·시간창을 결과에 맞춰 바꾸지 않는다. 얼굴 추출 추가 학습은 없으며 CPU 8스레드 이하로 lab-black에서 실행한다. 실패·결측·품질 탈락 수도 보고한다. 미달은 이 낭독 자료·텍스트 표지·영상 구간 정의에서 근거가 부족하다는 뜻이며, 얼굴 운율 자체가 없다는 결론은 아니다.
