# 말하기 5단계 문장 끝 억양 판정(2026-09-27 늦은 밤, 확인 전 기준)

## 문제

5단계(문장·억양)는 프론트가 녹음 중 약 67ms마다 잰 음높이(유성 프레임만) 가운데 앞 30%와 뒤 30%의 평균을 비교해, 1.33반음을
넘으면 올림, −1.33반음 아래면 내림으로 본다. 한국어 의문문의 상승은 마지막 음절(약 200~300ms)에 몰리는데, 뒤 30% 평균에는 그 앞의
음절(평서 하강으로 낮아진 부분)이 섞여 상승이 묻힌다. 예: "밥 먹었어요?"에서 '요'만 올려도 '평평했어요'가 나올 수 있다.

## 측정(`scripts/intonation_538_contours.py`, `scripts/intonation_measures.py`)

- 자료: AI Hub 538 스냅숏(`~/Downloads/liplab_gpu_snapshot/expand538_more`, 앱 저장소에는 넣지 않는다) 1,737문장. 전사 끝이 '?'이면
  의문문, 마지막 문장에 의문사(뭐·어디·언제·누구·왜·어떻게·몇·얼마 등)가 있으면 의문사 의문문, 없으면 예/아니오 의문문, '.'이면 평서문.
- 음높이: 프론트 `lib/pitch.js`의 autoCorrelate와 녹음 루프(버퍼 42.7ms, 간격 66.7ms, 70~500Hz, 유성 프레임만)를 파이썬으로 옮김.
  참고로 librosa pYIN(313문장)도 쟀다.
- 척도: M0(지금) 앞 30% 평균 → 뒤 30% 평균. M1 마지막 3프레임 중앙값 ← 그 앞 5프레임 최저. M2 마지막 3프레임 중앙값 ← 전체
  중앙값. M3 마지막 3프레임 ← 그 앞 5프레임 중앙값. M1~M3은 3프레임 중앙값 필터 뒤(옥타브 튐 제거).
- 탐색(화자 해시 절반 0, 30명, 예/아니오 51·의문사 35·평서 813, 프론트 추정기):
  예/아니오 대 평서 AUC M0 0.601, M1 0.626, M2 0.649, M3 0.634. 문턱 1.33반음에서 올림 판정 비율(예/아니오·평서): M0 0.22·0.16,
  M2 0.33·0.14. 평서 내림 판정: M0 0.56, M2 0.73.
- pYIN(전체, 예/아니오 90·의문사 68·평서 150): AUC M0 0.540, M1 0.627, M2 0.666, M3 0.627. 예/아니오 의문문도 끝이 1.33반음 넘게
  오르는 것은 36~37%뿐이라 이 자료(읽은 대화체)의 억양 대비는 원래 약하다. 두 추정기 모두에서 M0이 가장 약하고 M2가 가장 낫다.
- 의문사 의문문: pYIN M1 기준 끝 상승 비율이 예/아니오 0.37, 의문사 0.22, 평서 0.21로 의문사 의문문은 평서문과 비슷하다.
  한국어 교육의 일반 기술(설명 의문문은 내림조, 판정 의문문은 올림조)과 맞는다.

## 확인 기준(화자 해시 절반 1, 프론트 추정기, 결과 전에 적음)

모두 통과하면 M2(마지막 3프레임 중앙값 대 전체 중앙값, 3프레임 중앙값 필터, 문턱 1.33반음 그대로)로 바꾼다.

- C1 예/아니오 대 평서 AUC: M2 ≥ M0 + 0.03.
- C2 예/아니오 의문문의 올림 판정 비율: M2 > M0.
- C3 평서문의 올림 판정 비율(틀린 올림): M2 ≤ M0 + 0.03.
- C4 평서문의 내림 판정 비율: M2 ≥ M0.

콘텐츠: 5단계의 '올림' 문항 가운데 의문사 의문문 4개(어디 가요?, 이름이 뭐예요?, 지금 몇 시예요?, 이거 얼마예요?)는 끝을 올리라고
가르치기에 맞지 않아(위 측정과 교육 기술), 예/아니오 의문문으로 바꾼다. 이것은 측정 기준과 따로 적용한다.

## 확인 결과(화자 해시 절반 1, 28명, 예/아니오 40·의문사 37·평서 761, 프론트 추정기)

모두 통과해 넣었다. C1 AUC M0 0.540 → M2 0.670(+0.130). C2 예/아니오 의문문 올림 판정 0.25 → 0.38. C3 평서문 올림 판정 0.14 → 0.15.
C4 평서문 내림 판정 0.53 → 0.70. 의문사 의문문의 올림 판정은 M2에서 0.14로 평서문(0.15)과 같았다.

적용: 프론트 `lib/speakTone.finalTone`(3프레임 중앙값 필터 뒤 전체 중앙값·마지막 3프레임 중앙값)을 `pitch_ref`·`pitch_final`로 보내고,
서버 `speak_curriculum.sentence_direction`이 둘의 반음 차로 판정한다(없으면 예전 척도). 운율 연습(올리기·내리기)은 9/29에 따로 고쳤다:
`lib/speakTone.riseFallTone`이 5프레임 중앙값 필터, 마지막 약 100ms 제외, 앞 30% 중앙값 대 마지막 3프레임 중앙값으로 시작·끝 음높이를
내고 유성 프레임이 6개 미만이면 판정하지 않는다(평평한 200Hz 끝의 옥타브 튐 한 프레임으로 '올리기' 100점이 되던 문제).
5단계 문항의 의문사 의문문 4개는 예/아니오 의문문으로 바꿨고(학교 가요?, 처음 오셨어요?, 지금 바빠요?, 이거 새로 샀어요?), AI가 만든
5단계 문장은 LLM 라벨 대신 `expected_intonation`(문장 부호, 의문사 의문문은 뺌)으로 기대 억양을 정한다.

## 청각장애 화자(AI Hub 608) 확인: 사전 등록(2026-09-29, 측정 전)

위 기준은 538(청인 화자) 음성으로만 확인했다. LIPLAB 사용자인 청각장애 화자의 억양이 이 판정으로 잡히는지 608 음성으로 따로 잰다.

- 자료: 608 라벨(TL02) 가운데 같은 문장을 평서·의문으로 번갈아 읽는 대본('문 열어. 문 열어? 나무가 많아. 나무가 많아? …', 한 세션에
  30쌍)이 143개 세션(화자 이니셜 기준 108명, 이니셜·성별·나이 기준 123명, 32.7시간)이다. 범주는 27 전음성 116, 28 감음신경성 22,
  32 감음신경성 1, 21 조음 4. 청각장애가 아닌 21은 뺀다. 화자(이니셜·성별·나이)마다 20분 이하에서 가장 짧은 세션 하나를 쓴다.
  음성은 TS02를 흘려받아 고른 세션만 16kHz 단일 채널로 줄여 두고, 앱 저장소에는 넣지 않는다.
- 문장 자르기: faster-whisper(large-v3 계열) 단어 시각을 대본 문장에 차례로 맞춘다(한글만 비교, 유사도 0.6 이상). 앞 0.15초·뒤 0.25초를
  더해 자른다. 한 쌍의 평서·의문이 모두 잡히고 의문이 평서보다 뒤에 있으며 각각 0.4~6초인 쌍만 쓴다.
- 음높이·척도: 538과 같은 파이썬 이식(`scripts/intonation_538_contours.py`의 acf_pitch, 42.7ms 버퍼·66.7ms 간격·70~500Hz, 최댓값
  0.5 정규화)과 같은 척도 M0(앞 30% 평균 → 뒤 30% 평균), M2(3프레임 중앙값 필터 뒤 마지막 3프레임 중앙값 ← 전체 중앙값). 유성 프레임
  6개 미만인 문장은 뺀다. 판정 문턱은 앱과 같은 1.33반음.
- 화자 절반: crc32(화자 키) % 2. 조정할 값이 없으므로 절반 0은 설명용이고, 판정은 절반 1로 한다.
- 잴 것: 의문 대 평서 AUC(M0·M2), 평서문의 틀린 올림 비율(M2 > 1.33반음), 의문문 올림 비율, 평서문 내림 비율, 같은 화자·같은 문장
  쌍에서 의문이 평서보다 높게 나온 비율(설명용), 범주별(27 대 28·32) 값(설명용). 옥타브 튐 비율은 한 문장 안 이웃 유성 프레임의
  음높이 차가 9반음 이상인 비율로, 608 전체와 538 전체(위 1,737문장)를 비교한다.

판정(절반 1, M2):

- AUC ≥ 0.60 그리고 평서문 틀린 올림 비율 ≤ 0.20이면 지금 억양 피드백을 이 사용자군에도 그대로 둔다.
- 하나라도 못 미치면 청각장애 사용자에게는 억양 판정을 '참고'로 표시하도록 권고한다. 코드는 권고까지만 적고, 플래그 뒤에서 쉽게
  끌 수 있는 경우에만 바꾼다.

## 608 확인 진행 상황(2026-09-29 오후, 미완료)

판정까지 가지 못했다. 위 기준은 그대로 두고 다음에 이어서 잰다.

- 자료 받기: 화자별 세션 119개(범주 27 101, 28 17, 32 1)를 TS02(약 108GB, 범위 요청이 안 돼 처음부터 흘려받기)에서 받던 중
  20.4GB 지점에서 연결이 끊겼고, 다시 받기를 사용자 요청으로 멈췄다. 받은 것은 범주 27 화자 22명뿐이다(범주 28·32는 파일 뒤쪽이라
  아직 없음). 목록을 만들 때 범주 21을 빼는 필터가 나이 21세 화자 2명(27-LJH, 27-KMK)도 잘못 뺐다. 다음 받기에서 넣는다.
- 문장 자르기: 받은 22세션을 파드(L4)에서 faster-whisper large-v3(빔 5, VAD)로 잘랐다. 세션마다 약 10~50초 걸렸고, 대본 문장
  1,278개 가운데 950개(74%)가 유사도 0.6 이상으로 맞았다(세션별 12/50 ~ 60/60). 억양 척도는 아직 재지 않았다.
- 절반 1 AUC·평서문 틀린 올림 비율: 미측정. 따라서 억양 피드백 유지·'참고' 표시 권고 판정도 아직 없다.
