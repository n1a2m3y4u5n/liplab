# 소음 속 SNR 계단의 목표 정답률·단계 크기·반전 규칙: P3 SNR 맞추기와 소리 듣기 검사(사전 기준과 결과)

작성 2026-10-09. 1~5절은 시뮬레이션을 돌리기 전에 적고 커밋했다. 탐색 결과와 확인 후보는 6절, 확인 결과와 판정은 7절 이후에 덧붙인다.
가상 청취자 모형과 조건 C0~C5는 1차(`docs/listen-adaptive-sim-2026-10.md` 2절, 6.1절)와 같다. 코드는 `scripts/listen_stair_target_sim.py`이며
1·2차 스크립트(`listen_adaptive_sim.py`, `listen_mastery_sim.py`)의 청취자·응답·격자 함수를 가져다 쓴다. 순수 numpy, 맥에서 돈다.

## 1. 문제

근거 문서(`docs/auditory-training-evidence-2026-10.md` 2.6절)와 설계 문서(`docs/auditory-training-design.md` 9절 5항)가 두 계단을 지적했다.

- **P3 SNR 맞추기**(`backend/pilot_battery.py`의 `staircase_run`, 목록 `layers.snr.staircase`). 가중 상하법(Kaernbach 1991), 맞으면 3 dB 내리고
  틀리면 2 dB 올린다. '맞음'은 문장 낱말의 50% 이상. 시작 0 dB, 범위 −20 ~ +10 dB, 반전 8번 또는 24시행에서 멈추고 마지막 반전 6개의 평균이
  개인 SNR이다. 이 SNR에서 시청각 층(av)의 청각만(A)·시청각(AV) 문장을 낸다. 목표는 개인마다 A 낱말 정답률 30~50%이고(가4), 사전 A가
  15% 미만이거나 85% 초과면 'SNR 실패'로 뺀다. 문장 맞음 40%가 낱말 몇 %에 해당하는지, 이 SNR의 정밀도가 목표 띠를 지키기에 충분한지,
  상한 +10 dB가 보청기·인공와우 사용자에게 천장이 되는지는 측정하지 않았다.
- **소리 듣기 4단계 검사**(`listen_curriculum.test_next_snr`·`test_srt`, 연습 5 + 20문장). 1-up-1-down이지만 4어절 문장에서 낱말 2개만 맞혀도
  '맞음'이라 낱말 약 39% 지점으로 모인다(1차 6.2절, 편향 약 −0.75 dB, 인공와우 약 −1 dB). 결과 화면은 이를 '열에 넷쯤 알아듣는' 역치로 적는다.
  1차는 재검사 SD를 25% 줄이는 후보를 찾았으나 기준에 못 미쳤다. 이번에는 **편향(목표 정답률)**을 주 기준으로 다시 등록한다.

훈련 계단(`stair_state`)과 4단계 숙달은 이번 범위에서 뺀다. 1~5차 시뮬레이션에서 목표 정답률을 바꾼 계단 자체는 기준을 지켰지만 숙달
판정과의 조합이 매번 문장당 낱말 상관(C5)에서 갈렸고, 그 결론은 실제 j 측정 전에는 바뀌지 않는다(5차 8절).

## 2. 모형

- 청취자·응답: 1차 2절. 집단 NH 20% N(−4, 1²), HA 40% U(−1, 8), CI 40% U(2, 22), 기울기 s = clip(0.16 − 0.004(SRT + 4) + N(0, 0.015²), 0.05, 0.20).
  조건 C0~C5(문장 난이도 SD 0·1·2·1·1·1 dB, 제시마다 흔들림 0·0·0·2·0·4 dB, C4는 기울기 9%/dB 고정)를 모두 판정에 쓴다.
- 보조 조건 C6(보고만): C1에서 인공와우 집단의 문장 난이도 SD를 3 dB로(가상 청취자 V1 10.6절 제안 2).
- 두 모집단. **혼합**(위 비율, 시드마다 2,000명)과 **정상 청력만**(P3 청인 예비 파일럿 모집단, NH 분포 2,000명).
- P3 문장: SNR 맞추기 24문장의 실제 낱말 수(공백 기준, 3어절 17·2어절 4·4어절 2·5어절 1), 청취자마다 섞은 순서. 시청각 층의 청각만 블록은
  10문장, 낱말 수는 av 폼 A 앞 절반(A 블록 배정)의 실제 값을 쓴다.
- 4단계 검사 문장: 폼 A의 어절 수(1차 2.4절), 연습 5문장은 훈련 문장에서 무작위(2차 `run_test_practice`와 같다).

| P4 | 낱말 비율 걸음, 목표 0.40: ΔL = −f(i)(비율 − 0.40)/0.15, f(i) = max(0.1, 1.5·1.41^−i) | −20 ~ +25 | 늘 24시행 | 격자 사후 평균의 40% 지점 |

- 격자 사후 평균의 40% 지점: 1차 3.1 (c)의 격자(역치 −15 ~ +32 dB 0.5 dB, 기울기 9개)에 편평한 사전분포, 낱말 수 이항 가능도.
  격자 점마다 x40 = θ + ln(0.4/0.6)/(4s)를 구해 사후 평균을 낸다. P4의 f(i)·i는 1차 3.1 (b)의 ICRA 식(i = SNR 변화 방향이 바뀐 횟수)이다.
- P4·P5는 서버가 회차의 답 글에서 낱말 비율을 다시 계산하면 되므로(답과 정답이 `p3_open_responses`에 있다) 기록 형식은 바뀌지 않는다.

### 3.2 소리 듣기 검사(T 후보)

| 이름 | 걸음 | 추정량 |
|---|---|---|
| Ta 지금 | 연습 4 dB, 검사 2 dB, 맞음 = 낱말 비율 ≥ 0.5 | 검사 5~20번째 SNR과 다음 SNR의 평균 |
| Tt | Ta와 같되 낱말 비율이 정확히 0.5면 SNR을 그대로 둔다(연습·검사 모두) | Ta와 같음 |
| Tb | 연습은 Tt, 검사는 1차 b_icra 식(ΔL = −f(i)(비율 − 0.5)/0.15, f 하한 0.1) | 검사 20문장의 격자 사후 평균(50% 지점) |

Tt는 4어절 문장의 '2개 맞음'을 맞음·틀림 어느 쪽에도 넣지 않는다. 맞음과 틀림이 같은 확률이 되는 지점이 낱말 50%가 되어 1-up-1-down의
설계 의도(Levitt 1971)로 돌아간다. 3어절·5어절 문장은 비율 0.5가 나오지 않아 지금과 같다.

## 4. 지표

### 4.1 P 후보

청취자 i의 개인 SNR x̂_i에서 기대 A 정답률 A_i = E[1/(1 + exp(−4 s_i (x̂_i − SRT_i − δ − ε)))](δ·ε는 조건의 문장 난이도·흔들림, 가우스-에르미트 적분)이다.

- 띠 안 비율: A_i ∈ [0.30, 0.50]인 청취자 비율.
- 관측 제외율: x̂_i에서 A 블록 10문장을 실제로 시뮬레이션해 낱말 정답률이 0.15 미만이거나 0.85 초과인 비율(가4 'SNR 실패').
- 평균 A_i, x̂_i의 RMSE(기대 A가 0.40인 SNR 기준), 천장 막힘(기대 A 0.40 지점이 상한 위인데 x̂가 상한인 비율), 평균 시행 수.
- 몬테카를로 표준오차: 비율 √(p(1−p)/N).

### 4.2 T 후보

1차 4.1절과 같다(청취자마다 두 번 검사, 편향·재검사 SD·MDC95·+25 dB 막힘, 집단별).

## 5. 사전 기준

### 5.1 P 후보 채택

탐색 시드 2에서 P1~P5 가운데 **후보 하나**를 정하고(아래 1~4를 모두 만족하는 것 가운데 정상 청력 모집단 띠 안 비율 증가의 조건별 최솟값이
가장 큰 것, 없으면 그 최솟값이 가장 큰 것) 6절에 적어 커밋한 뒤, 확인 시드 3의 C0~C5 **모두에서** 아래를 만족하면 채택한다. 비교 기준은 P0이다.

1. 정상 청력 모집단: 띠 안 비율이 P0보다 5%p 이상 높다.
2. 정상 청력 모집단: 관측 제외율이 P0보다 높지 않다(+0.5%p까지 허용, 몬테카를로 오차).
3. 혼합 모집단 집단(NH·HA·CI)마다 평균 A_i가 0.35 ~ 0.45다.
4. 혼합 모집단 HA·CI: 관측 제외율이 P0보다 높지 않다(+0.5%p까지).

근거: (1) 2,000명에서 비율의 몬테카를로 오차는 약 1%p이고 같은 청취자 짝 비교라 5%p는 잡음으로 넘기 어렵다. 띠 안 비율이 5%p 늘면
파일럿 20~30명에서 한두 명이 목표 난이도로 들어온다. (2)·(4) 'SNR 실패'는 참여자를 잃는 것이라 늘면 안 된다. (3) 0.40 ± 0.05는 띠(30~50%)의 가운데 절반이다.

**범위만 바꾸는 P0w**는 따로 판정한다. 확인 시드의 C0~C5 모두에서 정상 청력 모집단 띠 안 비율이 P0보다 1%p 넘게 낮지 않고, 혼합 모집단 HA·CI의
관측 제외율이 P0보다 낮으면 상한을 +25 dB로 올린다(위 후보가 채택되면 그 후보에 이미 들어 있다).

### 5.2 T 후보 채택

탐색 시드 2에서 Tt·Tb 가운데 후보 하나를 정한다(아래 1~3을 C0~C5 모두에서 만족하면 Tt, Tt가 못 하고 Tb가 하면 Tb, 둘 다 못 하면 재검사 SD 비의
조건별 최댓값이 작은 쪽). 6절에 적어 커밋한 뒤 확인 시드 3의 C0~C5 **모두에서** 아래를 만족하면 채택한다. 비교 기준은 Ta다.

1. 전체 |편향| ≤ 0.3 dB, 집단(NH·HA·CI)마다 |편향| ≤ 0.5 dB.
2. 재검사 SD ≤ 1.05 × Ta의 재검사 SD.
3. +25 dB 막힘이 Ta보다 1%p 넘게 늘지 않는다.

근거: (1) Ta의 편향(약 −0.75 dB, 인공와우 약 −1 dB)을 절반 아래로 줄이는지 본다. 0.3 dB는 1차에서 쓴 0.5 dB보다 엄격하다. 이번 목적이
편향이기 때문이다. (2) 편향을 없애는 대가로 정밀도를 잃으면 결과 화면의 MDC(3 dB)가 커지므로 5%까지만 허용한다(재검사 SD 몬테카를로 오차 약 2%).
(3) 1차와 같다.

### 5.3 채택되면 넣을 것

- P 후보: `pilot_battery.staircase_run`(또는 목록 `layers.snr.staircase` 값)과 `docs/pilot/battery.md` 2절. 목록 판(`version`)을 올린다. 기록 형식은 그대로다.
- T 후보: `listen_curriculum.test_next_snr`·`test_srt`와 `main.py`의 검사 상태. 새 규칙은 **새로 시작한 회차에만** 쓴다(회차 id로 구별).
  이미 있는 회차는 옛 규칙으로 계산해 기록이 바뀌지 않는다. 결과 화면의 역치 설명(지금 '열에 넷쯤')을 새 회차에는 '절반쯤'으로 바꾸고,
  규칙이 다른 두 회차의 비교에는 그 사실을 함께 적는다. 결과 화면 MDC는 1차 5.3절 규칙(채택 절차의 C0~C3 전체 MDC95 최댓값을 0.5 dB 단위로 올림)으로 다시 낸다.
- 배포하지 않는다. 백엔드·프론트 테스트를 통과해야 넣는다.

### 5.4 지키는 것

확인 시드 결과를 본 뒤 기준이나 후보를 바꾸지 않는다. 패키지를 설치하지 않는다. 시드 0·1은 1~5차가 썼으므로 이번에는 2(탐색)·3(확인)을 쓴다.

### 6.1 P3 SNR 맞추기

정상 청력 모집단의 띠 안 비율(기대 A 30~50%)과 관측 제외율(A 블록 10문장 15% 미만·85% 초과).

| 후보 | C0 | C1 | C2 | C3 | C4 | C5 | 띠 안 증가 최솟값 | 기준 1~4 |
|---|---|---|---|---|---|---|---|---|
| P0 지금 | 0.56 / 5.8% | 0.56 / 6.5% | 0.54 | 0.55 / 6.7% | 0.64 | 0.55 / 7.0% | | |
| P0w | 0.54 / 7.1% | 0.55 / 8.0% | | 0.55 / 8.0% | | 0.56 / 7.1% | | 따로 판정, 미달 |
| P1·P2·P3s | | | | | | | −0.08 ~ +0.06 | 미달 |
| P4 | 0.88 / 1.0% | 0.83 / 1.4% | | 0.81 / 2.9% | | 0.76 / 5.1% | +0.204 | 통과 |
| P5 | 0.85 / 1.0% | 0.83 / 1.4% | | 0.78 / 2.8% | | 0.75 / 4.5% | +0.199 | 통과 |

- 지금 규칙(P0)은 정상 청력에서도 기대 A가 띠 안에 드는 사람이 55% 안팎이다. 반전 6개 평균의 흔들림(RMSE 정상 청력 약 1.2 dB)이 낱말 정답률로
  ±0.15 넘게 옮겨 가기 때문이다. 혼합 모집단 인공와우 집단은 상한 +10 dB에 걸려 관측 제외가 39~44%다(참 40% 지점이 +10 dB 위인 사람이 많다).
- 반전 규칙(P1, 늘 24시행)·큰 첫 걸음(P2)·작은 걸음(P3s)은 걸음 규칙만 바꾸고 추정량은 반전 평균이라 거의 나아지지 않았다.
  낱말 수를 모두 쓰는 격자 사후 추정량(P4·P5)이 띠 안 비율을 20~32%p 올리고 제외율을 줄였다. 걸음 규칙의 차이(P4 낱말 비율 대 P5 지금 걸음)는 작다.
- P0w(상한만 +25 dB)는 정상 청력에서 P0과 같은 것이 당연한데 C0·C1에서 비열등(−1%p) 판정이 −2%p로 미달했다. 두 절차가 다른 난수열을 써서
  생긴 몬테카를로 차이다(비율 차의 오차 약 1.6%p). HA 집단 제외율이 C3·C4에서 P0보다 낮지 않은 것도 같은 이유다(HA는 +10 dB에 거의 닿지 않는다).
  P0w 기준을 같은 난수열 없이 1%p로 잡은 것은 사전 등록의 잘못이다. 기준은 바꾸지 않고 확인 시드에서도 그대로 판정한다.
- 선택 규칙대로 **P4**를 확인 후보로 정한다(띠 안 증가 조건별 최솟값 0.204, P5 0.199).
