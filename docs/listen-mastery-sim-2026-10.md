# 소음 속 듣기 2차: 숙달 판정, 훈련 목표와의 조합, 검사 앞 연습 문장(사전 기준과 결과)

작성 2026-10-07. 1~6절은 시뮬레이션을 돌리기 전에 적고 커밋했다. 탐색 결과와 확인 후보는 7절, 확인 결과와 판정은 8절 이후에 덧붙인다.
1차(`docs/listen-adaptive-sim-2026-10.md`)의 가상 청취자 모형과 조건을 그대로 쓴다. 코드는 `scripts/listen_mastery_sim.py`이며
1차 스크립트(`scripts/listen_adaptive_sim.py`)의 청취자·응답·격자 함수를 가져다 쓴다.

## 1. 문제

4단계 숙달(`noise_mastered`)은 5단계를 여는 문이다. 1차 확인 시드에서 지금 규칙은 향상하지 않은 학습자(참 SRT ≥ +2 dB)의 9~21%를
60시행 안에 숙달로 판정했고, 낱말 상관이 큰 조건(C5)에서는 32%였다. 거짓 숙달은 곧 잘못된 진급이다. 원인은 20시행 창 역치(방향 전환
평균)의 흔들림이 큰데, "처음 창보다 3 dB 낮음"을 시행마다 다시 보기 때문이다(여러 번 보는 만큼 우연히 넘을 기회가 쌓인다).

2차는 세 가지를 묻는다.

1. 역치 추정의 불확실성을 반영한 숙달 판정이 거짓 숙달을 5% 이하로 낮추면서 실제 향상을 지금만큼 잡는가.
2. 훈련 계단 목표를 75~80%로 바꾸고 1의 판정을 함께 쓰면 어떤가(1차 제안 4).
3. 검사 앞 연습 문장 3~5개(역치에 넣지 않고 마지막 SNR을 첫 검사 문장의 시작점으로 씀)가 검사의 편향·재검사 SD를 어떻게 바꾸는가.

## 2. 모형과 조건

- 청취자, 기울기, 문장 난이도 오프셋, 낱말 사이 상관, 어절 수는 1차 2절과 같다. 조건은 1차의 C0~C5를 모두 쓴다.
  C0(σ_d 0), C1(σ_d 1), C2(σ_d 2), C3(σ_d 1 + 제시 흔들림 2 dB), C4(σ_d 1, 기울기 모두 9%/dB), C5(σ_d 1 + 흔들림 4 dB, 문장당 독립 요소 j ≈ 2).
  2차의 판정은 **C0~C5 모두**로 한다(낱말 상관 조건 C3·C5와 한국어 문장 기울기 조건 C4를 포함).
- 훈련 기간: 소리만 시행 100번(1차는 60번). 실제 학습자가 4단계에 머무는 기간을 넉넉히 덮고, 판정 규칙을 여러 번 들여다보는 효과를
  보수적으로 포함하려는 것이다. 숙달은 시행마다 판정하고 한번 숙달하면 유지한다(`main._settle_mastery`).
- 시나리오(같은 청취자 2,000명에 시나리오마다 따로 응답을 뽑는다):
  - 향상 없음: 참 SRT가 100시행 내내 그대로.
  - 3 dB 향상: 참 SRT가 21~40번째 시행에서 곧게 3 dB 낮아지고 그 뒤 유지.
  - 5 dB 향상: 같은 모양으로 5 dB.

## 3. 비교할 숙달 판정(훈련 계단은 지금 1-up-1-down)

이 절의 "역치"는 판정 규칙이 쓰는 추정량이다. 지금 계단의 방향 전환 평균은 낱말 약 40% 지점(SRT40 근처)을, 낱말 비율 최대가능도는
50% 지점(SRT50)을 추정한다. 0 dB 기준의 뜻은 설계 문서대로 "낱말 절반을 0 dB에서 알아들음"(SRT50 ≤ 0)으로 본다. 지금 규칙과 그 변형은
지금 추정량에 0 dB를 그대로 쓴다(SRT50으로 약 +0.8 dB에 해당).

- **(a) 지금 규칙**: 20시행 이상, 최근 20시행 역치 ≤ 0 dB, 또는 40시행 이상에서 처음 20시행 역치 − 최근 20시행 역치 ≥ 3 dB.
- **(b) 불확실성 반영(지금 추정량)**: 같은 추정량(`srt_estimate`)의 두 창 차이 D의 SD σ_D를 시뮬레이션으로 보정한다. 보정은 탐색 시드에서
  C1, 향상 없음 시나리오, 겹치지 않는 두 20시행 창(1~20, 41~60)의 차이로 하되, 기울기가 역치와 엮여 있으므로 최근 창 역치 구간
  (< 3, 3 ~ 10, ≥ 10 dB)마다 따로 구해 상수표로 고정한다. 판정: 최근 창 역치 + z · σ_D/√2 ≤ 0 dB, 또는 (40시행 이상에서) D ≥ max(3, z · σ_D).
  z ∈ {1.645, 2.326, 3.09}를 탐색한다.
- **(c) 낱말 비율 최대가능도**: 최근 N시행(N ∈ {20, 30})의 (SNR, 맞힌 낱말 수, 어절 수)로 로지스틱 정신측정 함수를 격자(1차와 같은
  역치 −15 ~ +32 dB 0.5 dB 간격 × 기울기 9개)에서 적합한다. 역치 사전분포는 편평, 기울기는 로그정규(중앙 0.10, 로그 SD 0.4)로 두고 역치 주변
  사후 평균 θ̂와 사후 SD를 쓴다. 낱말 상관으로 과소평가되는 SD를 배율 √φ로 키운다(φ ∈ {1, 2}, φ = 2는 j ≈ 2에 해당하는 과분산).
  판정: θ̂_최근 + z · SD_최근 ≤ 0 dB, 또는 (2N시행 이상에서) Δ = θ̂_처음 − θ̂_최근이 Δ − z · √(SD_처음² + SD_최근²) > 0이고 Δ ≥ G.
  z ∈ {1.645, 2.326}, G ∈ {2, 3} dB를 탐색한다(16조합).
- **(d) 최소 시행 수만 늘림(대조)**: d40은 (a)에서 최소 시행만 40으로, dw30은 창을 30시행으로(최소 30, 향상 판정은 60시행 이상).

## 4. 훈련 계단 목표와의 조합

- 계단: 1차 (d)의 낱말 비율 걸음. ΔL = −f(i)(비율 − tar)/0.10, f(i) = max(0.5, 1.5 · 1.41^(−i)), tar ∈ {0.75, 0.80}.
- 판정: 3절 (c)의 16조합. 낱말 비율 최대가능도는 계단이 어디에 머물든 SRT50을 직접 추정하므로 0 dB 기준을 환산할 필요가 없다.
- **환산(창 SNR 평균을 역치로 쓰는 경우).** 목표 tar에 모인 계단의 SNR 평균은 SRT_tar = SRT50 + ln(tar/(1 − tar)) / (4s)를 추정한다.
  tar 0.80이면 ln 4 / (4s) = 0.347/s로, 기울기 0.16/dB에서 +2.2 dB, 0.10에서 +3.5 dB, 0.06에서 +5.8 dB다. 따라서 "SRT50 ≤ 0 dB"는
  "SRT80 ≤ 0.347/s dB"와 같고, 학습자의 기울기를 모르면 한 값으로 환산할 수 없다. 기울기를 0.10으로 가정해 기준을 +3.5 dB로 두면
  정상 청력처럼 기울기가 가파른 학습자는 1.3 dB 엄격하게, 인공와우처럼 완만한 학습자는 2.3 dB 느슨하게 판정된다. 1차의 'shift' 추정량이
  이 방식이었다. 이 때문에 조합 후보는 최대가능도 추정량만 쓰고, shift 방식은 비교용으로만 적는다.
- 참고 조합: 1차 확인 후보(d80, 사후 평균, 점추정 3 dB 규칙)도 100시행에서 다시 측정한다.

## 5. 검사 앞 연습 문장

- 연습 문장은 훈련 문장(`TRAIN_SENTENCES`)에서 무작위로 고르고(검사 폼과 겹치지 않음), +10 dB에서 시작해 검사와 같은 맞음 기준(낱말 0.5 이상)과
  4 dB 걸음으로 오르내린다. 연습의 마지막 다음 SNR을 첫 검사 문장의 SNR로 쓴다. 연습 문장은 역치에 넣지 않는다.
- 변형: p3·p5(연습 3·5문장, 그 뒤 검사는 지금대로 처음 4문장 4 dB), p3s·p5s(연습 뒤 검사는 처음부터 2 dB). 역치 추정량은 모두 지금과 같다
  (5~20번째 검사 문장 SNR과 다음 SNR의 평균).
- 연습 효과(첫 리스트에서 1~2 dB 좋아짐, Jansen 외 2012)는 모형에 넣지 않는다. 이 시뮬레이션은 시작점이 역치에 가까워져 생기는 편향·SD
  변화만 측정한다. 연습 효과는 문헌 근거로만 제안에 쓴다.

## 6. 지표와 사전 기준

### 6.1 숙달 판정 지표

- 거짓 숙달률(FM): 향상 없음, 참 SRT50 ≥ +2 dB 청취자 가운데 100시행 안에 숙달된 비율.
- 3 dB 향상 도달률(R3): 3 dB 향상, 참 SRT₀ ≥ +5 dB 청취자 가운데 100시행 안에 숙달된 비율과 도달 시행 수 중앙값.
- 5 dB 향상 도달률(R5): 5 dB 향상, 참 SRT₀ ≥ +7 dB 청취자에서 같은 것.
- 정상 청력 도달: 향상 없음, 참 SRT50 ≤ −1 dB 청취자의 100시행 안 도달률과 도달 시행 수 중앙값.
- 조합에서는 11~100번째 시행의 평균 낱말 정답 비율.

### 6.2 숙달 판정 채택 기준(조건 C0~C5 모두)

1. FM ≤ 5%.
2. R3 ≥ (a)의 R3 − 10%p.
3. 정상 청력 도달률 ≥ 95%이고 도달 시행 수 중앙값 ≤ (a) + 20시행.

조합은 위에 더해 4. 평균 낱말 정답 비율이 전체 0.70 ~ 0.80, 집단(NH·HA·CI)마다 0.65 ~ 0.85.

근거: (1) 5%는 관례적인 1종 오류 수준이며, 잘못된 진급이 20명 중 1명 이하라는 뜻이다. (2) 실제 향상을 잡는 힘은 지금 규칙도 높지 않아(1차 놓침
23~31%), 10%p까지만 양보한다. 거짓 숙달을 5% 아래로 낮추는 대가로 향상한 학습자 일부가 더 오래 머무는 것은 받아들이되, 인공와우 사용자처럼
0 dB에 닿을 수 없는 학습자에게 향상 경로가 사실상 닫히는 것은 막는다. (3) 이미 잘 듣는 학습자를 붙잡아 두지 않게 한다.

### 6.3 후보 선택과 확인

- 탐색 시드(0)에서 6.2 기준을 모든 조건에서 만족하는 판정 규칙(지금 계단) 가운데 R3 최솟값(조건 사이)이 가장 큰 것 하나, 조합 가운데 같은
  방식으로 하나를 고른다(같으면 FM 최댓값이 작은 것). 7절에 적어 커밋한 뒤 확인 시드(1)에서 그 둘만 판정한다.
- 탐색에서 기준을 모두 만족한 것이 없으면 그 갈래는 확인 시드를 돌리지 않고 부정 결과로 적는다.
- 둘 다 확인을 통과하면 조합을 채택한다(훈련 난이도 70~80%라는 이점이 더해지므로). 조합만 통과하면 조합, 판정 규칙만 통과하면 판정 규칙만 넣는다.

### 6.4 연습 문장 채택 기준(조건 C0~C5 모두)

탐색 시드에서 네 변형 가운데 조건 사이 재검사 SD 비(변형/지금)의 최댓값이 가장 작은 것 하나를 고르고, 확인 시드에서 아래를 모두 만족하면 채택한다.

1. 재검사 SD ≤ 지금 × 1.02.
2. |편향| ≤ |지금 편향| + 0.1 dB.
3. +25 dB 막힘 비율 ≤ 지금 + 1%p.

근거: 연습 문장의 주된 이점(첫 리스트 연습 효과 1~2 dB를 검사 밖으로 빼는 것)은 모형 밖에 있으므로, 모형 안에서는 정밀도·편향·막힘이 나빠지지
않는지(비열등)만 확인한다. 2%는 SD 비의 몬테카를로 오차 수준이다. 비용은 회차마다 3~5문장(1~2분)이다.

### 6.5 지키는 것

응답 필드(`stair.ao/av.next_db`·`srt_db`·`n_trials`, 검사 `next_db`·`srt_db`·`done`·`n`)는 유지한다. 연습 문장을 넣으면 검사 시작·답 계약의
변경을 이 문서에 적는다. 확인 시드 결과를 본 뒤 기준과 후보를 바꾸지 않는다.

  FM은 1/4, R3는 오히려 높다. 그러나 낱말 상관이 큰 조건에서 SD가 과소평가되어 C2·C3 8~10%, C5 26%로 넘친다. φ 2·z 2.326으로 막으면 C5 8.7%까지
  내려가지만 R3가 71~77%로 지금보다 13~20%p 낮아진다.
- 사전 등록한 23개 규칙 가운데 6.2 기준을 C0~C5 모두에서 만족한 것은 없었다. 걸림돌은 언제나 C5(문장당 독립 요소 j ≈ 2)였다.

### 7.2 사후 탐색(사전 등록 뒤 추가, 확인 판정에 쓰지 않음)

시행마다 판정하는 것이 여러 번 보기의 오류를 키우므로, (c)를 10시행마다(회차 끝)만 보고, 두 번 잇달아(c2) 만족해야 숙달로 하는 32조합(창 20·30,
φ 1·2, z 1.645·2.326, G 2·3, 연속 1·2)을 더 보았다. 가장 나은 것은 30시행 창·φ 1·z 1.645·G 2·10시행마다·2번 연속(e30_c2)이었다.

| 규칙 | C0 | C1 | C2 | C3 | C4 | C5 |
|---|---|---|---|---|---|---|
| e30_c2 FM / R3 | 1.3 / 86.1 | 1.3 / 86.1 | 2.8 / 84.9 | 3.0 / 80.9 | 1.0 / 85.5 | **9.9 / 78.8** |

C0~C4에서는 기준을 모두 만족했다(FM 1.0~3.0%, R3 감소 4.6~9.1%p, 정상 청력 100% 도달, 중앙 40시행으로 지금 20시행보다 20시행 늦음, 5 dB 향상
도달 98~100%). 그러나 C5에서 FM 9.9%, R3 −10.2%p로 두 기준을 넘었다. 3 dB 향상 도달 시행 수 중앙값은 지금 45~46시행에서 70시행으로 늦어진다.

### 7.3 조합(낱말 비율 계단 목표 75·80% + 최대가능도 판정)

- 사전 등록한 SRT50 판정은 목표 80% 계단과 맞지 않았다. 80% 근처에 모인 자료로는 기울기를 거의 알 수 없어 50% 지점의 사후 SD가 커지고,
  불확실성 규칙을 쓰면 3 dB 향상 도달이 1~11%로 떨어졌다(d80, 20시행, φ 2, z 2.326, G 3). 4절에서 예상한 환산 문제가 추정 단계에서도 나타난 것이다.
- 그래서 탐색 중에 목표 지점 역치 SRT_tar(격자점마다 θ + logit(tar)/(4s))를 직접 추정하고 0 dB 기준을 logit(tar)/(4 · 0.10) dB(tar 0.75 +2.75 dB,
  0.80 +3.47 dB)로 환산한 'q' 판정을 더했다(사전 등록 뒤 추가). 이 환산은 4절대로 기울기 0.10을 가정한 것이라 기울기가 다른 학습자에게 절대 기준이
  1~2 dB 어긋난다. 향상 판정(차이)은 기울기가 그대로면 영향이 없다.
- q 판정의 결과는 지금 계단의 (c)와 거의 같은 맞바꿈을 보였다. 예: d75·30시행·φ 1·z 1.645·G 2는 FM 5.3 / 6.4 / 10.0 / 11.2 / 10.5 / 27.0%, R3 88~96%.
  사후 탐색의 d75·e30_c2도 C5에서 FM 11.4%, R3 73.6%였다. 낱말 정답 비율은 d75 0.75(집단 0.74~0.75), d80 0.79~0.80으로 목표를 지켰다.
- 사전 등록 조합 64개와 사후 조합 64개 가운데 기준을 C0~C5 모두에서 만족한 것은 없었다.

### 7.4 검사 앞 연습 문장

| 변형 | 재검사 SD 비(C0~C5) | 편향 변화 | 막힘 변화 |
|---|---|---|---|
| p3(연습 3, 검사 처음 4 dB) | 0.96 ~ 1.03 | −0.07 ~ +0.03 dB | −0.03 ~ +0.15%p |
| p5 | 0.98 ~ 1.03 | −0.03 ~ +0.01 | −0.02 ~ +0.30 |
| p3s(연습 3, 검사 처음부터 2 dB) | 0.91 ~ 0.95 | −0.02 ~ +0.02 | −0.25 ~ 0.00 |
| **p5s(연습 5, 검사 처음부터 2 dB)** | **0.90 ~ 0.94** | −0.03 ~ +0.03 | −0.10 ~ +0.05 |

연습만 넣고 검사의 처음 4 dB 걸음을 그대로 두면 정밀도가 나아지지 않는다. 시작점이 역치 가까이 오면 처음 4문장의 큰 걸음이 오히려 역치에서 멀어지게
흔들기 때문이다. 연습 뒤 검사를 처음부터 2 dB로 하면 재검사 SD가 5~10% 줄고 편향은 그대로(−0.73 ~ −0.94 dB, 기준 폭 안)다.

### 7.5 확인 후보와 확인 계획(시드 1을 돌리기 전에 적음)

- **숙달 판정·조합: 확인하지 않는다.** 6.3대로 탐색에서 기준을 모두 만족한 것이 없으므로 부정 결과로 적는다. 다만 사후 최선(e30_c2)과 지금 규칙의
  시드 1 값을 **참고로만** 함께 측정한다(판정과 코드 반영에 쓰지 않는다).
- **연습 문장 후보: p5s.** 6.4의 선택 규칙(조건 사이 SD 비 최댓값이 가장 작은 것, p5s 0.942 대 p3s 0.949)을 따른다. 확인 시드에서 6.4의 세 기준을
  C0~C5 모두에서 판정한다.

## 9. 판정

- **숙달 판정: 바꾸지 않는다(부정 결과).** 사전 등록한 23개 규칙 가운데 거짓 숙달 5% 이하와 3 dB 향상 도달(지금 − 10%p 이상)을 C0~C5 모두에서
  함께 만족한 것은 없었다. 낱말 비율 최대가능도는 같은 거짓 숙달에서 지금 추정량보다 향상을 더 잘 잡았지만, 문장당 독립 요소가 약 2개인 조건(C5)에서는
  20~30시행 창으로 두 조건을 함께 맞출 정보가 부족했다. 사후 탐색(회차 끝 판정, 2번 연속)도 C5에서 미달했다.
- **훈련 목표 조합: 바꾸지 않는다(부정 결과).** SRT50 판정은 80% 근처 자료에서 기울기를 몰라 쓸 수 없었고, SRT_tar 환산 판정도 숙달 판정과 같은
  맞바꿈에 걸렸다. 목표 75·80% 계단 자체는 낱말 정답 비율을 집단과 무관하게 0.74~0.80으로 지켰다.
- **검사 앞 연습 문장: 채택한다(p5s).** `backend/listen_curriculum.py`와 `main.py`에 넣었다(10절).
- 결과 화면 MDC: 1차 5.3절 규칙(채택 절차의 C0~C3 전체 MDC95 최댓값을 0.5 dB 단위로 올림)으로 p5s는 2.84 dB → **3.0 dB**다. 프론트의 `MDC_DB = 3.0`을
  그대로 둔다.

## 10. 바뀐 계약(검사 시작·답)

`POST /api/listen/test/start`
- `items`: 맨 앞 5개가 연습 문장이다. 항목마다 `practice`(참·거짓)가 붙는다. 연습 키는 `testp:<훈련 문장 id>`(예: `testp:t012`), 검사 키는 그대로
  `test:A01`~`test:A20`. 연습 문장은 회차 id로 정해지며(`listen_curriculum.test_practice_items(session)`) 검사 폼과 겹치지 않는다.
- 새 필드 `n_practice`(5). `session`·`form`·`start_db`(10)·`n_done_tests`는 그대로다. 그래서 `items`를 차례대로 답하는 지금 화면은 고치지 않아도
  돌아가며 회차는 25문장이 된다.

`POST /api/listen/test/answer`
- 요청은 그대로다(`item_key`에 연습 키를 보낼 수 있다).
- 연습 문장은 검사 문장보다 먼저만 받는다. 검사 문장을 하나라도 답한 뒤 연습 키를 보내면 400, 같은 키를 다시 보내면 409, 그 회차의 연습 목록에 없는
  연습 키는 400이다.
- 응답: `n`은 **답한 검사 문장 수(연습 제외)**로 뜻이 바뀌었다(전에는 회차에서 답한 수였고, 연습이 없는 회차에서는 같다). `snr_db`·`next_db`·`done`·`srt_db`는
  그대로다. 새 필드: `n_practice`(지금까지 답한 연습 수), `practice`(이번 답이 연습인가). 연습 답에는 `target`(정답 문장), `score`, `word_feedback`도 준다
  (훈련 문장이라 보여 줘도 된다). 검사 문장의 정답은 지금처럼 마칠 때까지 주지 않는다.
- 걸음: 연습은 +10 dB에서 4 dB, 검사 문장은 연습 마지막 다음 SNR에서 처음부터 2 dB. 역치는 검사 문장 5~20번째 SNR과 다음 SNR의 평균(연습 제외).
  연습 없이 검사 키부터 보낸 회차(이전 기록 포함)는 옛 규칙(처음 4문장 4 dB)으로 계산한다.

그 밖
- `_listen_test_state`(검사 추이·요약)의 `n`은 검사 문장 수이고 `n_practice`가 더해졌다. 연습 행도 `mode = "test"`, 같은 `session`으로 저장되며 키 접두사
  `testp:`로 가린다. 스키마 변경은 없다.
- 화면 제안: 연습 문장 동안 "연습 문장 1 / 5(점수에 들어가지 않아요)"처럼 표시하고, 답 뒤 정답 문장을 보여 주며, 진행 표시는 검사 문장 기준(`n` / 20)으로 한다.

## 11. 제안과 한계

1. **숙달 판정의 다음 단계.** 시뮬레이션만으로는 판정 규칙을 정할 수 없었다. 결론을 가르는 것은 실제 문장의 독립 요소 수 j(C3의 약 2.9인지 C5의 약 2인지)다.
   파일럿이나 초기 사용자의 4단계 기록(같은 SNR 근처에서 맞힌 낱말 수의 분산)으로 j를 측정한 뒤, 그 조건 하나로 다시 사전 등록할 것을 제안한다. j가 3 근처이면
   사후 최선(e30_c2: 낱말 비율 최대가능도, 30시행 창, 10시행마다, 2번 연속)이 C0~C4 값대로 거짓 숙달을 20~34%에서 1~3%로 줄일 수 있다.
2. **향상 경로를 검사로 옮기는 안.** 4단계 숙달의 거짓 숙달 대부분은 같은 훈련 기록 안에서 "처음 창 대비 향상"을 시행마다 보는 데서 나온다. 향상 판정을
   훈련하지 않은 검사(사전·사후 SRT 차이 ≥ MDC95 3 dB)로 옮기면 들여다보는 횟수가 한 번이 된다. 다만 연습 문장을 넣은 검사의 재검사 SD(1.08~1.96 dB, 8.1절)로는 3 dB 문턱의
   한 번 거짓 양성이 정규 근사로 0.3~6%라 C5에서는 5%를 넘을 수 있다. 다음 사전 등록의 후보로 둔다.
3. **연습 문장의 효과는 모형 밖.** p5s의 채택 근거는 모형 안의 비열등(오히려 SD 5~10% 감소)과 문헌의 연습 효과(첫 리스트 1~2 dB, Jansen 외 2012, ICRA 권고의
   연습 목록)다. 실제로 첫 검사 역치가 덜 낙관·비관되는지는 A-A 재검사 자료로 확인해야 한다.
4. 한계: 1차 11절과 같다. 더해 향상 시나리오는 21~40번째 시행의 직선 향상 한 모양이고, 30시행 창은 처음 창이 향상 구간(21~30번째)과 겹쳐 향상 판정에 불리하다.
   실제 향상이 더 늦게 시작하면 30시행 창 규칙의 R3는 이 문서보다 나아질 수 있다.
