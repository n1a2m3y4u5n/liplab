# 소음 속 듣기 4차: 훈련 기록과 재검사를 함께 쓰는 4단계 숙달(사전 기준과 결과)

작성 2026-10-07. 1~5절은 시뮬레이션을 돌리기 전에 적고 커밋했다. 탐색 결과와 확인 후보는 6절, 확인 결과와 판정은 7절 이후에 덧붙인다.
가상 청취자 모형, 조건 C0~C5, 검사 절차(연습 5 + 20문장), 지표는 1~3차(`docs/listen-adaptive-sim-2026-10.md`, `docs/listen-mastery-sim-2026-10.md`,
`docs/listen-testmastery-sim-2026-10.md`)와 같다. 코드는 `scripts/listen_combined_mastery_sim.py`다.

## 1. 문제

3차의 정기 재검사(40시행마다, 3 dB)는 거짓 숙달을 C0~C4에서 2~5%로 낮췄지만, 참 향상 3 dB를 문턱 3 dB로 보는 재검사가 회마다 절반쯤만 넘어
3 dB 향상 도달이 68~71%였다. 4차는 3차 제안대로 훈련 기록을 선별에 쓰는 결합안을 평가한다. 훈련 기록이 향상을 가리킬 때만 재검사를 권하면,
향상한 학습자는 재검사를 더 여러 번 받고(최대 k회) 향상하지 않은 학습자는 덜 받는다. 아울러 '5 dB 향상 또는 절대 기준' 규칙과, 검사 폼 수(2개 재사용 대 4개)가
결과를 가르는지를 본다.

## 2. 후보

### 2.1 (a) 결합안

- 4단계 시작 때 사전 검사(폼 1번째). 사전 검사 역치 ≤ −0.8 dB(SRT50 0 dB의 검사 환산, 3차 2.2절)이면 훈련 40시행에서 숙달.
- 훈련 40시행 이상에서 시행마다 **재검사 권유 조건**을 본다. 권유 = 훈련 기록의 (처음 창 역치 − 최근 창 역치 ≥ g_t) 또는 (최근 창 역치가 절대 기준 + 2 dB 이하).
  절대 기준은 지금 추정량(방향 전환 평균, 낱말 약 40% 지점)에서 −0.8 dB, 낱말 비율 최대가능도(SRT50)에서 0 dB로 두므로 "근처"는 각각 +1.2 dB, +2.0 dB 이하다.
- 권유 조건이 참이고, 남은 재검사가 있고(학습자당 최대 k회), 직전 재검사에서 20시행 이상 지났으면(첫 재검사는 바로) 그 시행 뒤 재검사한다.
- 재검사 역치가 사전 검사보다 3 dB 이상 낮거나 −0.8 dB 이하면 그 시행에서 숙달. 한번 숙달하면 유지한다.
- 변형(8개): 훈련 추정량 ∈ {cur20: 지금 `srt_estimate` 20시행 창, ml30: 낱말 비율 최대가능도 30시행 창(2차 3절 (c)와 같은 격자·사전분포)}, g_t ∈ {1.5, 2.0} dB,
  k ∈ {2, 3}.
- **주 후보 A1**: cur20, g_t 2.0, k 3(앱에 이미 있는 추정량을 그대로 쓴다).

### 2.2 (b) 5 dB 향상 또는 절대 기준

- b_sched: 3차 T1과 같은 정기 재검사(40·80시행 뒤, 2회)에서 사전 대비 5 dB 이상 향상 또는 −0.8 dB 이하면 숙달.
- b_comb: (a)의 A1과 같은 권유·횟수에서 재검사 문턱만 5 dB.
- (b)는 숙달의 뜻을 바꾸므로 3 dB 향상 도달 기준(5.1의 2)을 넘기 어렵다는 것이 미리 예상된다. 그래도 같은 기준으로 판정하고, 5 dB 향상 도달을 함께 적는다.

### 2.3 (c) 검사 폼 수

- F4: 폼 4개(A·B·C·D). 사전 A, 재검사 B·C·D로 한 사람에게 같은 문장을 다시 내지 않는다. 기억 효과 0.
- F2m1: 폼 2개 재사용. 사전 A, 재검사 B·A·B. 같은 폼을 두 번째 이상 쓰는 검사에서 참 SRT가 1 dB 좋아진다(문장 기억, 3차 M1과 같은 가정).
- F2m0: 폼 2개 재사용, 기억 효과 0(참고). 같은 폼이면 문장 난이도 오프셋을 그대로 쓴다(3차와 같음).
- 폼 C·D는 A·B와 같은 어절 수 배열로 만든다고 가정한다.

## 3. 모형

- 청취자, 기울기, 문장 난이도, 낱말 상관, 어절 수, 훈련 계단(지금 1-up-1-down), 향상 시나리오(21~40번째 시행에서 3·5 dB), 소리만 100시행은 2·3차와 같다.
- 재검사 순간의 참 SRT는 그 훈련 시행 시점의 값이다. 재검사는 훈련 시행 수에 넣지 않는다.
- 지금 규칙(`noise_mastered`)은 같은 청취자에서 기준선으로 측정한다.

## 4. 지표

3차와 같다(FM, R3·R5와 도달 시행 수 중앙값, 이미 잘하는 학습자 도달). 더해 학습자당 평균 재검사 횟수(향상 없음·3 dB 향상).

## 5. 사전 기준과 절차

### 5.1 채택 기준(C0~C5 모두)

1. FM ≤ 5%.
2. R3 ≥ 지금 규칙의 R3 − 10%p(100시행 안).
3. 이미 잘하는 학습자(참 SRT50 ≤ −1 dB) 도달 ≥ 95%.

### 5.2 폼 조건의 판정

채택 판정은 F4와 F2m1 각각에서 따로 한다. F2m1에서 통과하면 지금 폼 2개로도 쓸 수 있고, F4에서만 통과하면 "폼 4개가 결정적"으로 적고 폼 C·D가 생길 때까지
코드에 넣지 않는다(재사용 시의 거짓 숙달이 기준을 넘기 때문). 둘 다 미달이면 부정 결과다.

### 5.3 후보 선택과 확인

- 탐색 시드(0)에서 A1이 F4 기준을 만족하면 A1을 확인 후보로 한다. 아니면 (a)의 8개 가운데 F4에서 5.1을 모두 만족하는 것 중 R3 최솟값(조건 사이)이 가장 큰 것
  (같으면 FM 최댓값이 작은 것, 그다음 평균 재검사 횟수가 적은 것)을 고른다. (b)는 후보 선택에 넣지 않고 보고만 한다(숙달의 뜻이 달라서).
- 6절에 적어 커밋한 뒤 확인 시드(1)에서 그 하나를 F4와 F2m1로 판정한다. 탐색에서 F4 통과가 없으면 확인하지 않는다.
- F2m1까지 통과하면 백엔드에 넣는다(숙달 판정과 4단계 응답의 재검사 권유 필드). F4만 통과하면 문서에 설계와 계약 초안만 적는다.
