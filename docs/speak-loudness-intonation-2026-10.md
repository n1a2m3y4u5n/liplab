## 2. 크기 기준선: 설계와 측정(9/29 등록 내용 그대로, 다시 쓴 부분만 적는다)

### 2.1 설계 R(바뀌지 않음)

`docs/speak-loudness-baseline.md` '설계(R)' 절 그대로다. 잡음 바닥 F = min(처음 0.3초 표본 RMS 중앙값, 전체 표본 RMS 10백분위), 하한 0.0005.
유성 표본 = RMS ≥ 2F이고, 최댓값 0.5로 맞춘 버퍼에서 `lib/pitch.js` 자기상관으로 70~500Hz 주기를 찾았고, 그 주기의 정규화 상호상관 ≥ θ(= 0.3,
9/29 538 절반 0에서 정함). Dv = 끊김 0.15초 이내로 이어진 유성 표본의 가장 긴 길이, L = 유성 표본 RMS 중앙값(dBFS), SNR = L − 20·log10 F.
0단계 합격 Dv ≥ 1.2초이고 SNR ≥ 12dB. 기준선 B = 기기별 최근 합격 0단계 L 최대 5개의 중앙값(2개 이상일 때). '크게' L ≥ B + 6dB,
'작게' B − 18 ≤ L ≤ B − 6dB, 둘 다 Dv ≥ 0.3초. 기준선이 없으면 지금 절대 규칙. '길게' Dv ≥ 2초.

### 2.2 이식(다시 씀)

`scripts/speak_loop_port.py`: 녹음 루프를 16kHz에서 같은 시간 길이로 옮긴다(버퍼 683표본 = 42.7ms, 화면 16.7ms마다 RMS, 네 화면마다 trace 한 점).
지금 규칙(크기 = (RMS > 0.01 화면 RMS 평균 − 0.01) / 0.13 × 100, 이어 낸 길이는 `longestVoicedRun(trace, 0.01)`)도 같은 파일에 있다.
모음 구간·크기 변화(0, −12, −6, +6dB, +6은 ±1에서 잘림)·기준선 흉내(같은 화자·같은 크기 변화에서 Dv ≥ 0.3초인 클립의 L 중앙값)는 9/29 정의 그대로다.

### 2.3 탐색 후보(이번에 더함)

9/29 538 절반 1의 모음 구간 유성 비율은 0.685였고, 빠진 표본 대부분이 선명도가 아니라 크기 문턱(2F)에서 빠졌다. 608에서 C3가 같은 이유로
미달할 수 있어, 확인 전에 608 절반 0으로 다음 격자를 탐색한다: 문턱 배수 k ∈ {2, 1.41, 1}, θ ∈ {0.3, 0.2}, 바닥 백분위 p ∈ {10, 5}(12개, R = k 2·θ 0.3·p 10).

고르는 규칙(절반 0의 538·608과 합성 시드 0에서, 확인 기준과 같은 문턱):
1. R이 C1(538, 608) ≥ 0.95, C2 ≤ 0.05, C3(608) ≥ 0.80을 모두 넘으면 R.
2. 아니면 넷을 모두 넘는 후보 가운데 R과 다른 매개변수 수가 가장 적은 것(같으면 C3가 높은 것).
3. 그런 후보가 없으면 C1·C2를 지키는 후보 가운데 C3가 가장 높은 것을 확인하되, 기록용이고 채택은 확인 기준으로만 정한다.

## 3. 문장 억양: 608 확인(9/29 등록 그대로)

`docs/sentence-intonation.md` 608 절의 척도·판정을 그대로 쓴다. 음높이는 같은 이식(클립 최댓값 0.5, 42.7ms 버퍼, 66.7ms 간격, 70~500Hz),
M0(앞 30% 평균 → 뒤 30% 평균), M2(3프레임 중앙값 필터 뒤 마지막 3프레임 중앙값 ← 전체 중앙값), 유성 프레임 6개 미만 제외, 문턱 1.33반음.
짝 규칙: 같은 세션에서 평서(si) 바로 다음이 의문(si + 1)이고 한글 문자열이 같으며, 둘 다 유사도 0.6 이상·0.4~6초이고 의문이 뒤에 있음.
의문사 의문문은 뺀다(대본에 거의 없다).

판정(절반 1, M2): AUC(의문 대 평서) ≥ 0.60 그리고 평서문 틀린 올림 비율 ≤ 0.20이면 지금 억양 피드백을 이 사용자군에도 그대로 둔다. 하나라도
못 미치면 청각장애 사용자에게 억양 판정을 '참고'로 표시하도록 권고하고, 코드는 플래그 뒤에서 쉽게 끌 수 있을 때만 바꾼다.
설명용: 의문문 올림 비율, 평서문 내림 비율, 같은 화자·같은 문장 쌍에서 의문이 높게 나온 비율, 성별 값, 옥타브 튐 비율(이웃 유성 프레임 차 ≥ 9반음,
608 짝 전체 대 538 전체). 범주 28·32 짝 세션이 없으므로 '범주 27 대 28·32' 비교는 하지 못한다.
