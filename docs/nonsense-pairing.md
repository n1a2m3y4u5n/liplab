# 뜻 없는 말 짝 맞추기(C10, 2026-10-06)

> 종합 계획 2판 C10의 나머지(idea-sweep 다2). 3단계 힌트를 자음 골격으로 바꾼 앞부분은 1a39c91에서 했다. 이 문서는 1·2단계 사이에 둔
> 무의미 낱말 짝 학습 과제의 근거, 설계, 기록, 측정할 것을 적는다. 코드: `backend/nonsense_words.py`, `backend/data/nonsense_words.json`,
> `/api/nonsense/session`·`/api/nonsense/answer`(`backend/main.py`), `frontend/src/pages/NonsensePairing.jsx`, `frontend/src/lib/nonsensePairing.js`,
> `frontend/src/lib/nonsenseShapes.js`, `frontend/src/lib/consonantSkeleton.js`의 `consonantFrame`.

## 1. 근거

- Bernstein, Auer, Eberhardt 2023, Brain Sci 13(7):1008(https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10377548/). 건청 성인이 약 20분씩
  4회기 동안 새 그림에 새 말(무의미 낱말)을 붙이는 짝 학습을 했다. 시행마다 미리 주는 정보를 집단마다 달리했다. 입모양만 보는
  조건에서 자음만 미리 본 집단(예: t_th_n)만 음소 식별과 개방형 문장 독화가 향상했다. 낱말 철자 전체를 미리 본 집단은 익히려던 짝을
  잘 기억하지 못했다.
- Eberhardt, Auer, Bernstein 2014(https://pmc.ncbi.nlm.nih.gov/articles/PMC4215828/). 무의미 낱말 짝 학습이 자음 식별로는 전이했고
  문장으로는 전이하지 않았다.
- 앱에 맞는 이유: 어휘 지식이 끼어들지 않아 시각 음성 지각만 훈련한다. 어휘가 적은 학습자에게도 공정하다. 규칙 엔진이 임의의 한글
  열을 그릴 수 있어 촬영 없이 만들 수 있다.

## 2. 설계

### 2.1 낱말(결정론 생성, 시드 20261006)

| 항목 | 규칙 |
|---|---|
| 모양 | CV + CVC 두 음절(CVCVC). 첫 음절에 받침이 없어 두 음절 사이에 발음 규칙이 걸리지 않는다. 아바타는 적힌 그대로 말한다(테스트로 확인) |
| 첫소리 | ㅂ ㅍ ㅁ ㄷ ㅌ ㄴ ㄹ ㅅ ㄱ ㅋ ㅎ ㅈ ㅊ(13개, 소리 없는 ㅇ과 된소리 제외) |
| 모음 | ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ ㅔ(홑모음 7개, ㅐ는 ㅔ와 같아 뺌) |
| 받침 | ㄱ ㄴ ㄹ ㅁ ㅂ ㅇ(대표음 6개, ㄷ 계열 받침은 철자와 소리가 달라 뺌) |
| 실제 낱말 빼기 | 저장소 낱말 자료(단어 은행, 최소대립쌍, 문맥 문항, 표준검사 단어, `backend/data` 아래 JSON의 모든 한글 덩어리)와 wordfreq 한국어 사전(약 3만 낱말)에 있는 말을 뺀다. 후보 공간 49,686개 가운데 사전 적중 1,639개를 JSON에 함께 얼려, wordfreq가 없는 환경에서도 같은 목록이 다시 만들어진다. 생성 결과를 사람이 읽고 고락(苦樂), 저 몸, 구김, 파닥을 더 뺐다(`MANUAL_EXCLUDED`) |
| 학습 목록 | 8개 × 6낱말. 한 목록은 모음 틀(V1, V2)이 하나라 낱말이 자음으로만 갈린다. 목록 안에서 C1끼리, C2끼리 겹치지 않고, 세 자음의 입모양 무리가 두 자리 이상 다르다(아바타는 같은 무리 자음을 같은 입모양으로 그리므로 구별 단서를 둘 이상 남긴다). 자음 골격은 목록끼리도 겹치지 않는다. 자음은 쓰인 횟수가 적은 것부터 골라 목록 전체에 고르게 든다(첫소리 13개가 모두 나옴, 횟수 차 3 이하) |
| 남겨 둔 목록 | 2 × 16낱말. 학습 목록에 없는 자음 골격으로 만들고 학습에 쓰지 않는다. P3 '학습하지 않은 무의미 낱말 자음 식별'(가1 첫째 층) 문항 후보다. 실제 검사 문항은 P2 촬영 목록을 동결할 때 정하고, 다른 목록을 쓰면 학습 목록 48개와 겹치지 않는지 확인한다 |
| 도형 | 12가지 단색 추상 도형(원, 세모, 네모, 마름모, 별, 십자, 육각형, 고리, 아치, 번개, 물방울, 세 줄). 목록마다 6개를 골라 낱말과 짝짓는다. 색이 아니라 모양으로만 구별한다 |

다시 만들기: `backend/`에서 `python -m nonsense_words --write`(wordfreq 필요). 규칙이나 `MANUAL_EXCLUDED`를 바꾸면 목록 전체가 바뀌므로,
파일럿이 시작된 뒤에는 바꾸지 않는다.

### 2.2 회차

1. 목록을 처음 열면 짝 6개를 하나씩 보여 준다. 도형, 자음 골격(예: ㅎ_ㅂ_ㅂ), 낱말을 되풀이해 말하는 아바타.
2. 홀수 블록은 **골격 보고**: 시행마다 자음 골격을 1.5초 먼저 보이고, 아바타가 말하는 동안에도 남긴다. 짝수 블록은 **확인**: 골격 없이
   입모양만 보고 고른다. 블록 안 순서와 도형 자리는 목록·블록마다 정해진 씨앗으로 섞는다(블록마다 자리가 바뀐다).
3. 답하면 맞은 도형을 초록 테두리로 보이고 그 낱말의 골격을 보인다. 아바타는 계속 되풀이한다. 철자 전체는 끝까지 보이지 않는다.
4. 확인 블록 정답률이 90% 이상(6개 목록이면 6개 모두)이면 목록을 마친다. 화면은 목록을 마치면 그날 회차를 끝내고, 다음 목록은 다음 날
   시작한다.
5. 하루 분량: 서버는 하루(KST) 60시행에서 더 받지 않는다(시행당 약 10초). 화면은 이 기기에서 그날 쓴 시간을 더해 10분이 지나면 그 시행
   뒤에 멈춘다. 둘 가운데 먼저 닿는 쪽에서 끝난다.
6. 점수, XP, 연속 학습 보상, 배지는 없다. 끝 화면은 오늘 고른 횟수만 알린다.

### 2.3 자리

학습 경로의 1단계(입모양 인지)와 2단계(음절·단어) 카드에 보조 버튼 '뜻 없는 말 짝 맞추기 · 하루 10분'으로 둔다. 2단계가 열린 뒤에만
보이고, 라우트(`/learn/nonsense`)도 2단계 잠금 가드(`StageGate stage={2}`)를 쓴다. 단계 노드를 새로 만들지 않아 순차 잠금과 숙달 규칙은
그대로다.

## 3. 기록

| 열 | 값 |
|---|---|
| `trial_attempts.item_type` | `nonsense` |
| `stage` | NULL(단계 밖). 파일럿 내보내기의 `trials_by_stage`에서는 "0" 칸에 든다 |
| `target`, `chosen` | 아바타가 말한 낱말, 고른 도형과 짝인 낱말 |
| `item_id` | `ns01:b3:h`처럼 목록, 블록 번호, 골격 여부(h 골격 보고, c 확인) |
| `options` | 보인 도형 자리(낱말로, 보인 순서) |
| `confusions` | 오답이면 `scoring.viseme_confusions`로 자리별 자모 혼동(같은 입모양 여부 포함) |

넣지 않는 곳: 단계 숙달(StageProgress), 취약 입모양(WeakViseme), 복습 큐, XP. 학습 효과 리포트의 학습곡선과 초기 대비 최근에서도
뺀다. 같은 목록을 기준까지 되풀이해 외우는 과제라 정답률이 오르는 몫의 대부분이 짝을 외운 효과이기 때문이다. 유형별 정확도
(`by_item_type`)와 회차 기록(활동 캘린더, 회차 상세)에는 '뜻 없는 말 짝 맞추기'로 보인다. 개인 혼동 리포트에는 다른 시행과 함께
들어간다. 서버는 지금 목록·블록의 아직 안 본 낱말만 받는다(같은 시행을 두 번 넣거나 블록을 건너뛰지 못한다).

## 4. 측정할 것

1. **주결과(사전 등록, idea-sweep 다2):** 학습하지 않은 무의미 낱말의 자음 식별(가1 첫째 층) 향상이 A-A 기저선 변화보다 크다(하한 > 0).
   문장 전이는 기대하지 않는다고 미리 적고, 오르면 보조 결과로만 보고한다.
2. **과제 안 기록(설명용):** 목록마다 기준 도달까지 블록 수와 시행 수, 확인 블록 정답률의 변화, 자음 무리별 혼동(입술·잇몸·여린입천장·
   목·센입천장), 골격 보고 블록과 확인 블록의 정답률 차이(골격에 기대는 정도).
3. **이행:** 하루 시행 수와 쓴 날 수, 10분 안에 끝나는 비율, 목록을 마치지 못하고 그만둔 비율.
4. **안전 확인:** 이 과제 때문에 1·2단계 숙달 경로가 늦어지지 않는지(숙달 도달 시행 수 비교, 기록만).

## 5. 한계

- 실제 낱말 빼기는 3만 낱말 빈도 사전과 사람의 읽기에 기댄다. 드문 낱말, 이름, 사투리가 남아 있을 수 있다. 파일럿 전에 학습 목록 48개와
  남겨 둔 목록 32개를 한 사람이 더 읽는다.
- 아바타는 자음을 입모양 무리 5개(입술, 잇몸, 여린입천장, 목, 센입천장)로만 그린다. 무리 안 구별(ㄷ 대 ㄴ 대 ㅅ)은 이 과제로 훈련되지
  않는다. 실제 얼굴 영상 목록은 P2 촬영 뒤에 더할 수 있다.
- Bernstein 2023은 건청 성인, 영어, 실제 화자 영상이다. 한국어 규칙 엔진 아바타에서 같은 효과가 날지는 P3에서 확인한다.
