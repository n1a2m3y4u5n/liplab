# KMSAV ROI 후보 사전등록: KMSAV를 학습에 더한 입술 영역 독화(2026-11-02, 학습 전)

질문, 자료, 후보, 시드, 선택 규칙, 판정 기준, 보조 지표를 학습 전에 고정한다. 이 문서를 커밋한 뒤 등록 학습을 시작하고, 실행 뒤에는 '결과' 절만
덧붙인다. 판정은 한 번이다. 결과를 보고 후보·설정·셀을 바꿔 다시 판정하지 않는다. 새 시도는 새 사전등록으로 한다.

## 1. 질문

같은 구조·같은 학습 33명에 KMSAV ROI를 더하면 train538 평가 19명에서 4지 hard 정확도가 오르는가.

## 2. 비교 기준을 바꾼 이유: R2 s0는 평가 인물을 학습에 썼다

처음 작업 지시의 비교 기준은 기존 모델 R2 s0였다. 평가 19명 결과를 보기 전, 이 문서를 커밋하기 전에 오염을 측정해 오케스트레이터 지시로 주 비교를 B33(5절)으로 바꿨다.

- R2 s0(`docs/lipread-roi-2026-10.md` 10.1절)는 이 PC에 pt가 없고 앱용 ONNX만 있다.
  `liplab-lab/models/lipread_roi_R2s0_2026-10-21/kr_lipread_roi.web.onnx`(sha256 d3c01830…, 가중치 int8, 정규화는 그래프 밖). 다시 학습하지 않는다.
  채점 경로 `roi_train.py p4 --onnx`. ONNX 구조상 dup1만 잴 수 있고, R2 s0의 선택 dup도 1이다.
- 확인: 평가 화자 spk315(C287)·spk316(C321)은 R2 s0 대조 검사의 '학습 화자'였다(`roi_judge_2026-10-21/parity/_dump_summary.json`, 인물 번호까지 같음).
  옛 학습 화자 전체 명단은 이 PC에 없다. train538 받기는 옛 V1 평가 40명 배치만 뺐고 옛 학습 배치는 빼지 않았다.
- 측정(평가 화자 안 씀): 평가가 아닌 train538 45명(학습 33 + 검증 12)에 R2 s0를 건 4지 hard dup1은 **76.4%**(8,250문항, `overlap_r2s0_nonEval.json`)이고,
  45명 중 38명이 70% 이상이다. 같은 모델이 처음 보는 옛 평가 40명에서 낸 58.7%보다 훨씬 높다. 번호가 spk331 이상인 화자도 대부분 높아 본 인물로 보인다.
- 그래서 **R2 s0와의 비교는 보고만 한다.** 평가 19명의 R2 s0 값도 비슷하게 부풀 것으로 보며, 차이를 제품 모델 대비 성능으로 해석하지 않는다.
- 비교 기준은 바꿨지만 기준값은 느슨하게 하지 않았다(Δ ≥ +5점, 하한 > 0).

## 3. 자료와 격리

- train538(`liplab-lab/data/train538/v1prep`, bench_id db0ad564): V1-538 등록과 같은 분할. 평가 19명, 검증 12명, 학습 33명(`split.json`).
  문항은 `d_bench.py product4way`와 같다. 평가 19명 3,432문항, 어휘 1,281(`roi_pair.py items` → `PAIR_OK items=3432 vocab=1281 win=3432 unseg=0`, V1-538 p4와 대조).
- KMSAV: 학습 전용, CC BY-NC-SA 4.0. **판정 경로(검증 12·평가 19, 벤치 어휘·오답 보기, E2 클립 360·E2 인물)에 섞지 않는다.** KMSAV는 `prep.json`의 `kms` 항목으로만 학습에 들어가고,
  검증 문항·쉬는 구간에 쓰이지 않는다. `prep-k`는 평가 화자가 pack에 있거나 KMSAV가 학습 밖 역할이면 멈춘다.
- 겹침 확인(`prep-k`, 결과 `run_k/prep.json` meta): KMSAV 영상 ID·클립 이름과 train538 화자·클립·벤치 클립의 겹침은 0이다. 이름 공간이 달라(유튜브 ID 대 AI Hub 인물 번호) 얼굴까지 대조한 것은 아니다.
- 내용 분리: 평가·검증 화자가 읽은 문장과 같은 KMSAV 문장은 뺐다(7개). train538 학습 클립은 V1-538과 같은 규칙으로 뺐다(86개).
- OLKAVS 사전학습 모델과 그 밖의 사전학습 가중치는 쓰지 않는다. WavLM 교사(R2 방식)도 쓰지 않는다(이 PC에 모델이 없고 받기는 금지). 그래서 후보와 B33은 R2 s0와 구조는 같지만 학습 방식은 R1 계열(CTC만)이다.

## 4. KMSAV 입력 규칙

ROI는 `lip_roi_extract.py` 기본값(88×88 흑백, 30 fps 격자, 원본은 25 fps). 문장은 `cropped/<id>/utts/*.txt`.

| 규칙 | 뺀 클립 |
|---|---|
| 전체 npz | 36,291 |
| 숫자·로마자·% 포함 문장(읽는 소리와 자모열이 어긋남) | 6,927 |
| 유효 프레임 50% 미만 | 1,802 |
| 길이 10프레임 미만 또는 450프레임 초과 | 1,432 |
| 자모 수 > 프레임 수 | 12 |
| 문장 공유 | 7 |
| 문장 없음 | 3 |
| **남음** | **26,108클립, 약 43.0시간, 영상 447편** |

train538 학습 항목: 문장 886, 어절 9,112. KMSAV에는 어절 구간이 없어 문장 항목으로만 들어간다.

## 5. 후보와 학습(전부 CTC, 머리·전단 구조는 `roi_train.py` 그대로)

공통: AdamW lr 3e-4, wd 1e-4, 배치 32, 기울기 노름 5, 2에폭마다 검증, 검증 6회 동안 나아지지 않으면 멈춤, 증강(80×80 임의 자르기, 좌우 뒤집기, 속도 0.8~1.25, 시간 마스크 ≤3).
에폭마다 뽑는 KMSAV 클립은 시드로 정해진다.

| 모델 | 시드 | 학습 | 에폭 상한 | 장소 |
|---|---|---|---|---|
| K1 | 0, 1 | 처음부터, train538 항목 전부 + 에폭마다 KMSAV 60만 프레임 | 30 | lab-sub 3060 |
| K2 | 0, 1 | 1단계 KMSAV만(에폭당 150만 프레임), 그 시드의 검증 최고 체크포인트(전단·머리)에서 2단계 K1과 같은 항목 | 1단계 10, 2단계 20 | lab-main 3060 |
| B33(비교 기준) | 0, 1 | 처음부터, train538 항목만 | 40 | s0 lab-sub, s1 lab-main |

- GPU당 학습 하나. 두 PC 모두 RTX 3060, 같은 코드·같은 자료다. K1과 K2 비교에는 PC 차이가 섞일 수 있지만 선택은 검증 값만 본다.
- 시간(시험 실행 약 4,100~4,500 fr/s 기준 추정): K1 실행당 약 2.6시간, K2 실행당 약 2.9시간, B33 실행당 약 2시간. 3060 한 대당 약 7~8시간.
- 시험 실행에서 쓴 작은 pack과 수치는 코드 확인용이며 등록 실행에 쓰지 않았다.

## 6. 선택(검증 12명만)

- 체크포인트: 실행마다 검증 4지 hard(ctc_ll α=1, idle75, dup1·dup2 평균, 화자 평균) 최고 에폭.
- 후보 선택: K1 s0, K1 s1, K2 s0, K2 s1 × dup {2, 1} 8개 중 검증 4지 최고 하나, 동점은 이 순서·dup2 먼저(`roi_train.py select`).
- B33 선택: B33 s0, s1 × dup {2, 1} 4개 중 같은 규칙으로 하나.
- K2 1단계는 선택 대상이 아니다. 평가 화자는 쓰지 않는다.
- 후보는 8개, B33은 4개에서 고른다. 고르는 데 검증 값만 쓰므로 평가 값이 직접 유리해지지는 않지만, 후보 쪽 시도가 많다는 점을 결과와 함께 적는다.

## 7. 판정(주 지표 하나, 한 번)

- 주 지표: 평가 19명 3,432문항, 4지 hard, ctc_ll α=1, idle75, 화자 평균. Δ = 선택 후보 − 선택 B33(각자 선택 dup), 화자 짝, 화자 부트스트랩 10,000회(seed 0, 백분위) 95% CI.
- **통과: Δ ≥ +5.0점 그리고 95% CI 하한 > 0**(`docs/lipread-roi-2026-10.md` 판정 1과 같은 형식). 문항 ID 순서가 어긋나거나 못 자른 문항·ROI 없는 문항이 있으면 판정하지 않는다(`roi_kmsav.py judge`).
- **앱 연결은 이번에 하지 않는다.** 통과·불통과와 무관하다. 현재 제품 모델과 공정하게 비교할 깨끗한 평가 화자가 없기 때문이다. 통과하면 '깨끗한 평가 자료로 R2 s0와 다시 비교 필요'로 남긴다. 모델 파일은 커밋하지 않는다.
- 보고만(판정에 쓰지 않음):
  1. 후보 − R2 s0, B33 − R2 s0 짝 차이(2절 오염).
  2. 부분집합: spk301~330(옛 벤치 v2 번호대, 평가 19명 중 spk303·315·316·326·327·328·329의 7명)을 뺀 12명에서 후보 − R2 s0, 후보 − B33. 2절 측정으로 보아 남은 12명도 R2 s0가 본 인물일 수 있어 '깨끗한 부분집합'이 아니다.
  3. 8절 열화 하락폭.

## 8. 보조 지표: 열화 강건성(보고만)

평가 클립 ROI(88×88)에 클립마다 고정 시드(crc32 "조건|클립")로 건다(`scripts/lipread_roi/roi_degrade.py`, 판정 전에 생성, 570클립, 점수를 보지 않음). 문항·창은 주 지표와 같다.

| 조건 | 내용 |
|---|---|
| low | 44×44로 줄였다가(area) 88×88로 키움(linear) |
| jpeg | 프레임마다 JPEG 품질 20 |
| geo | 클립마다 회전 ±6°, 평행이동 ±4화소(부호 무작위) + 프레임마다 위치 흔들림 σ 0.7화소, 가장자리 반복 |
| bright | 밝기 ×0.6 × (1 + 0.15·sin(2πt/2초 + 위상)) |
| all | low → jpeg → geo → bright |

보고: 조건마다 정확도, 하락폭(깨끗함 − 열화, 화자 짝 CI), 후보·B33·R2 s0. 이미 자른 ROI에 거는 근사다. 실제 웹캠의 비정면·검출 오차·원본 해상도를 재현하지는 않는다.
R2 s0는 평가 인물을 보았으므로 절대 하락폭 비교는 주의해서 읽는다.

## 9. 주장 상한

- 통과여도 '538 정면 평가 19명, 학습 화자 33명 조건에서 KMSAV를 더하면 올랐다'까지만 말한다. 화자 150명 규모에서의 효과로 외삽하지 않고, R2 s0보다 낫다는 뜻이 아니다. 사람 검증이 아니고 웹캠 성능이 아니다.
- 불통과면 이 조건(시드·에폭 상한·입력 규칙)에서 +5점에 못 미쳤다고만 적는다.
- KMSAV 학습 모델은 NC 자료를 포함하므로 상업 이용 제한을 모델 카드에 적는다(`docs/model-card-roi-kmsav-2026-11.md`).
