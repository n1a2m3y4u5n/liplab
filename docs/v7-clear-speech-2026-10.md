# V7 명료 발화 → 대화체 진폭 비계: 사전 기준과 0단계 결과 (2026-10-07)

종합 계획(`docs/master-plan-2026-10.md`) 트랙 V의 V7이다. 아바타가 처음에는 입을 크게 벌려 또박또박 보여 주고, 학습자가 숙달할수록
대화체 크기로 줄이는 진폭 단계를 둘지, 둔다면 단계 크기를 얼마로 할지를 538 라벨로 정하려 했다(idea-sweep 가7).

## 1. 사전 기준(10/3 가7, 10/4 종합 계획에서 고정, 이 문서에서 바꾸지 않음)

- **0단계(0원):** 538 라벨만으로 같은 화자가 여러 소음 조건을 녹음했는지 센다. **조건 쌍이 있는 화자가 30명 이상일 때만 1단계로 간다.**
- **1단계(채택 판정):** 화자마다 소음 조건 발화와 무소음 발화의 jawOpen 95백분위 비를 구하고, 화자 부트스트랩 95% 구간의 **하한이 1.0보다 클 때만**
  그 비를 '명료' 단계 진폭으로 채택한다. '대화체' 단계는 자유발화 분포에서 가져온다.
- 미달이면 '명료' 단계를 채택하지 않고 부정 결과로 적는다. 이번 작업 범위에서는 미달일 때 앱을 바꾸지 않고 문서만 남긴다
  (가7의 '문헌 값 사용'은 따로 결정할 일로 넘긴다, 5절).

통과했을 때 하려던 앱 반영(기록용): 숙달 단계별 진폭 배율을 `frontend/src/lib/talkers.js`의 화자 배율(`amp`, `AMP_KEYS`) 경로에 곱하고,
학습자 숙달은 기존 단계 상태 API 값(`/api/curriculum/stages`의 status)으로 고른다. 진폭 배율은 538 집계 상수로만 둔다.

0단계 집계는 이 문서를 커밋하기 전에 같은 작업 안에서 먼저 돌렸다. 기준은 위 두 문서에 이미 고정되어 있었고, 집계를 본 뒤 바꾼 것은 없다.

## 2. 자료와 방법(0단계)

- 538 파일 이름은 `lip_<묶음>_<소음 환경>_<성별>_<나이대>_<인물>_<시점>_<대본>` 꼴이다(예: 묶음 J, 환경 1, 인물 C901). 받기 도구의 자체검사
  (`liplab-lab/tools/dl_more.sh`)에 남은 tar 안쪽 경로도 `소음환경1/C(일반인)/...` 꼴이라, 소음 환경은 녹음 묶음 단위로 붙는다.
- `scripts/v7_noise_pairs.py`가 맥에 남은 manifest와 받기 기록(`liplab-lab/data` 아래 tsv·log·out·json)에서 파일 이름을 모아 인물 번호별
  소음 환경 수를 센다. 받기 중인 작업 폴더(`data/v1_538/.work`)와 받기 프로세스는 건드리지 않았다. 출력은 집계뿐이다
  (`liplab-lab/data/v7/step0.json`).
- 대상: D 벤치 30명, 9/25 새 화자 38명, 지금 진행 중인 V1 받기에서 끝난 화자와 그 tar 안에서 이름이 보인 인물을 합친 것이다.

## 3. 0단계 결과

| 항목 | 값 |
|---|---|
| 이름이 보인 파일 | 357개 |
| 서로 다른 인물 | 152명(C 계열 110, E 계열 42) |
| 소음 환경별 인물 | 환경 1: 47, 2: 28, 3: 26, 4: 21, 5: 22, 6: 8 |
| 묶음별 | J는 환경 1·2·6, K는 환경 3·4·5에만 있다 |
| **둘 이상의 소음 환경을 녹음한 인물** | **0명**(기준 30명) |

- 인물 번호가 환경마다 따로 매겨지는 체계였다면, 번호 범위(C001~C957, E007~E274)와 인원으로 보아 다른 환경 사이에 같은 번호가 평균 7.5번
  겹쳐야 한다(무작위 배정 가정, 0번일 확률 약 0.06%). 하나도 겹치지 않으므로 인물 번호는 자료 전체에서 하나이고, **한 인물은 한 소음
  환경에서만 녹음했다**고 본다. 반대로 번호는 전체에서 하나인데 인물마다 두 환경을 녹음했다면, 152명 표본에서 같은 인물이 약 4.7번 보여야 한다
  (같은 가정, 0번일 확률 약 1%). tar마다 앞쪽 인물만 받는 표집이라 무작위 가정은 어림이다.
- 같은 사람이 번호를 바꿔 다른 환경에 다시 나왔을 가능성은 라벨로 확인할 수 없다. 그런 경우가 있더라도 라벨로 짝을 지을 수 없으므로
  0단계 조건(라벨로 센 조건 쌍)은 같다.

## 4. 판정

- **0단계 미달(조건 쌍 화자 0명 < 30명).** 1단계 비(화자 안 소음/무소음 jawOpen)를 538로는 계산할 수 없어 판정 불가이며, 사전 기준대로
  **'명료' 단계를 채택하지 않는다. 앱은 바꾸지 않았다.**
- V2(`docs/avatar-validity-2026-10.md` 10.5절)의 화자 사이 비교(소음 라벨 1인 화자와 2인 화자의 J 진폭 중앙값이 두 절반에서 방향이 엇갈림)는
  환경과 인물이 섞인 비교라 이 판정에 쓰지 않는다. 그 비교를 늘려도(화자를 더 받아도) 화자 안 비라는 기준을 대신하지 못한다.
- 주장 문장: "538은 인물마다 소음 환경이 하나라(인물 152명 중 둘 이상 0명) 같은 사람의 소음·무소음 입 벌림 차이를 측정할 수 없다. 명료 발화
  진폭 단계는 538 근거가 없어 넣지 않았다."

## 5. 넘기는 결정

- 가7은 미달일 때 문헌 값(시청각 롬바르드 말뭉치의 입 움직임 증가)을 쓰자고 했다. 그 값은 영어 화자, 다른 측정기에서 나온 것이라
  앱의 진폭 배율로 옮기려면 따로 근거가 필요하다. 이번에는 넣지 않았고, 넣을지는 사용자 결정으로 남긴다.
- 화자 안 비교가 가능한 경로는 두 가지다. (1) P2 촬영 목록에 같은 사람의 '또박또박'·'평소 대화체' 낭독을 한 쌍으로 넣는다(동의 범위 안,
  소음 대신 명료 지시로 같은 비를 측정). (2) 같은 인물이 여러 조건을 녹음한 한국어 시청각 자료를 찾는다. 둘 다 이번 작업에서는 하지 않았다.
- 538의 '자유발화' 라벨(전문가 화자 일부)로 낭독과 대화체를 같은 인물 안에서 비교하는 것은 V7 기준이 아니어서 이번에 하지 않았다. 라벨
  JSON(`Sentence_info`의 topic, `speaker_info`의 Specificity)은 받기 도중에만 읽고 남기지 않아서, 하려면 라벨을 다시 스트리밍해야 한다.
