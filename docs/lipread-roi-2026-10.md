# 입술 영역 화소 전단 사전등록: 538로 직접 학습한 제품용 독화 전단(2026-10-17, 학습·측정 전)

독화 방향 ①을 실행하기 전에 질문, 자료, 평가 화자, 후보, 선택 규칙, 판정 기준, 비용을 고정한다. 이 문서는 ROI 추출 결과나
학습 수치를 보기 전에 커밋하며, 실행 뒤에는 결과 절(10절 이후)만 덧붙인다. 하이퍼파라미터는 평가 결과를 보고 바꾸지 않는다.

## 1. 질문과 범위

웹캠 기계 확인의 입력을 MediaPipe 입 블렌드셰이프 27채널에서 입술 영역 화소(88×88 흑백)로 바꾸고, 그 전단을 538(OLKAVS)
자료만으로 직접 학습하면, V1과 같은 처음 보는 화자 40명·같은 문항에서 4지 정확도가 V1 선택 모델(블렌드셰이프)보다 높은가.

- 제품에 넣을 수 있어야 하므로 538 밖의 사전학습 가중치(LRS3·VoxCeleb2로 학습한 Auto-AVSR 등 비상업 조건)는 쓰지 않는다.
  후보 R2의 교사 WavLM Base+는 MIT 사용권으로 이미 제품 발음 모델에 쓰고 있어 예외가 아니다(교사는 학습 때만 쓰고 제품
  독화 모델에는 들어가지 않는다).
- 538 자료는 10/6 관리자 확인으로 LIPLAB용 처리가 허용되어 있다. 원자료·조각별 자료·ROI·가중치는 저장소에 넣지 않고 데스크탑
  D:에만 둔다.

## 2. 근거와 기대 효과(실행 전 추정)

### 2.2 공개 결과(기억에 기댄 값, 불확실 표시)

- LRW(영어 500단어, 약 50만 클립·약 160시간): 직접 학습한 3D 합성곱 + ResNet-18 전단이 단어 정확도 83~89%
  (Stafylakis·Tzimiropoulos 2017, Martinez 외 2020, Ma 외 2022). 같은 과제에서 화소 모델이 특징 모델을 크게 앞선다.
- LRW-1000(중국어 1,000단어, 약 70만 표본·약 57시간): 직접 학습 약 38~56%(불확실). 단어 수가 많고 자료가 적으면 크게 떨어진다.
- 문장 독화를 30시간 정도로 처음부터 학습하면 단어 오류율이 80~90%대로 남는다는 보고가 있다(AV-HuBERT 논문의 사전학습 없는
  저자원 비교, 수치는 불확실). 자기지도나 음성 교사로 전단을 먼저 학습하면 같은 표지 자료에서 크게 나아진다(LiRA, Ma 외 2021;
  AV-HuBERT, Shi 외 2022).
- 정리: 화소 전단을 직접 학습해 특징 모델을 넘으려면 대략 수십 시간 규모가 필요하고, 표지 자료가 그보다 적으면 음성 교사
  사전학습이 도움이 된다는 것이 공개 결과의 일관된 방향이다.

- 기대치(4지 hard, 평가 40명, 불확실): R1(직접 학습) 26~34%, R2(음성 교사 사전학습) 30~40%. D-7에서 V16까지의 기울기를 그대로
  늘리면 교차점은 수천~1만여 클립 사이로 보이지만, 이 외삽은 근거가 약하다. 판정 1(V1보다 +5점) 통과 가능성은 반반 아래,
  제품 관문(40%) 통과 가능성은 낮게 본다.

## 3. 자료와 분할

- 화자: 위 168명 + 받기 A로 커밋되는 화자. 인물 중복은 받기 도구(`dl_more.sh`)가 막는다. 받기 B는 같은 화자 ID의 인물이 이전
  manifest_meta와 같은지 확인하고, 다르면 그 화자의 B 클립을 쓰지 않는다.
- 평가 40명: V1과 같다(`scripts/lipread_v1/eval40.txt`, V1 사전등록 부록 A). 판정 문항은 V1 판정에 쓴 7,545개(어휘 3,252)와
  같은 문항·같은 오답 보기다. 평가 화자의 받기 B 클립은 판정에 쓰지 않는다(보고만).
- 검증 12명: V1과 같은 규칙과 같은 명단(`sha256("liplab-v1-val:" + spk)`). 체크포인트와 후보 선택에만 쓴다.
- 학습: 나머지 전부. 받기 A로 늘어난 화자는 학습에만 넣는다.
- 내용 분리: V1 3.3절과 같다(검증·평가 화자가 읽은 문장과 같은 문장의 학습 클립과 그 어절 조각은 뺀다, 뺀 수 보고).
- 시점: 주 학습은 정면(A) 클립만 쓴다. 받기에서 다른 시점 클립이 나오면 보고만 하는 R1v에만 쓴다.

## 4. 입력

- ROI: D-7·V16과 같은 `lip_roi_extract.py` 기본값(88×88 흑백, 입 너비 2.0배, 머리 기울기 보정, 30 fps 격자). 데스크탑 CPU에서
  vlip 환경(mediapipe 0.10.14)으로 뽑는다. 추출 실패가 5%를 넘거나 `train_lip_roi.py check`의 입 벌림·jawOpen 상관이 지연 0에서
  최대가 아니면 학습하지 않는다.
- 브라우저에서도 같은 자르기를 해야 하므로, 판정 뒤 제품에 넣을 때는 이 규칙을 웹 쪽에 그대로 옮긴다(입 중심 이동평균 15프레임,
  클립 대표 입 너비). 녹화 창 2.5초 안에서 계산할 수 있는 규칙이다.

## 5. 모델

- 전단(공통): Conv3d(1→24, 5×7×7, 보폭 1×2×2) + BN + ReLU + 최대풀링 1×3×3(보폭 1×2×2) → 프레임별 ResNet-18 폭 0.5(채널 32·64·128·256,
  블록 2·2·2·2) → 전역 평균 → 선형 256. 입력은 학습 때 임의 80×80 자르기와 좌우 뒤집기(p 0.5), 평가 때 가운데 80×80. 파라미터 약
  300만, 프레임당 약 0.07 GFLOPs.
- 머리(공통): V1과 같은 BiGRU 3층 자모 CTC(`train_lipread.build`의 머리, 입력 차원만 27 → 256). 출력 계약 `logits [B,T,53]`과 채점
  (ctc_ll, idle75, dup)은 V1과 같다.
- 내보내기 목표: ONNX 가중치 int8 20 MB 이하(추정 약 4~6 MB), onnxruntime-web WASM으로 2.5초 창 하나를 1초 안에 처리.
- R1: 전단과 머리를 처음부터 함께 학습(V1 후보 B와 같은 학습 항목·idle75 창 증강, 같은 최적화기 설정: AdamW lr 3e-4, wd 1e-4,
  배치 32, 기울기 노름 5, 최대 60에폭, 2에폭마다 검증, 10회 개선 없으면 멈춤). 시간 마스크 ≤3프레임, 속도 0.8~1.25.
- R2: 학습 화자 클립 전체(문장 전체, 표지 불필요)로 전단 + 2층 1차원 합성곱 투영을 먼저 학습한다. 목표는 같은 클립 음성의
  WavLM Base+ 9층 특징(50 Hz → 30 fps 선형 보간, 화자 평균 정규화)이고 손실은 L1 + (1 − 코사인)이다(LiRA 방식). 20에폭 뒤
  투영을 버리고 R1과 같은 방법으로 CTC 미세조정한다.
- 시드: R1·R2 각 0·1(실행 4개).
- 보고만: R3(R2 전단 출력 256 + 블렌드셰이프 27을 이어 붙인 융합), R1v(R1에 다른 시점 클립 추가).

## 6. 선택

- 체크포인트: 실행마다 검증 12명 4지 hard(주 셀과 같은 채점, dup1·dup2 평균, 화자 평균)가 가장 높은 에폭.
- 선택: 4개 실행 × dup ∈ {2, 1} 8개 중 검증 4지가 가장 높은 하나(동점이면 R1 s0, s1, R2 s0, s1 순서, dup2 먼저). 평가 화자는
  선택에 쓰지 않는다.

## 7. 판정(주 지표 하나)

- 주 지표: 선택한 모델 하나를 V1과 같은 평가 40명·7,545문항에 V1 주 셀과 같은 규칙(4지 hard, ctc_ll α = 1, idle75, 선택한 dup)으로
  건다. 입력만 ROI로 바꾸므로 `d_bench.py product4way`의 창 구성(어절 구간 + 같은 화자 쉬는 프레임으로 채운 75프레임)을 ROI 프레임
  번호에 그대로 적용하는 채점기를 쓰고, 문항 ID가 V1과 하나도 빠짐없이 같은지 먼저 확인한다(다르면 판정하지 않음).
- 비교 대상: V1 선택 모델 B1(30.1%), 다시 학습하지 않는다. 문항이 같으므로 화자별 짝 차이를 쓴다.
- **판정 1(구조): Δ4지 = ROI 선택 모델 − B1 ≥ +5.0점이고, 화자 부트스트랩(10,000회) 95% CI 하한 > 0.** 통과하면 제품 독화의
  입력을 ROI 전단으로 바꾸는 쪽으로 다음 단계(브라우저 자르기 이식, ONNX int8, 지연 측정)를 진행한다.
- **판정 2(제품 관문, V1과 같은 기준): 4지 ≥ 40%이고 화자 부트스트랩 95% CI 하한 > 30%.** 통과해야 웹캠 기계 확인을 다시 켜자고
  제안한다(배포는 사용자 결정).
- 판정 1 미달이면 제품 독화는 블렌드셰이프 구조로 두고, 화소 전단은 받기 B 이후 자료로만 한 번 더 비교한다(새 사전등록).
- 보고만: R1·R2 각각의 같은 셀, R3·R1v, 평가 화자 받기 B 클립의 4지, int8과 fp32의 정답 일치율, 학습 화자 수에 따른 곡선
  (같은 분할에서 학습 화자 25·50·100·전체, R1 s0만), 브라우저 지연.
