### 1.2 이미 산 것 가운데 덜 쓴 것

- **Character Creator 5 영구 라이선스 + Headshot 3:** 얼굴을 더 만드는 데 돈이 들지 않는다. Headshot Morph 1400+, 리소스 팩, **콘텐츠 쿠폰 $50×2·$100×1**이 무상으로 들어 있다(집행대장 3번). 다화자 얼굴(H-6, P1)이 막힌 이유는 돈이 아니라 작업 시간이다.
- **Claude Max 2계정(10/5, 10/7 만료):** 코딩, 콘텐츠 생성, LLM 1차 검수, 대화 품질 평가를 API 비용 없이 할 수 있다. 만료 전에 몰아 쓴다.
- **Figma 팀 구독(10/8 만료).**

### 1.4 무료 모델과 도구

- 음성: Whisper large-v3, wav2vec2 XLS-R(300M/1B), Meta MMS, w2v-BERT 2.0, WavLM, Silero VAD.
- 음성합성: 브라우저 내장 음성(기기 안, 무료), MeloTTS(한국어 지원, MIT), XTTS-v2(한국어 지원, 비상업 라이선스). Typecast 결제 없이 소리 조건(P11)을 시험할 수 있다.
- 얼굴: MediaPipe, NVIDIA Audio2Face-3D(2025년 공개된 것으로 알고 있음, ARKit 계수 출력, 라이선스 확인 필요), 2D 말하는 얼굴 생성 모델(MuseTalk, LivePortrait 등).
- 립리딩: OLKAVS 공개 기준 모델, Auto-AVSR(영어) 구조.

### 1.5 무료 연산

- Kaggle 노트북(주당 GPU 약 30시간), Google Colab 무료 등급, Modal 월 무료 크레딧 등. 수치는 각 서비스에서 확인 필요.
- 538·608에서 뽑은 특징 파일로 돌리는 작은 학습·평가에 쓴다. 원자료 업로드는 국외 처리 범위 안에서만 한다.

### 1.6 사람과 기관

- 팀원 5명: 녹음, 촬영, 받아쓰기, 검수.
- 학교: 청인 또래 예비 파일럿, 교사 얼굴(Headshot 동의), 촬영 장소.
- KT 지원 제안: 국내 GPU, 청각장애 지원 사업과의 연결(당사자 파일럿), 언어재활사 자문, 촬영 시설.
- 대학 언어치료학과·특수교육과: 명료도 판정이나 검수 자문(메일 요청, 무료).

## 3. 예산 재배정 제안

- 3D 성도 모델 290,000원과 CC5 세일 여유분 291,812원은 계획서 원칙(남는 예산은 GPU 우선)에 따라 GPU로 옮긴다.
- Typecast 42,000원은 무료 TTS가 충분하면 쓰지 않는다.
- Claude Max는 10월 작업량이 많으므로 1계정 1개월 갱신을 권한다. 모자라는 약 6만 원은 TTS·성도 몫에서 충당할 수 있다.
- SpeechSuper는 더 쓰지 않는다. 키는 폐기하거나 재발급한다.

## 4. 먼저 확인할 것

1. Claude Max·Figma 갱신 여부(10/5~10/8).
