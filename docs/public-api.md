# 공개 인터페이스 (계획서 §6.3)

LIPLAB의 독화 자원과 채점 기준을 앱 밖(수업, 연구, 다른 서비스)에서도 쓰도록 연 무상태 API다.
로그인이 필요 없고, 요청 내용은 저장하지 않는다. IP마다 분당 요청 수만 제한한다.

## GET /api/public/resources

한국어 독화 표준 자원 한 벌. 분당 20회.

- `meta`: 판본(`semver`), 판(`edition`), 라이선스(`CC BY 4.0`), 출처, 단어 수
- 동구형이음 사전, 독화 난이도 지수, 최소대립·동구형 쌍, (있으면) 실화자 데이터에서 나온 자모 시각 유사도

같은 내용을 판본과 함께 `docs/perceptual-resources.json`(1.1.0)으로도 배포한다. 그 파일에는 재현 가능한 표준 평가셋
20문항이 더 들어 있고, 앱의 표준검사(사전·사후 폼) 문항 단어는 빠져 있다.

## POST /api/public/score

독화 답 채점. 분당 30회.

```json
{ "target": "밥 먹었어요", "answer": "맘 먹었어요" }
```

- 두 문장을 '소리 나는 대로' 자모로 바꿔 입모양(viseme) 가중 음운 유사도로 채점한다. 표기가 달라도 소리가 같으면
  만점이다(굳이·구지).
- 응답: `score`(0~100), `phoneme_accuracy`(초성·중성·종성), `viseme_errors`, `confusions`(자리, 목표 자모, 읽은 자모,
  입모양이 같은지).
- 입력은 각 100자까지. 넘으면 400.

## 쓰지 않는 것

- 개인 학습 기록, 음성·영상은 받지 않는다. 음성 채점(D-GOP)은 모델과 연산 비용 때문에 공개하지 않는다.
- 결과를 저장하거나 로그에 남기지 않는다(요청 수 제한용 IP 계수만 메모리에 몇 분 둔다).

코드: `backend/main.py`(`/api/public/*`), 채점 `backend/scoring.py`, 자원 `backend/perceptual.py`.
테스트: `backend/test_public_api.py`.
