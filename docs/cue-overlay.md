# 안 보이는 소리의 시각 증강(축 J) — 설계 근거와 소규모 실증

고도화계획서 §3.10(J)의 목표 수준은 "설계와 소규모 실증"이다. 코드는 `backend/cue_overlay.py`
(`generate_cues`), API는 `/api/cues`, 화면 표시는 `frontend/src/components/CueBadges.jsx`다.
실증 수치의 원자료는 `docs/cue-overlay-stats.json`이다.

## 1. 자질과 기호의 대응

입모양이 같은 음소(동구형이음)는 입술 밖으로 드러나지 않는 자질에서 갈린다. 기호는 그 자질에만 붙인다.

| 자질 | 음소 | 기호(`cue`) | 뜻 |
|---|---|---|---|
| 기식 | ㅋ ㅌ ㅍ ㅊ ㅎ | `aspirated` | 바람이 새어 나옴 |
| 긴장(된소리) | ㄲ ㄸ ㅃ ㅆ ㅉ | `tense` | 목에 힘을 준 소리 |
| 비음 | ㄴ ㅁ ㅇ | `nasal` | 코로 울리는 소리 |

평음(ㄱ ㄷ ㅂ ㅅ ㅈ)은 기준이라 기호가 없다. 계획서 초안의 "유성 = 채운 점"을 "된소리 = 긴장" 기호로 바꾼
근거는 한국어 장애음의 대립 구조다. 한국어 파열음·파찰음은 유성/무성이 아니라 평음·경음·격음의 3항 대립이고,
유성음은 평음이 모음 사이에서 나는 변이음이라 뜻을 가르지 않는다. 따라서 학습자가 구별해야 하는 것은
기식(격음)과 긴장(경음)이며, 유성은 기호로 나타낼 대상이 아니다.

기호는 입모양만으로 구별이 어려운 무리(양순음과 입 안쪽 자음 {6, 7, 8, 10})에서만 붙인다.

## 2. 실제 발음 기준 적용(J-5)

기호는 들리는 소리의 자질을 보여 주므로, 글자가 아니라 **실제 발음**으로 풀어야 한다. 이전 구현은 입모양 경로
(`to_pronounced_syllables` 기본값: 연음·격음화·구개음화만)로 풀어, 비음화·경음화·받침 중화가 반영되지 않았다.
예를 들어 국물[궁물]의 첫 음절 받침 비음, 먹고[먹꼬]의 된소리를 놓쳤다. 지금은 표준발음법 규칙까지 적용하는
발음 모드(`phonetic=True`)로 푼다. 두 모드는 음절 수가 같아 화면의 음절 위치와 그대로 맞는다
(테스트 `test_cues_follow_actual_pronunciation`).

## 3. 소규모 실증: 기호 밀도와 발음 모드의 효과

대상: 승인된 문맥 추론 문장 186개(빈칸에 정답을 채운 문장, 평균 10.6음절).

| 지표 | 값 |
|---|---|
| 문장당 기호 수(상한 없음) | 평균 5.94, 중앙값 6 |
| 기호가 붙는 음절 비율 | 55.8% |
| 문장당 기호 수(`max_cues=2`) | 평균 1.99 (66.5% 감소) |
| 기호 종류 | 비음 636, 기식 244, 긴장 224 |

상한 없이 모든 자질에 기호를 붙이면 음절의 절반 이상이 기호로 덮여, 입모양을 보는 데 방해가 된다. 그래서
기호마다 안 보이는 정도(축 C 난이도 지수의 음소 성분)로 우선순위를 매겨 상위 몇 개만 남기고(`max_cues`),
학습자의 숙달도가 오르면 흐리게 하다가 없앤다(`mastery`, `fade_threshold` 0.85). 훈련 화면에서는
문장당 2개 안팎을 기본으로 둔다.

발음 모드로 바꾼 효과: 186문장 중 63문장(34%)의 기호가 달라졌다. 비음 21개(비음화)와 긴장 42개(경음화)가
새로 붙고, 기식 7개·긴장 13개·비음 2개가 빠졌다. 빠진 것은 받침 중화(꽃[꼳], 잎[입]처럼 받침 자리 격음·경음이
평음으로 소리 남)에 따른 것으로, 모두 실제 발음과 맞는 방향이다.

## 4. 한계와 남은 일

- **문제 풀이 중 표시(J-3).** 지금 기호는 답한 뒤의 피드백으로만 쓰인다. 입 근처에 글자 없이 기호만 시간에 맞춰
  띄우는 경로는 레슨 화면 작업에서 붙인다.
- **실제 영상 위 표시(J-9).** 규칙 기반이라 강제정렬 시각만 있으면 촬영 영상에도 얹을 수 있지만 아직 실증하지 않았다.
- **당사자 검증(J-12).** 기호가 늘리는 학습 부담과, 기호를 없앤 뒤에도 구별이 유지되는지(전이)는 파일럿으로 확인해야 한다.
- 위 수치는 규칙이 만드는 기호의 양이며, 학습 효과의 근거가 아니다.
