# 소음 속 듣기 3차: 검사 기반 4단계 숙달(사전 기준과 결과)

작성 2026-10-07. 1~5절은 시뮬레이션을 돌리기 전에 적고 커밋했다. 탐색 결과와 확인 후보는 6절, 확인 결과와 판정은 7절 이후에 덧붙인다.
가상 청취자 모형과 조건 C0~C5는 1차(`docs/listen-adaptive-sim-2026-10.md`)·2차(`docs/listen-mastery-sim-2026-10.md`)와 같다.
코드는 `scripts/listen_testmastery_sim.py`이며 1·2차 스크립트의 함수를 가져다 쓴다.

## 1. 문제

2차에서 훈련 기록만으로 4단계 숙달을 판정하는 규칙은 어느 것도 거짓 숙달 5% 이하와 향상 도달을 함께 맞추지 못했다. 거짓 숙달의 대부분은
같은 훈련 기록 안에서 "처음 창 대비 향상"을 시행마다 다시 보는 데서 나왔다. 3차는 향상 판정을 훈련하지 않은 문장의 검사(연습 5 + 20문장,
2차에서 채택한 절차)로 옮기는 안 하나를 평가한다. 검사는 들여다보는 횟수가 검사 횟수뿐이고, 훈련 문장과 겹치지 않아 과제 안 향상과 섞이지 않는다.

## 2. 후보 규칙

### 2.1 주 후보 T1

4단계 숙달 = 소리만 훈련 시행 ≥ 40 그리고 다음 가운데 하나.

- (절대) 가장 최근 검사 역치 ≤ c. 사전 검사도 "가장 최근 검사"가 될 수 있다.
- (향상) 사전 검사 역치 − 가장 최근 재검사 역치 ≥ G(3 dB, 1·2차의 MDC95 3.0 dB).

검사는 4단계를 시작할 때 한 번(사전 검사, 지금 앱의 `needs_pretest`), 그 뒤 소리만 훈련 40시행마다 한 번(40, 80번째 시행 뒤) 다시 본다고 가정한다.
폼은 지금 앱처럼 A·B를 번갈아 쓴다(사전 A, 재검사 B, A, …). 잡음은 babble 하나다. 판정은 검사를 마친 순간과 그 뒤 훈련 시행마다 하며 한번 숙달하면 유지한다.

### 2.2 절대 기준 c의 환산

설계 의도의 0 dB는 "낱말 절반을 0 dB에서 알아들음"(SRT50 ≤ 0)이다. 지금 검사 절차(4어절 '절반 이상'이면 맞음)는 낱말 약 40% 지점에 모여
SRT50보다 낮게 나온다. 1·2차 확인 시드에서 연습 문장을 넣은 검사의 평균 편향은 −0.69 ~ −0.90 dB(C0~C3 −0.69 ~ −0.77)였다. 따라서 SRT50 = 0 dB는
검사 역치로 약 −0.8 dB이고, 주 후보의 c는 **−0.8 dB**로 둔다. 문자 그대로 c = 0 dB인 경우도 함께 적는다(판정에는 쓰지 않음). 편향은 집단에 따라
−0.5(정상 청력) ~ −1.0 dB(인공와우)로 달라, 한 값의 환산은 집단별로 ±0.3 dB 어긋난다.

### 2.3 미리 적어 두는 변형(다중 검사 대책 포함)

- 재검사 간격 I ∈ {40, 20} 시행(20이면 20·40·60·80·100번째 뒤, 학습자가 더 자주 다시 보는 경우를 대신한다. 숙달은 여전히 40시행 이상에서만).
- 향상 문턱 G ∈ {2.0, 2.5, 3.0} dB.
- 확인 방식: c1(재검사 한 번이 문턱을 넘음), c2(잇단 두 재검사가 모두 사전 검사보다 G 이상 낮음, 두 번 연속 향상), m2(최근 두 재검사의 평균이
  사전 검사보다 G 이상 낮음). c2·m2는 재검사가 두 번 쌓여야 판정된다.
- 절대 기준은 모든 변형에서 c = −0.8 dB, 최근 검사 하나로 판정한다.
- 18개 조합(I 2 × G 3 × 확인 3). T1은 I 40·G 3·c1이다.

## 3. 모형

- 청취자·기울기·문장 난이도·낱말 상관·어절 수는 1·2차와 같다. 조건 C0~C5 모두, 조건마다 2,000명.
- 훈련: 지금 1-up-1-down 계단, 소리만 100시행. 시나리오는 향상 없음, 21~40번째 시행에서 3 dB 또는 5 dB 곧게 향상(2차와 같음).
- 검사: 2차에서 채택한 절차(연습 5문장 4 dB, 검사 20문장 처음부터 2 dB, 역치 = 5~20번째 SNR과 다음 SNR 평균). 검사 순간의 참 SRT는 그 시점의 훈련 시행
  참 SRT다(사전 검사는 0번째).
- **폼 재사용.** 1·2차는 두 검사의 문장 난이도 오프셋을 따로 뽑았다. 3차는 실제처럼 폼 A·B의 문장 40개의 오프셋을 청취자마다 한 번 뽑아, 같은 폼을
  다시 쓰면 같은 오프셋을 쓴다(같은 폼끼리의 비교는 문장 난이도가 상쇄되어 차이의 SD가 작아진다). 연습 문장은 회차마다 훈련 문장에서 새로 고른다.
- **문장 기억(보조 조건 M, 판정에 쓰지 않음).** 일상 문장은 의미가 있어 다시 들으면 기억으로 더 잘 알아들을 수 있다. 같은 폼을 두 번째 이상 쓰는
  검사에서 참 SRT가 1 dB 좋아지는 조건(M1, C1 바탕)을 따로 돌려 거짓 숙달이 얼마나 늘어나는지 본다.
- 지금 규칙(`noise_mastered`)은 같은 청취자·시나리오에서 2차와 같이 측정해 기준선으로 쓴다.

## 4. 지표

- 거짓 숙달률(FM): 향상 없음, 참 SRT50 ≥ +2 dB 청취자 가운데 100시행 안에 숙달된 비율(검사 반복의 누적 포함).
- 3·5 dB 향상 도달률(R3·R5): 참 SRT₀ ≥ +5·+7 dB 청취자의 100시행 안 도달률과 도달까지 훈련 시행 수 중앙값.
- 이미 잘하는 학습자: 향상 없음, 참 SRT50 ≤ −1 dB 청취자의 도달률과 도달 시행 수 중앙값.
- 검사 횟수(100시행 안 사전 포함 검사 수)와 검사에 드는 문장 수.

## 5. 사전 기준과 절차

### 5.1 채택 기준(조건 C0~C5 모두)

1. FM ≤ 5%.
2. R3 ≥ 지금 규칙의 R3 − 10%p(100시행 안).
3. 이미 잘하는 학습자의 도달률 ≥ 95%(100시행 안).

근거는 2차 6.2절과 같다. 3번은 2차의 "도달 시행 수 중앙값 ≤ 지금 + 20"을 쓰지 않는다. 검사 기반 숙달은 구조상 최소 40시행이 걸리고(지금은 20시행),
40시행은 코디네이터가 정한 설계값이기 때문이다. 도달 시행 수는 보고만 한다.

### 5.2 후보 선택과 확인

- 탐색 시드(0)에서 T1이 5.1을 모두 만족하면 T1을 확인 후보로 한다.
- T1이 미달이면 18개 조합 가운데 5.1을 모두 만족한 것 중 R3 최솟값(조건 사이)이 가장 큰 것(같으면 FM 최댓값이 작은 것, 그다음 검사 수가 적은 것)을 고른다.
- 6절에 후보를 적어 커밋한 뒤 확인 시드(1)에서 그 하나만 판정한다. 탐색에서 통과한 것이 없으면 확인하지 않고 부정 결과로 적는다.
- 통과하면 `backend/listen_curriculum.py`에 숙달 판정을 넣고 4단계 응답에 다시 검사할 때를 알리는 필드를 더한다(계약 변경은 이 문서에 적는다). 미달이면 문서만 남긴다.

### 5.3 폼 재사용에 관한 문헌 근거(평가 전 정리)

- 행렬 문장 검사(OLSA 등)는 단어 50개의 무작위 조합이라 문장을 외우기 어렵고, 같은 목록을 되풀이해 쓰도록 설계되었다(Kollmeier 외 2015, 다국어 행렬 검사 개관).
  그래도 처음 두 목록에서 약 1.5~2 dB의 절차 학습이 있어 연습 목록을 먼저 둔다(Wagener 외 1999, 1차 evidence 2.6절의 이탈리아 행렬 검사 보고).
- 우리 검사 문장은 일상 문장(HINT·K-HINT형)이다. 일상 문장은 의미 맥락이 있어 같은 문장을 다시 들으면 기억이 이해를 돕는다는 우려 때문에, 이런 검사는
  목록을 여러 개 두고 한 사람에게 같은 목록을 되풀이하지 않는 방식으로 쓰는 것이 일반적이다(K-HINT는 문장 250개를 여러 목록으로 나눈다, Moon 외 2005).
  같은 목록 재사용의 기억 효과 크기를 직접 보고한 자료는 이번에 확인하지 못했다. 그래서 1 dB 기억 효과를 보조 조건 M1로만 둔다.
- 함의: 폼이 A·B 둘뿐이면 세 번째 검사부터 같은 문장을 다시 듣게 된다. 검사 기반 숙달을 쓰려면 폼을 늘리거나(목록 4개 이상) 재검사 사이 간격을 두는 것이 필요할 수 있다.

### 6.1 확인 후보

5.2대로 T1과 18개 조합 모두 탐색에서 미달이므로 **확인 시드를 돌리지 않는다.** 부정 결과로 적는다.

## 7. 판정

**검사 기반 숙달은 채택하지 않는다.** 코드는 바꾸지 않았고(4단계 숙달은 지금 `noise_mastered` 그대로), 4단계 응답에 다시 검사할 때를 알리는 필드도 넣지 않았다.
응답 계약 변화는 없다.

## 8. 해석과 제안

1. **검사 기반 숙달은 거짓 숙달 문제를 푸는 방향은 맞다.** 같은 기록 안에서 시행마다 향상을 보는 지금 규칙의 거짓 숙달(19~50%)이 검사 두 번의 비교로
   2~5%(C0~C4)까지 내려갔다. 걸림돌은 향상을 잡는 힘이다. 20문장 검사 두 번의 차이(SD 1.1~2.0 dB)로는 3 dB 향상과 우연한 차이를 가르기 어렵다.
   거짓 숙달 5%(두 번 비교)와 3 dB 향상 검출 80%를 함께 맞추려면 차이의 SD가 대략 3 / (1.96 + 0.84) ≈ 1.07 dB 이하여야 하는데, 이는 C0 수준이다.
   C5(SD 2.02 dB)에서 같은 정밀도를 얻으려면 검사 문장을 약 (2.02 / 1.07)² ≈ 3.6배(약 70문장)로 늘려야 한다(SD가 √문장 수에 반비례한다는 가정의 환산).
2. **현실적 대안 두 가지(다음 사전 등록 후보).**
   - 숙달의 뜻을 "5 dB 향상 또는 절대 기준"으로 바꾸는 안. T1은 5 dB 향상을 93~99% 잡았다. 다만 3 dB 향상만 한 학습자는 5단계로 넘어가기 어려워지고,
     이는 훈련 설계(4단계에 머무는 기간)의 결정이라 시뮬레이션만으로 정할 일이 아니다.
   - 훈련 기록(2차의 낱말 비율 최대가능도)과 검사를 함께 쓰는 안. 예: 훈련 기록이 향상을 가리킬 때만 재검사를 권하고, 재검사가 확인하면 숙달. 들여다보는 횟수는
     검사 기반과 같고, 훈련 기록이 사전 선별을 하므로 문턱을 낮출 여지가 있다.
3. **실제 j(문장당 독립 요소 수) 측정이 먼저다.** 1~3차 모두 C5에서 결론이 갈렸다. 4단계 실사용 기록이나 파일럿에서 같은 SNR 근처의 맞힌 낱말 수 분산을 측정하면
   C3과 C5 가운데 어느 쪽이 실제에 가까운지 정할 수 있다.
4. **폼을 늘릴 것.** 검사를 숙달·효과 판정에 쓰려면 같은 사람에게 같은 문장을 되풀이하지 않아야 한다(5.3절). 폼 A·B 두 개로는 세 번째 검사부터 같은 문장을 다시 듣고,
   1 dB의 기억 효과만 있어도 거짓 숙달이 세 배가 된다. 같은 구조로 폼을 4개 이상 만드는 것(문장 80개)을 제안한다.

## 9. 한계

1·2차 한계와 같다. 더해, 기억 효과는 크기를 모르는 채 1 dB 한 값으로만 두었고, 재검사 일정은 40·20시행 고정 간격만 보았다(학습자가 원할 때 보는 일정은 20시행
간격으로 대신했다). 검사와 훈련 사이의 절차 학습(첫 리스트 효과)은 연습 문장이 없앤다고 가정했다.
