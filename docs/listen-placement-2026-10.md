# 소리 듣기 배치검사(시작 단계 정하기): 설계와 가상 청취자 사전 기준

작성 2026-10-15. 0~7절은 시뮬레이션을 돌리기 전에 적고 커밋했다. 탐색 결과와 확인 후보는 8절, 확인 결과와 판정은 9절 이후에 덧붙인다.
코드는 `scripts/listen_placement_sim.py`, 채점 모형은 `scripts/listen_placement_model.py`(순수 numpy)다. 독화 배치검사(`docs/assessment-design.md` 10~12절)의 방식, 곧 격자 사후분포(EAP)로
시작 단계의 확률을 구하고 확신이 서면 멈추는 방식을 소리 듣기 여섯 단계에 맞게 옮긴다.

## 0. 문제와 지금 상태

- 지금 소리 듣기 트랙에는 배치검사가 없다. 0단계(소리 확인)는 늘 열려 있고, N단계는 N−1단계를 숙달했거나 '건너뛰기'로 연 경우에만 열린다
  (`main._listen_open`, `/api/listen/skip`은 바로 다음 한 단계만 연다). 학습 경로·오늘의 듣기·분석 탭 어디에도 시작 단계를 정하는 검사가 없다.
- 숙달 기준은 단계마다 다르다(`listen_curriculum.LEVELED`, `EWMA_STAGES`, `NOISE_MASTER`). 1단계는 네 수준을 차례로 올라가 맨 위 수준에서
  최근 10번 중 9번, 2단계는 세 수준을 올라가 맨 위 수준에서 10번 중 8번, 3단계는 10번 이상에서 이동 평균 80점, 4단계는 소리만 역치 0 dB 이하
  또는 3 dB 향상이다. 소리를 이미 잘 알아듣는 학습자도 4단계에 닿기까지 최소 약 90문항(1단계 40, 2단계 30, 3단계 10, 수준마다 승급 10문항씩)을
  거친다. 근거 문서(`docs/auditory-training-evidence-2026-10.md` 3.1절)는 성인에게는 엄격한 순서보다 진단적 출발이 맞다고 적었다(실무 관행, 문헌 미확인).
- 이 검사는 진단이 아니다. 앱 안에서 어느 연습부터 할지 정하는 데만 쓰고, 화면에 청력이나 기기 상태에 대한 판단을 적지 않는다.

## 1. 정하는 것

- 시작 단계 1~5. 0단계(소리 확인)는 기기 점검을 겸하므로 배치검사로 건너뛰지 않는다. 배치검사는 0단계를 한 번 마친 뒤에 할 수 있다.
- 결과가 k단계면 1~k단계를 연다(지금 '건너뛰기'처럼 'unlocked' 행을 만든다). 앞 단계는 숙달로 적지 않고, 학습자는 언제든 앞 단계로 돌아가 연습할 수 있다.
- 과배치(실제보다 높은 단계에서 시작)는 필요한 연습을 건너뛰게 하고, 과소배치는 학습자가 '건너뛰기'로 스스로 고칠 수 있는 지연이다.
  독화 배치검사와 같이 과배치를 먼저 막는다.

## 2. 참 시작 단계(시뮬레이션의 정답)

가상 청취자마다 단계별 참 성능으로 '이미 숙달한 단계'를 정하고, 처음으로 숙달하지 못한 단계를 참 시작 단계로 둔다.

| 단계 | 이미 숙달함의 조건(참 값) | 앱 숙달 기준과의 대응 |
|---|---|---|
| 1 소리 구별 | 수준 4(자리·마찰음·받침 짝) 같다·다르다 정답 확률 p_a ≥ 0.90 | 맨 위 수준 10번 중 9번 |
| 2 낱말 고르기 | 수준 3(한두 자질만 다른 4지) 정답 확률 p_w ≥ 0.80 | 맨 위 수준 10번 중 8번 |
| 3 문장 알아듣기 | 조용한 곳 문장의 낱말 정답 비율 q ≥ 0.80(가운데 난이도 문장) | 이동 평균 80점 |
| 4 소음 속 듣기 | 잡담 잡음 속 SRT50 ≤ 0 dB | 역치 0 dB 이하(`docs/listen-mastery-sim-2026-10.md` 3절의 해석) |

1~4단계를 모두 숙달했으면 참 시작 단계는 5(대화 듣기)다. 낮은 단계의 수준(1단계 수준 1~3, 2단계 수준 1~2)은 맨 위 수준보다 쉬우므로 따로 보지 않는다.

## 3. 가상 청취자 모형

### 3.1 기존 모형에서 그대로 쓰는 것

`scripts/listen_adaptive_sim.py`(2.1~2.3절)의 청취자와 소음 속 문장 응답을 그대로 쓴다.

- 집단: 정상 청력(NH) 20% SRT ~ N(−4, 1²), 보청기(HA) 40% U(−1, 8), 인공와우(CI) 40% U(2, 22) dB.
- 기울기: s_i = clip(0.16 − 0.004 (SRT_i + 4) + N(0, 0.015²), 0.05, 0.20).
- 소음 속 낱말 정답 확률: L(4 s_i (x − SRT_i − δ − ε)), L은 로지스틱, δ는 문장(과 목소리)의 난이도, ε는 제시마다 문장 낱말에 함께 걸리는 흔들림.
- 문장 난이도 δ는 가정값 대신 **소리 듣기 가상 청취자 실험 V1**(`docs/listen-virtual-listener-2026-10.md`, Whisper 받아쓰기, 정상·인공와우 모의·보청기 모의)의
  문장별 SRT40을 쓴다. 배치검사 문장 풀(4.2절) 문장 × 목소리마다, 청취자 집단에 맞는 모의(NH → 정상, HA → 보청기 모의, CI → 인공와우 모의)의 SRT40에서
  그 모의의 풀 전체(네 훈련 목소리) 평균을 뺀 값이다. 목소리 차이(V1에서 m1·f1이 m2·f2보다 약 3 dB 쉬움)도 이 값에 들어 있다.
  V1 뒤 서버 음성이 다시 합성되어(10/9) 클립이 같지 않으므로, 이 값은 문장별 정확한 난이도가 아니라 난이도 퍼짐의 경험 분포로 쓴다.

### 3.2 새로 더하는 연결 가정(조건으로 흔든다)

기존 모형은 소음 속 문장만 다룬다. 조용한 곳의 문장·낱말·소리 구별 성능을 같은 청취자에게 주려면 연결 가정이 필요하다. 아래 값은 모두 가정이고,
5절의 조건으로 크기와 방향을 바꿔 판정이 가정 하나에 기대지 않게 한다.

- **조용한 곳 능력 z_i(로짓).** z_i = a0 − b · SRT_i + u_i, u_i ~ N(0, σ_u²). 기준값 a0 = 3.9, b = 0.175, σ_u = 0.7.
  조용한 곳 문장의 낱말 정답 비율은 L(z_i + e), e는 문장마다 N(0, σ_q²)(기준 0.5). 기준값에서 SRT −4 dB는 0.99, +3 dB는 0.97, +12 dB는 0.86, +20 dB는 0.57이다.
  고정점: V1의 인공와우 모의(m3 SRT40 평균 +12.1 dB)의 조용한 곳 낱말 비율 0.903(로짓 2.23)은 이 직선의 +0.4로 σ_u 안에 든다.
  정상 청력과 보청기 모의는 조용한 곳에서 0.99였다.
- **낱말 고르기(수준 3).** 정답 확률 p_w = 1/4 + 3/4 · L(z_i − Δw + d_w,i), d_w ~ N(0, τ²). 기준 Δw = 0, τ = 0.7. 문항마다 로짓 N(0, 0.5²)을 더한다.
- **소리 구별(수준 4).** 같다·다르다 정답 확률 p_a = 1/2 + 1/2 · L(z_i − Δa + d_a,i), d_a ~ N(0, τ²). 기준 Δa = 0. 문항마다 로짓 N(0, 0.5²).
- 기준값에서 세 조용한 곳 과제의 숙달 조건은 z(+편차)로 2절의 문턱이 된다: 소리 구별 z + d_a ≥ 1.386, 낱말 z + d_w ≥ 1.012, 문장 z ≥ 1.386.
  편차가 없으면 참 시작 단계는 1·4·5뿐이고, 편차(u, d)가 2·3단계 시작을 만든다. Δ의 부호는 알 수 없다. Erber 위계(구별 → 확인 → 이해)를 따르면 낮은 단계가
  쉽고(Δ < 0), 한 음절의 자리·마찰음·받침 짝은 보청기·인공와우 사용자가 가장 자주 놓치는 대조라 낮은 단계가 어려울 수도 있다(Δ > 0). 둘 다 조건으로 둔다.

### 3.3 모형에 넣지 않은 것

연습 효과, 피로, 문항 사이 학습, 입력 속도는 넣지 않는다. 문장 답의 띄어쓰기·맞춤법 실수는 실수 조건(G8)의 낱말 실수로만 근사한다.

## 4. 배치검사 절차

### 4.1 문항 종류와 걸리는 시간

시간은 오늘의 듣기 계획의 문항당 초(`listen_curriculum.TODAY_SECONDS`)를 쓴다.

| 종류 | 내용 | 초 | 채점 |
|---|---|---|---|
| 소리 구별(pa) | 1단계 수준 4 같다·다르다, 같음·다름 반반 | 12 | 정오 |
| 낱말 고르기(pw) | 2단계 수준 3, 4지 | 15 | 정오 |
| 조용한 곳 문장(pq) | 3단계와 같은 받아쓰기, 첫 답만 | 40 | 맞힌 낱말 수 k / 4 (`word_score`) |
| 소음 속 문장(pn) | 4단계와 같은 잡담 잡음(babble) 받아쓰기, 정한 SNR | 40 | k / 4 |

### 4.2 문항 풀(검사 분리 규칙)

- 문장: `TRAIN_SENTENCES`에서 4어절, V1에서 측정한 같은 글이 있음, 일반화 검사 낱말과 교체 후보가 글자로 들어 있지 않음(`gen_words_in`), V1 조용한 곳에서 정상·보청기 모의가
  네 훈련 목소리 모두 다 맞힘, 세 모의·네 목소리 모두 SRT40이 그 모의·목소리 평균에서 1.5 SD 안. 이 규칙으로 13문장이 남는다(t002·t003·t004·t009·t011·t012·t014·t023·t029·t042·t076·t087·t092,
  V1 번호). 소리 듣기 검사 폼(A~D)의 문장은 쓰지 않는다(훈련 문장이라 이미 분리돼 있다).
- 목소리: 훈련 목소리 m1·f1만 번갈아 쓴다(검사 목소리 m3는 쓰지 않음). 채점은 V1에서 구한 목소리 보정(m1·f1 평균이 네 훈련 목소리 평균보다 얼마나 쉬운지,
  세 모의 평균)을 SNR에서 빼서 '네 목소리 평균 기준' 역치로 읽는다. 풀 13문장의 V1 SRT40으로 m1 −2.35 dB, f1 −1.18 dB이다
  (모의별 m1 −2.26·−2.27·−2.51, f1 −0.62·−0.72·−2.20, 정상·보청기·인공와우 순). 채점의 실효 SNR은 SNR + 2.35(m1), SNR + 1.18(f1)이다.
- 낱말: 2단계 수준 3 문항(`word_items`, 소리 듣기 낱말 풀 `word_pool()`: 독화 표준검사 정답·일반화 검사 낱말·드문 말이 이미 빠짐)에서 교체 후보 넷(손목·경찰·고기·오이)을
  정답·보기에서 더 빼고, 피할 목소리(`avoid_voices_word`)가 없는 정답만 쓴다.
- 소리 구별: 1단계 수준 4 짝 20개에서 피할 목소리(`avoid_voices_ax`)가 훈련 목소리 셋 이상인 짝(바·다, 바·가, 파·타)을 뺀 17개. 남은 짝의 피할 목소리는 문항에 붙여 화면이 건너뛴다.
- 한 회기에서 같은 문장·낱말·짝을 두 번 내지 않는다.

### 4.3 채점 모형(앱이 쓰는 것)

- 격자: SRT θ −12 ~ +30 dB(1 dB 간격) × 조용한 곳 편차 u −2.1 ~ +2.1(0.35 간격). z = 3.9 − 0.175 θ + u. 사전분포 θ ~ N(5, 10²), u ~ N(0, 0.7²).
- 과제별 편차 d_a, d_w는 −2.1 ~ +2.1(0.35 간격), 사전분포 N(0, 0.7²). 각 과제의 자료(정답 수, 문항 수)로 z마다 d의 사후분포를 구한다(과제끼리는 z가 주어지면 독립).
- 가능도: 소음 속 문장 이항(4, L(4 s(θ)(x − θ))), s(θ)는 3.1절 기울기 직선(잡음 없음), 조용한 곳 문장 이항(4, L(z)), 낱말 1/4 + 3/4 L(z + d_w), 소리 구별 1/2 + 1/2 L(z + d_a).
  실수 2%를 넣는다(문장 낱말은 0.98배, 고르는 문항은 2%를 우연 수준으로).
- 시작 단계 확률: 격자 점마다 π_a = P(z + d_a ≥ 1.386 | 자료), π_w = P(z + d_w ≥ 1.012 | 자료)로 P(1) = 1 − π_a, P(2) = π_a(1 − π_w), P(3) = π_a π_w 1[z < 1.386],
  P(4) = π_a π_w 1[z ≥ 1.386] 1[θ > 0], P(5) = π_a π_w 1[z ≥ 1.386] 1[θ ≤ 0]을 사후분포로 평균한다.

### 4.4 문항 고르기, 멈춤, 결정

- 후보: 소리 구별 1개, 낱말 1개, 조용한 곳 문장 1개, 소음 속 문장 SNR {−6, −3, 0, 3, 6, 10, 14, 18} dB(8개).
- 고르기: 후보마다 답의 예측분포로 시작 단계 분포의 기대 엔트로피 감소를 구하고, 이를 (걸리는 초)^γ로 나눈 값이 가장 큰 후보를 낸다. γ ∈ {0, 1}을 탐색한다.
  비교용 '문장만' 절차는 소음 속 문장 후보만 쓴다.
- 멈춤: 최소 m문항 뒤 가장 큰 시작 단계 확률이 s 이상이면 멈춘다. 문항 16개 또는 300초(다음 문항을 내면 넘는 때)에 닿아도 멈춘다. m ∈ {2, 4}, s ∈ {0.80, 0.85, 0.90, 0.95}.
- 결정: (mode) 확률이 가장 큰 단계, 또는 (보수 q) P(참 시작 ≥ k) ≥ q인 가장 큰 k. q ∈ {0.6, 0.7, 0.8}.
- 탐색 조합: γ 2 × m 2 × s 4 × 결정 4 = 64개와 '문장만'의 m 2 × s 4 × 결정 4 = 32개. 고르기는 멈춤·결정과 무관하므로 한 번 돌린 문항 흐름에서 모든 멈춤·결정을 계산한다.

## 5. 조건

조건마다 집단 비율은 3.1절 그대로다. G0이 기준이고 나머지는 하나씩 바꾼다.

| 조건 | 바꾸는 것 |
|---|---|
| G0 | 기준(σ_u 0.7, τ 0.7, Δ 0, 문장 난이도 V1 경험 분포, σ_q 0.5, 흔들림 없음, 실수 없음) |
| G1 | 소음 속 문장 흔들림 ε 2 dB(기존 C3), 조용한 곳 문장 제시마다 로짓 N(0, 0.5²) |
| G2 | ε 4 dB(기존 C5, 문장당 독립 요소 약 2), 조용한 곳 제시마다 로짓 N(0, 1²) |
| G3 | 편차를 크게: σ_u 1.2, τ 1.2(채점 모형은 0.7 그대로) |
| G4 | 낮은 단계가 쉬움: Δa = Δw = −1 |
| G5 | 낮은 단계가 어려움: Δa = Δw = +1 |
| G6 | 연결이 완만함: b 0.125, a0 3.3(SRT +12 dB의 z는 그대로) |
| G7 | 연결이 가파름: b 0.225, a0 4.5 |
| G8 | 실수 많음(고르는 문항 5%, 문장 낱말 3%) + 모든 청취자 기울기 9%/dB(기존 C4) |

채점 모형은 모든 조건에서 4.3절 그대로다(G1~G8은 잘못 지정된 가능도).

## 6. 지표와 사전 기준

### 6.1 지표(조건마다, 집단 NH·HA·CI별로도)

- 일치: 배치 = 참 시작 단계. 과배치: 배치 > 참. 심한 과배치: 배치 ≥ 참 + 2. 과소배치: 배치 < 참.
- 평균 문항 수, 평균 시간(초, 4.1절), 95백분위 시간.
- 비교 기준(지금 앱): 모두 1단계에서 시작. 일치 = P(참 시작 = 1), 과배치 0.

### 6.2 채택 기준(확인 시드, 아홉 조건 모두)

1. **K1** 과배치 ≤ 10%.
2. **K2** 심한 과배치 ≤ 2%.
3. **K3** 일치가 지금(모두 1단계)보다 20%p 이상 높고, 아홉 조건 평균 일치 ≥ 60%.
4. **K4** 평균 문항 수 ≤ 12, 평균 시간 ≤ 240초, 95백분위 시간 ≤ 300초.
5. **K5** 집단(NH·HA·CI)마다 과배치 ≤ 15%.

근거: 과배치 10%는 독화 배치검사가 채택할 때의 값(적응형 9.8%)과 같은 수준이다. 심한 과배치는 두 단계 이상을 건너뛰는 것이라 독화보다 넉넉한 2%를 두되
50명 중 1명 이하로 막는다. 일치 +20%p는 검사 4~5분을 들일 만한 차이로 본 값이고, 평균 60%는 다섯 갈래 분류에서 우연(20%)과 지금 기준을 넉넉히 넘는 값이다.
시간 상한 4분은 오늘의 듣기 권장(하루 15~20분)의 4분의 1 안이다. 집단 기준은 한 집단(특히 인공와우 사용자)에게 과배치가 몰리는 것을 막는다.

### 6.3 탐색과 확인

- 탐색 시드 0, 조건마다 청취자 2,000명. 64 + 32개 조합 가운데 아홉 조건 모두에서 K1~K5를 만족하는 것만 남기고, 그중 아홉 조건 최소 일치가 가장 큰 것 하나를 고른다
  (같으면 평균 시간이 짧은 것). 8절에 적어 커밋한 뒤 확인 시드 1(조건마다 4,000명)에서 그 하나만 판정한다.
- 탐색에서 모든 조합이 기준을 넘지 못하면 확인을 돌리지 않고 부정 결과로 적는다.
- 확인 결과를 본 뒤 기준·조건·후보를 바꾸지 않는다.

## 9. 판정과 다음 등록 제안

**판정: 사전 등록한 배치검사 절차를 채택하지 않는다(탐색 단계 부정 결과).** 앱 코드·화면은 바꾸지 않았다. 소리 듣기는 지금처럼 0단계부터 시작하고, 학습자가 한 단계씩 건너뛸 수 있다.

다음 등록 후보(이번에 돌리지 않음):

1. **1단계를 건너뛰지 않고 1단계 안의 수준을 정하기.** 수준은 앱이 스스로 올리고 내리므로(`next_level`, 10번 중 3번 이하면 내림) 수준 과배치의 비용이 작다. 2~4단계를 건너뛰는 판단만
   배치검사가 하고, 소리 구별은 '수준 3부터' 같은 출발점만 정한다. 참 시작의 정의를 '1단계 수준 k + 그 위 단계'로 다시 적어야 한다.
2. **건너뛴 단계를 짧은 확인으로 남기기.** 4단계에 배치하더라도 1단계 수준 4 확인 10문항(약 2분)을 첫 회기에 넣고, 9/10에 못 미치면 1단계를 다시 여는 방식. 과배치의 비용을 줄이는 대신
   검사 밖 시간이 든다. 이 흐름의 거짓 진급과 시간을 같은 모형으로 등록해 판정한다.
3. 위 둘 모두 연결 가정(3.2절)의 크기에 기대므로, 청인 예비 파일럿(인공와우 모의)의 소리 구별·낱말·문장 기록으로 Δ와 τ의 범위를 먼저 좁히는 것이 순서다.
