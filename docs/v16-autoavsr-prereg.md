# V16 사전등록: Auto-AVSR 사전학습 시각 전단 대 D6(2026-10-06, 실행 전)

종합 계획(`master-plan-2026-10.md`)의 V16과 병렬 탐색 나18을 실행하기 전에 판정 기준과 분석 방법을 고정한다. 이 문서는
결과를 보기 전에 커밋하며, 실행 뒤에는 결과 절만 덧붙인다.

## 1. 질문

영어 대규모 입술 영상으로 사전학습한 시각 전단(Auto-AVSR, Ma et al. 2023)을 특징 추출기로 쓰면, 같은 538 화자 데이터에서
지금의 D6(MediaPipe 얼굴 계수와 입술 좌표 특징) 모델보다 한국어 어절 분류 정확도가 높은가. 결과는 V1(538 화자 150~200명
재학습)의 기본 구조를 정하는 데 쓴다.

## 2. 가중치와 데이터 이용 조건

- 코드(github.com/mpc001/auto_avsr)는 Apache 2.0이다. 저장소는 사전학습 가중치가 학습 데이터의 조건을 따른다고 적고 있다.
- 쓰는 체크포인트는 `vsr_trlrs3vox2_base.pth`(LRS3 + VoxCeleb2, LRS3 WER 24.6%)다. LRS3는 비상업 연구용(CC BY-NC-ND 4.0으로
  알려짐)이고 VoxCeleb2도 연구용으로 배포된다. LRS2(BBC 별도 약관)를 포함한 `vsr_trlrs2lrs3vox2avsp_base.pth`는 약관이 더
  좁아 쓰지 않는다.
- 이용 범위: 이 시험은 비상업 연구 목적의 기계 평가다. 가중치와 미세조정한 머리는 실험 저장소(`liplab-lab`)와 파드 안에만
  두고 배포하지 않으며 제품(앱, 브라우저 모델)에 넣지 않는다. V16이 통과해도 이 구조는 연구용 판독기(V1·V2의 두 번째
  판독기)로만 쓰고, 제품 판독기로 쓰려면 상업 이용이 가능한 가중치를 따로 확보해야 한다.

## 3. 설계

- 벤치: `d-bench-v2.md`와 같은 벤치 파일(bench_id `ae9ea5cc`, 538 30화자 829클립, 어절 인스턴스 7,590개). 5겹 화자·내용
  동시 분리(폴드마다 평가 6명, 검증 1명, 학습 23명), 폴드마다 학습 화자로 정한 어휘, 시드 0·1·2, 총 15적합.
- 기준: 9/24에 같은 벤치로 돌린 D6 15적합(`liplab-lab/data/pod_runs/20260924_k74l2l74024fsz/d/runs_s2`, top-1 18.6%).
  다시 학습하지 않는다. 평가 인스턴스와 4지선다 오답 보기는 폴드마다 같으므로 짝지어 비교한다.
- 입력: 9/24 D-7과 같은 입술 ROI(88×88 흑백, 입 너비의 2.0배, 머리 기울기 보정, `lip_roi_extract.py` 기본값)를 파드에서
  다시 뽑는다. Auto-AVSR 기준 얼굴에서 96 자르기의 가운데 88은 입 너비의 약 1.96배라 화면 비율이 거의 같으므로 88을 그대로
  넣는다. 정규화는 Auto-AVSR 평가 변환과 같게 (x/255 − 0.421)/0.165, 프레임은 30fps에서 25fps로 가장 가까운 프레임을 뽑는다.
- 주 설정 AV16: 인스턴스의 'wide' 구간(D6와 같은 구간)만 얼린 인코더에 넣는다. 문장의 다른 부분은 보지 않으므로 D6와
  입력 정보가 같다. 인코더의 층 13개(투영 출력과 Conformer 블록 12개) 출력을 저장하고, 머리는 층 가중 합(softmax 가중치,
  층마다 LayerNorm) → 768→256 선형 → 잔차 1차원 합성곱(k=3) → 주의 풀링 → 어휘 분류다.
- 학습: AdamW lr 1e-3, wd 0.05, 라벨 스무딩 0.1, 워밍업 3에폭 뒤 코사인, 배치 32, 최대 100에폭, patience 15, 에폭 선택은 검증
  화자의 top-5(동점은 NLL). 증강은 시간 마스크 3프레임 이하만. 하이퍼파라미터는 이 값으로 고정하고 평가 결과를 보고 바꾸지
  않는다. 코드는 `liplab-lab/tools/v16_avsr.py`.
- 잘라낼 수 없는 인스턴스(구간 프레임의 절반 넘게 얼굴 미검출)는 D-7과 같이 오답으로 센다.

## 4. 판정 기준(주 지표 하나)

- 지표: top-1 정확도, 화자별 평균(시드 평균)의 평균. 95% CI는 폴드→화자 계층 부트스트랩 10,000회, 차이는 화자별 짝
  차이(AV16 − D6)의 같은 부트스트랩과 부호뒤집기 검정(보조).
- **통과: Δtop-1 ≥ +5.0점이고 95% CI 하한 > 0.** 통과하면 V1의 기본 구조를 Auto-AVSR 전단으로 한다(연구용 판독기, 2절의
  범위). 미달이면 V1은 D6 구조(MediaPipe 특징)로 한다.
- 계산 도구: `train_lip_roi.py compare --runs runs_s2 --runs v16/runs --cand AV16 --ref D6,D0`(9/24 D-7과 같은 집계 코드).

## 5. 보고만 하는 것(판정에 쓰지 않음)

- top-5, 4지 hard·easy, 개발에 쓰지 않은 20화자(spk311~330)만의 차이, 오라클 에폭 값, 학습된 층 가중치.
- AV16ctx: 문장 전체를 인코더에 넣고 같은 구간을 잘라 쓴 변형. 문장 맥락이 더해져 D6와 정보량이 다르므로 판정에 쓰지 않는다.
- 제품 4지선다(새 화자 21.8~25.9%)와는 과제가 달라 직접 비교하지 않는다.

## 6. 중단 조건

- 체크포인트의 전단·인코더 키가 하나라도 빠지면 중단하고 보고한다.
- ROI 추출 실패가 5%를 넘거나, ROI 입 벌림과 벤치 jawOpen의 상관이 지연 0에서 최대가 아니면(`train_lip_roi.py check`) 중단한다.
