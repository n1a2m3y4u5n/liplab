# 아바타 기계 판독 대리 등록안 (C1·C2 겸, 사전 등록 2026-10-27)

`docs/decisions-2026-10-27.md`의 아바타 판독 결정을 실행한다. 이 문서는 확인 150낱말을 렌더하기 전에 쓰고 따로 커밋한다.
**모든 수치는 기계 지표다. 사람 판독이 아니며 앱 값은 바꾸지 않는다(제안만).**

## 1. 환경 차이(기록)

- 실험 ①은 데스크탑(ANGLE D3D11)이었고, 이번은 lab-main(RTX 3060 12GB)의 Edge(headless, D3D11)다. 판독기는 같은 R2 s0이지만 웹용 fp32 ONNX
  (정규화 밖, 외부에서 `x/255 → 시퀀스 평균·표준편차`)다. 문항·창·채점식은 `avread.py`와 같다(`scripts/avread/c12_score.py`).
- 재현 점검(탐색 150낱말, 이미 본 자료): V3 j1.3 l1.3 = 36.0%(기존과 같음), V1 j1.0 l1.0 = 15.3%(기존 16.0%). 환경이 같은 결과를 낸다.

## 2. 대리 타당성 관문(기본값으로 정함)

결정문의 "표마다 관문"을 다음으로 읽는다. 판정으로 우월을 주장하는 쪽(후보 표)의 탐색 4지 정확도의 낱말 부트스트랩 95% 하한이 > 25%여야 한다.
- 후보 V3 j1.3 l1.3: 탐색 36.0% [28.7, 44.0] → 통과(재현 값 사용).
- 기준 V1 j1.0 l1.0: 하한이 25% 아래(16.0 [10.7, 22.0]) → **기준 표는 관문 미달**이다. 판정은 하되 아래 해석 제한을 같이 적는다:
  V1의 낮은 값에는 독화기 영역 차이가 섞여 있어 Δ가 크게 나와도 "V3가 사람에게 더 잘 읽힌다"가 아니다.
- 이 해석은 결정문이 모호해 내가 정한 것이다. 엄격히 "표마다 미달이면 판정 안 함"이라면 판정 없음이며, 보고서에 두 읽기를 모두 적는다.

## 3. 확인 판정(한 번)

- 문항: `items.json` 확인 150낱말(렌더한 적 없음). 조건: V3 j1.3 l1.3, V1 j1.0 l1.0, 재생 1.0배.
- Δ = V3 − V1 4지 정확도(낱말 짝) ≥ +5.0점이고 부트스트랩(10,000회, 시드 0, 백분위) 95% 하한 > 0이면 통과.
- 통과해도 V3는 앱 재생에 연결돼 있지 않으며(자기 등록 2.0배 진폭 미달) 연결은 사용자 결정이다. 사람 판독 주장 아님.

## 4. C1 (기계 혼동 짝, 예비)

- 정의: 4지 오답에서 정답 낱말 → 고른 낱말의 자모 정렬 치환을 짝으로 집계(초·중·종, 삽입·삭제 포함), 입모양 규칙(VISEME_MAP)과 대조.
- 사전 기준(시뮬레이션 숙달 20% 단축)은 **V1(538 재학습 독화기)에 의존**하고 538은 받기 중이라 이번에 판정하지 않는다. 짝 사전은 300낱말(탐색+확인) 예비 집계다.

## 5. C2 (기계 독화 난이도, 예비)

- 낱말 난이도 = −(정답 보기 점수 − 오답 최대 점수)(마진). V3 j1.0·1.3·1.6에서 조건 간 순위 안정성(스피어만), 규칙 지수·음절 수와의 상관을 보고.
- 사전 기준 ρ ≥ 0.4(예비 파일럿 정답률)는 파일럿 자료가 없어 **판정 불가**다.
